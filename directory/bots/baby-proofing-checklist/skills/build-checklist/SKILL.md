---
name: build-checklist
description: Make a room-by-room baby-proofing list from web search results.
---

1. Search the web for "baby-proofing checklist crawling nine-month-old". 2. If results appear, open the top result. 3. Read the page and extract room names and safety items. 4. If the page has a table, copy the rows. 5. If the page is a list, note the room and item for each line. 6. If no items are found, search again with different terms. 7. When items are gathered, make a table with columns "room" and "safety item". 8. Put each item in the correct room row. 9. If a room has no item, leave the cell blank. 10. After the table is done, write a text file named baby-proofing-checklist.txt with the same list, one item per line, showing the room name before each item. 11. Show the table and the file name to the person.
