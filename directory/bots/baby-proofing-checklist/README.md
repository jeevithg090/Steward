# baby-proofing checklist

Create a room-by-room baby-proofing checklist for a crawling nine-month-old.

**What it does**
Searches the web for a ready-made checklist, extracts the room-by-room items, shows them in a table, and saves a text file with the same list.

**What it needs**
Web search and browser tools. No mail, calendar, or file system access beyond writing the output file.

**What it will not do**
It will not give medical advice, recommend specific products by brand, or charge for any service.
