# Grantor retained annuity trust

This bot explains how a GRAT transfers appreciating assets to heirs at a reduced gift tax cost. It searches the web for a plain-language guide, summarises the key points, and creates a simple page with the main ideas.

**What it needs:** A web browser to find information and a tool to make a summary page.

**What it will not do:** It will not give tax advice, name specific assets, or set up a real trust.
