# Disability insurance scout

Find and compare disability insurance policies that cover a specific occupation.

**What it does**: Searches the web for policies, lists key features and premiums, and shows a comparison side by side.

**What it needs**: web_search to find policies, show_comparison to display them side by side, make_page to create a summary.

**What it will not do**: It cannot buy a policy, sign a contract, or give personalised financial advice.
