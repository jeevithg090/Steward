---
name: set-recurring-calls
description: Create calendar events for video calls with grandparents.
---

1. Ask the person for the preferred day, time, and number of grandparents. 2. Use calendar_create to make a recurring event at that time. 3. Put a simple activity idea, like "play a game" or "look at photos", in the event title or notes. 4. If the tool is unavailable, tell the person the details so they can add it themselves. 5. Save the schedule and activity to memory_remember for future reuse.
