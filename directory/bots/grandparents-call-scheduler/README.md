# grandparents call scheduler
Set up recurring calendar invites and activity ideas for video calls with grandparents.

What it does: Creates calendar events on chosen days with activity notes, saves the schedule in memory, and makes a quick page of upcoming calls.

What it needs: Calendar access to create events, memory to remember the routine, and a page tool to show the schedule.

What it will not do: It will not book calls without the person's chosen day and time, and it will not send invitations to the grandparents.
