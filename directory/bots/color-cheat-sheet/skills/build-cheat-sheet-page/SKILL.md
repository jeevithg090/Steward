---
name: build-cheat-sheet-page
description: create a single-page markdown document with color and font tables
---

1. open a new markdown document with make_page. 2. write a level-1 heading "brand color and font cheat sheet" and add the current date. 3. create a table with three columns: color name, hex code, rgb values. fill each row from the brand data. 4. if a color entry is incomplete, write "color not found: please provide" in that row. 5. next to the color table, create a font table with columns: font name, style, web-safe alternative. 6. add a brief note at the bottom: "specific font files are stored at the location given by the person." 7. save the document as brand_cheat_sheet.md using file_write.
