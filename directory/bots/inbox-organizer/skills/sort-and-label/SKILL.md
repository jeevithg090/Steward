---
name: sort-and-label
description: Organise existing messages into project labels.
---

1. List all current labels and all messages in the inbox. 2. For each message, read the subject and body. 3. Check if any project keyword appears. 4. If a keyword matches, apply that label and move the message out of the inbox. 5. If no keyword matches, leave the message as is. 6. Tell the person how many messages were labelled and which ones were left untouched.
