---
name: auto-file-new-mail
description: Apply labels to incoming mail automatically.
---

1. When new mail arrives, read its subject and body. 2. Look for project keywords. 3. If one keyword matches a label, apply that label and archive the message. 4. If several keywords match, ask the person which label to use. 5. If no keyword matches, leave the message in the inbox and tell the person. 6. Remember the person's choice for next time using memory_remember.
