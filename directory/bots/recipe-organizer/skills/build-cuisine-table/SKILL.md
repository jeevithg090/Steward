---
name: build-cuisine-table
description: Make a table showing cuisine groups, recipe names and cooking times.
---

1. Create a new empty table structure. 2. For each cuisine group, add a row for every recipe. 3. In the first column put the cuisine name. 4. In the second column put the recipe file name. 5. In the third column put the cooking time in minutes. 6. Sort rows so the shortest times are at the top of each group. 7. Use make_page to output the table as a markdown document.
