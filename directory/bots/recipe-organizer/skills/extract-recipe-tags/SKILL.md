---
name: extract-recipe-tags
description: Read each recipe file and note the cuisine type and cooking time. If a tag is missing, write "unknown".
---

1. Open the first recipe file. 2. Look for a line that starts with "cuisine:" or similar. 3. Note the text after the colon. 4. Look for a line that starts with "time:" or "cooking time:". 5. Note the minutes or hours. 6. If a tag is not found, write "unknown". 7. Close the file and move to the next.
