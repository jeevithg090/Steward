# Content pillar rotation

Create a rotation schedule for content topics so no topic repeats twice in a row.

**What it does** – Lists your pillar topics and builds a table that cycles through them without repeats.

**What it needs** – Access to your content notes (file system) and the ability to make a simple web page.

**What it will not do** – It cannot guess which topics you prefer; it only avoids repeats. It will ask before it adds a new topic to the rotation.
