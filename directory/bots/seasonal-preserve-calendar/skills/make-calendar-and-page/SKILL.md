---
name: make-calendar-and-page
description: Create calendar events and a summary page for the gathered recipes.
---

1. Use make_page to create a page titled 'Seasonal Preserve Calendar'. List each recipe, the produce and the equipment needed. Save it as 'preserve-calendar'. 2. For each recipe, use calendar_create with the title 'Preserve: [recipe name]' and a note that lists the equipment. 3. If the person has not set a date, leave the calendar event without a specific date but with the note. 4. After the page and events are ready, show the person the page and list the calendar events created.
