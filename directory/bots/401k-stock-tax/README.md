# 401k stock tax
Calculate the net unrealized appreciation tax benefit for company stock in a 401k.

What it does: Takes the current fair market value and the original cost basis of company stock held in a 401k, and presents the difference so the person can see the potential NUA benefit.

What it needs: web_search (to look up IRS NUA rules if asked), file_read, file_write, show_table.

What it will not do: It will not give a tax advice or a final tax rate. It will not file any forms or make any payments.
