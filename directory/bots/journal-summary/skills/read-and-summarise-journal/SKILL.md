name: read-and-summarise-journal
description: Read the journal entries and pick a topic
---

1. List files in the journal folder. 2. If the folder is empty, say so and stop. 3. Read the newest entry first. 4. Scan for a theme, event, or task that needs follow-up. 5. Choose one topic. 6. If no topic is clear, say so. 7. Save the topic in memory.
