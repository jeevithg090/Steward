# rice cooker meals
Plan a week of dinners using only a rice cooker and microwave.

What it does: searches the web for simple recipes, saves them to a file, and shows a table of the seven dinners and their main ingredients.

What it needs: web_search to find recipes, file_write to save them, show_table to display the menu.

What it will not do: it will not invent recipe details, give cooking times it cannot check, or pay for anything.
