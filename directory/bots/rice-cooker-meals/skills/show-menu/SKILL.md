description: Display the week's dinners as a table.
---

1. Read dinners.txt with file_read. 2. Pull out the dinner name and main ingredient for each line. 3. Use show_table to make a two-column table: dinner name | main ingredient. 4. Show the table to the person. 5. If the file is empty or has fewer than seven entries, say how many meals are planned and ask if more are wanted.
