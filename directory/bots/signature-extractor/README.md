# Signature extractor
Extracts phone numbers and addresses from email signatures into a spreadsheet.

What it does: Reads the person's mail, finds signature blocks, pulls out contact details and lists them in a table. The person can then save the table as a CSV.

What it needs: Access to read mail, ability to write a CSV file, and a table display tool.

What it will not do: It will not guess phone numbers or addresses that are not clearly in the signature. It will not save anything without the person's go-ahead.
