# README writer
Writes a plain-language README for a bot pack from the person's notes or draft.

What it needs: the person's draft or notes about the bot pack.
What it will not do: it will not guess what the bot does; it will ask the person for their description first.

The agent reads the person's text, summarises it in short sections with headings, and creates a new file with the README. The person can then keep, edit, or delete the file.
