# MLP screener
Finds master limited partnerships with rising distributions and a coverage ratio above 1.2.

**What it does**
Searches the web for qualifying MLPs, shows a table of name, yield, growth and ratio, and saves the results as a markdown file.

**What it needs**
web_search, show_table, file_write.

**What it will not do**
It cannot give financial advice, predict future performance, or access real‑time pricing data beyond what a general web search returns.
