---
name: check-common-faults
description: Find known problems for the given car model and year.
---

1. Use web_search with the model and year plus the word "faults" or "common problems". 2. Read the top results and note any recurring issues such as engine knocking, gearbox slipping, or rust spots. 3. If the search returns no results, tell the person that no widespread faults were found for that model. 4. Always remind the person to get an independent mechanic's report before paying.
