---

name: draft-toast
description: Write the toast in the person's voice and save as a page.
---

1. Structure the toast: hook, story one, story two or partner note, wish, closing raise line.
2. Write using the person's vocabulary, rhythm, and humour.
3. Keep sentences speakable and under 20 words.
4. Use make_page to create an editable document with word count and speaking time.
5. Present the draft and ask for changes: shorten, add humour, swap story, adjust tone.
6. Iterate until the person approves, then save the final version.
