# report summariser
Turns a long report into a one-page summary for a director.

**What it does:** Reads a report file, pulls out the key points and writes a short briefing.

**What it needs:** The report file to read from; creates a new summary page.

**What it will not do:** It will not write the summary if the report is shorter than 200 words, and it will not keep the file without asking the person first.
