# med-check
Check prescription and supplement interactions from a list of current medicines.

What it does: searches the web for each medicine the person lists, records interactions, and saves a text file.
What it needs: web_search to find interaction data, file_write to save the results, and show_comparison to display findings side by side if needed.
What it will not do: it cannot give medical advice, prescribe treatment, or replace a doctor or pharmacist.
