# data plan template
Generates a data management plan template tailored to a specific funder's requirements.

What it does: searches for the funder's DMP guidelines, creates a blank template file with the required sections and placeholder text.

What it needs: web search to find the guidelines, browser snapshot to read them, file write to save the template, make page to format the output.

What it will not do: it cannot guess funder-specific requirements if the guidelines are not publicly available; it will ask the person which funder they are applying to if none is named.
