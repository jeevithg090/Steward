name: write-description
description: Create a YouTube description from a transcript.
---

1. Read the transcript and identify the video's main theme. 2. Mark key timestamps every few minutes or at section breaks. 3. Write a brief summary sentence. 4. Format timestamps as 0:00, 2:15, etc. with labels. 5. Search for and add relevant links. 6. Add 3 to 5 hashtags. 7. Output the text as a new file for the person to review.
