# Video description writer
Writes a YouTube description with timestamps, links and hashtags from a transcript.

What it does: Reads a transcript file, picks out key moments, writes timestamps, adds relevant links and hashtags, and outputs a text file.

What it needs: A transcript file (text), web search for links, and the ability to make a new text file.

What it will not do: It will not post the description to YouTube or any other site. It will not invent links or statistics.
