---
name: build-routine
description: Create a short mobility routine for shoulders and hips.
---

1. Check memory_remember for any past injuries or tightness level. 2. If injuries are recorded, note them and exclude any exercise that matches. 3. Web-search for 'shoulder mobility exercises' and 'hip mobility exercises'. 4. Pick 5 to 8 exercises that are commonly safe and effective. 5. For each exercise, write the body part targeted and one short tip on form or breathing. 6. If fewer than 5 good exercises are found, say so and list what was searched for. 7. Use make_page to turn the list into a table titled 'Warm-up routine'. 8. Show the table to the person and ask if they want any changes. 9. If changes are requested, update memory_remember with the new preferences and return to step 2. 10. When the person is happy, mark the task as complete.
