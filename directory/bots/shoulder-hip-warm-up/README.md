# Shoulder-hip warm-up
A personalized warm-up routine to loosen tight shoulders and hips before strength training.

What it does: searches for mobility exercises, stores the person's tightness level, and builds a simple table they can follow.

What it needs: memory_remember to save the person's preferences, make_page to create the routine document, show_table to display the exercises.

What it will not do: give medical advice or claim the routine prevents injury. Stop if the person feels pain and ask them to consult a professional.
