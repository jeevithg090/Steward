---
name: scan-portfolio-for-region
description: Read the portfolio page and identify holdings linked to China.
---

1. Navigate to the portfolio dashboard. 2. Scan the page for a geography or region filter. 3. If a filter exists, apply it and wait for results. 4. If no filter, scroll through every holding row. 5. For each row, read the country field or tag. 6. If the country is China, copy the weight shown. 7. Continue until the end of the page. 8. Add all copied weights together. 9. If no China holdings were found, note that no exposure was detected.
