---
name: build-shot-list
description: Turn script topics into a B-roll shot list.
---

1. Open the script file using file_read. 2. List each topic or paragraph in the order it appears. 3. For each topic, use web_search to find stock footage, video clips, or visual ideas that match. 4. Write one sentence per topic describing a suitable B-roll shot or noting if no good match exists. 5. Use make_page to create a new document titled 'B-roll shot list' and paste the list into it. 6. Show the finished page to the person.
