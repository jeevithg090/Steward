description: After at least two entries, make a table of sleep ratings versus habits. List each date, the sleep score, and the habit noted. If fewer than two entries exist, say how many days have been recorded and ask if they want to continue.
---

1. Use memory_remember to list all past sleep entries. 2. If there are fewer than two entries, say how many days are recorded and ask if they want to keep going. 3. If there are two or more, make a table with three columns: Date, Sleep (1-5), Habit. 4. Show the table using make_page. 5. If a date has no habit, write 'no habit noted' in the Habit column.
