# LinkedIn thought posts
Turns bullet points into five polished LinkedIn posts with links between them.

**What it does:** Reads your bullet-point file, writes five posts, and creates a summary page with links.
**What it needs:** A file with bullet points, and the tools file_read, file_write, make_page.
**What it will not do:** It will not post to LinkedIn without your say-so, and it will not invent facts or statistics.
