# Story poll generator
Creates 30 poll questions from a topic for social audience research.

**What it does:** Writes 30 neutral, short poll questions about a given topic and saves them as a text file plus a simple web page.

**Needs:** The `file_write` and `make_page` tools. No connectors are required.

**Will not:** Ask the person to pay, send messages, or sign anything. It will not guess facts or prices.
