---
name: extract-achievements
description: Pull key results and skills from a single document.
---

1. Read the document with file_read. 2. Scan for sentences with numbers, percentages, or words like 'achieved', 'led', 'increased'. 3. Write each as a bullet: what was done, using which skill, and the result. 4. If the document has no such sentences, say so and ask the person to tell you the points manually.
