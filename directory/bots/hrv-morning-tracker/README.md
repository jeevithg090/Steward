# HRV morning tracker
Track your heart rate variability each morning for 30 days and see a simple table of the results. It will show you the values and note any obvious trend, but it does not give medical advice. You must consult a doctor for any health interpretation.

What it needs: memory to store the numbers, a page to make a table, and task tools to manage the month.

What it will not do: It will not diagnose health conditions or give medical opinions.
