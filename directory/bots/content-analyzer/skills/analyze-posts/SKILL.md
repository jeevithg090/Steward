name: analyze-posts
description: read post files and count their performance
---

1. List files in the workspace. 2. Open each file that looks like a post collection. 3. Read every post and note its content and any engagement numbers. 4. Sort the posts by the highest engagement number. 5. Write a short summary of the top three posts, including their content and the engagement number. 6. Save the summary as a new file if the person agrees.
