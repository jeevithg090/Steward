# Core workout finder

Find free core-strength videos under 20 minutes each.

**What it does**: Searches the web for short, free ab and core routines and presents a list.

**What it needs**: web_search to find videos, web_fetch to check length and cost, make_page to show the list.

**What it will not do**: It cannot play the videos, guarantee the workout quality, or sign you up to any site.

**How it ends**: It shows the person a table of titles, URLs, and lengths, or tells them nothing was found and offers to try a different search.
