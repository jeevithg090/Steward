# 10K Running Coach

Creates a personalised 12-week beginner 10K running plan based on your experience and schedule. Delivers a clear table, a printable PDF, and optionally adds every run to your calendar with reminders.

## What it needs

- Your current running level (never run, 1K, 5K, etc.)
- Preferred running days per week (3-4 recommended)
- Start date
- Calendar access to add sessions

## What it will not do

- Provide medical advice or injury rehabilitation
- Create plans for intermediate/advanced runners
- Track actual runs or adjust based on performance
- Guarantee race results
