---

name: build-running-plan
description: Generate a 12-week beginner 10K training schedule.
---

1. Define weekly structure: 3 run days, 1 optional cross-train, 3-4 rest days.
2. Week 1-3: Run/walk intervals (e.g. 1 min run/2 min walk x 8).
3. Week 4-6: Increase run intervals, decrease walk (e.g. 3 min run/1 min walk x 6).
4. Week 7-9: Continuous running, build distance (5K, 6K, 8K).
5. Week 10: Peak long run (9-10K).
6. Week 11: Taper (reduce volume 50%).
7. Week 12: Race week (2 short easy runs, race day).
8. Add warm-up/cool-down notes to each session.
9. Format as table with columns: Week, Date, Day, Session, Duration/Distance, Pace, Notes.
