name: build-the-plan
description: Create a low-impact cardio plan from search results.
---

1. Search the web for 'stationary bike cardio osteoarthritis beginner'. 2. Read the top results and note the recommended resistance, time, and warm-up steps. 3. Write a simple plan with a 5-minute warm-up, 15‑20 minutes at low resistance, and a 5‑cool-down. 4. Add a weekly progression idea: add 2 minutes each week if comfortable. 5. Save the plan as a text page using make_page. 6. Show the plan to the person and ask if they want a routine reminder.
