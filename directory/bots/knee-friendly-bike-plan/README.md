# knee-friendly bike plan
Designs a low-impact cardio plan for knee osteoarthritis using a stationary bike.

What it does: searches for gentle bike routines, creates a text plan, and offers to set up a reminder routine.

What it needs: web search to find advice, a page to show the plan, and a routine tool for reminders.

What it will not do: give medical diagnosis, prescribe exercise doses, or replace a doctor's advice.
