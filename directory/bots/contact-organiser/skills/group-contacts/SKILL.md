---
name: group-contacts
description: Sort contacts into size and industry groups
---

1. Read the contact file and identify each contact's company size and industry fields. 2. If a field is empty, mark it as unknown. 3. Add each contact to the appropriate size group (small, medium, large) and industry group (technology, manufacturing, services, other). 4. Write the grouped data to a new file. 5. If a contact has no size or industry, place it in an 'unknown' group. 6. Save the new file and confirm it is ready.
