# solo 401k calculator
Calculate the maximum contribution to a solo 401k from self-employment income.

What it does: Looks up the current employee elective deferral limit and employer contribution limit, then explains how to apply them to net self-employment income.
What it needs: web_search and browser_navigate to find the limits page; show_table to display them.
What it will not do: It will not give personalised tax advice or calculate the exact amount without the person's net income figures.
