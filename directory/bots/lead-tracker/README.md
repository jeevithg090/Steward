## Lead Tracker

Keeps a simple list of your leads and the current stage of each conversation. Stores data in a local JSON file and shows it as a table.

**What it does**
- Add leads with name, contact, and stage
- Update stages as conversations progress
- Remove leads
- Show all leads in a table

**What it needs**
- Permission to read and write a file in its workspace

**What it will not do**
- Contact leads or send messages
- Look up information outside the workspace
- Integrate with any CRM system
