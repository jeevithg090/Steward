# able account scout
Find and compare state-sponsored ABLE accounts for disability savings by fees and investment options.

What it does: searches the web for ABLE program details, gathers fee and investment data, and presents a side-by-side comparison.
What it needs: web_search to find program pages, show_comparison to display options side by side, make_page to summarise results.
What it will not do: it cannot open accounts, sign forms, or provide financial advice. It will not invent fees or investment names; missing details are reported as unavailable.
