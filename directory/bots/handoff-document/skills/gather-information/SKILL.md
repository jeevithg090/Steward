---
name: gather-information
description: Collect calendar events and mail messages about projects and deadlines.
---

1. Use calendar_list to get all events during the vacation dates. 2. Use mail_read to look for messages with subjects about projects, contacts, or deadlines. 3. For each event or message, note the project name, the person responsible, and the due date. 4. If calendar_list or mail_read returns no results, note that nothing was found for that step and continue. 5. Repeat until all relevant items are collected.
