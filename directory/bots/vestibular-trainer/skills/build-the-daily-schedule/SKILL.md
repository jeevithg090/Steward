---
name: build-the-daily-schedule
description: Organise the collected exercises into a 4-week progressive home program.
---

1. Open a new page with make_page titled 'Vestibular Balance Program'. 2. Create a 4-week structure with weekly progression. 3. For each day, list the exercise name, a brief description, recommended repetitions, and a note on how the difficulty increases that week. 4. Include a safety section advising the person to stop if dizziness worsens and to consult a healthcare professional. 5. When the layout is complete, write the full program text to 'vestibular_program.txt' using file_write.
