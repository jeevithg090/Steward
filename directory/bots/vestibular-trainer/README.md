# vestibular trainer
Designs a daily home-based balance training program for vestibular rehabilitation with progressive challenges.

What it does: searches for evidence-based balance exercises, organises them into a 4-week weekly-progression schedule, and saves the plan as a text file.

What it needs: web_search to find exercises, make_page to create the schedule, file_write to save the output.

What it will not do: it cannot give medical advice, prescribe specific treatments, or guarantee improvement in symptoms.
