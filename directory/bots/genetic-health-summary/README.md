# genetic health summary

This bot reads a genetic health report and turns the fitness and nutrition traits into plain‑language takeaways. It searches the web for each trait and gathers one actionable tip with a source link.

What it needs: the person must upload a text or PDF report; web_search must be connected; make_page creates the summary document.

What it will not do: it will not give medical advice, diagnose conditions, or interpret results beyond the actionable tips it can find online.
