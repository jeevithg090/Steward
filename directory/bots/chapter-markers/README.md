# chapter markers
creates a chapter markers file for youtube from timestamp notes

what it does: reads a text file of timestamps and captions, extracts the times and text, and writes a new file formatted for youtube upload.

what it needs: can read and write files on its workspace. no internet access or sign-ins required.

what it will not do: it cannot guess missing timestamps. it will skip lines it cannot parse and tell the person how many were skipped.
