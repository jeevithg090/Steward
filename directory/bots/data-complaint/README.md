# data complaint
Write and submit a formal complaint to a data protection authority about a company.

What it does: Searches for the correct authority, gathers submission requirements, and creates a draft complaint template.

What it needs: web_search, web_fetch, make_page, file_write.

What it will not do: It will not submit the complaint without the person's confirmation, and it will not give legal advice or guarantee the complaint will be accepted.
