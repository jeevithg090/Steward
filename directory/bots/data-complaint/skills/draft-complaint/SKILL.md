---
name: draft-complaint
description: Create a formal complaint template for a data protection authority.
---

1. Search the web for the data protection authority responsible for the company's region. 2. Fetch the authority's complaint form or submission requirements. 3. Make a page with a title 'Formal complaint about [company]' and sections for the complainant's name, contact details, a description of the issue, and the impact caused. 4. Include placeholders such as [COMPANY NAME], [YOUR NAME], [DATE OF INCIDENT], and [DESCRIPTION OF BREACH]. 5. Save the page as a draft text file for the person to review.
