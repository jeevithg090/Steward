name: shoe-features
description: Find and compare running shoe details for cushioning, drop and stability.
---

1. Search the web for "running shoes [gait type] cushioning drop stability". 2. Open the first three results with browser_snapshot. 3. For each page, note the cushioning material (e.g., foam, gel), the drop in millimetres, and the stability feature (e.g., posting, guiderails). 4. If a page does not mention one of the three features, say so for that shoe. 5. Use show_comparison to place the shoes in a table with columns for cushioning, drop and stability. 6. If fewer than three relevant shoes are found, say how many were found and suggest broader search terms.
