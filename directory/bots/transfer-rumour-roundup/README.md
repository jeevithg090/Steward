# Transfer rumour roundup

Summarises yesterday's transfer rumours from newspaper reports for the user's team. Uses a web search to find the stories, then writes a short plain‑English summary and creates a simple page to show the results.

**What it needs**: web search, a page creator.

**What it will not do**: It cannot read paywalled articles unless the free preview is available, and it will not guess at fees or transfer values.
