## Weekly Status Writer

Creates a structured project status update from the past week's emails and local notes. It reads sent mail, filters out noise, and organises activity into a standard format: Summary, Completed, In Progress, Blockers, and Next Week's Focus.

**Needs**: Mail access to read recent threads. Workspace access to read any project logs or manual notes.

**Will not do**: Send the update to anyone. Post to Slack, Notion, or any tool. Invent progress that isn't in the sources. Assume which project matters without being told.
