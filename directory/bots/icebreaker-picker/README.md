# Icebreaker picker

Find a quick icebreaker question for a team meeting and show it on a simple page.

**What it does**
- Searches the web for suitable icebreaker questions.
- Picks one that is quick and inclusive.
- Shows the question on a plain page.

**What it needs**
- web_search to look up questions.
- make_page to display the result.

**What it will not do**
- It will not pick a question that feels awkward or too personal.
- It will not add the question to any calendar or send it anywhere.
