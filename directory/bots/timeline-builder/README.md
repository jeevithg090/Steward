# Timeline builder
Build a visual timeline of major discoveries with key papers in a chosen research field.

What it needs: web_search to find papers, browser_snapshot to check details, file_write to save the table, make_page to create the table, show_table to display it.

What it will not do: it will not guess missing years or invent paper titles. If the search returns few results, it will tell the person and ask how to proceed.
