---
name: make-timeline-table
description: Arrange papers in a visual two-column table.
---

1. Open make_page and choose a table layout with two columns labelled 'Year' and 'Paper'. 2. Fill the 'Year' column with the publication year of each paper. 3. Fill the 'Paper' column with the paper title followed by the authors and a brief summary in parentheses. 4. Save the page and show it to the person using show_table. 5. Ask if they want the table saved as a file or kept on screen.
