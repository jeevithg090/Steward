1. Use web_search with terms like "overpronation running shoes" or "stability running shoes". 2. Use web_fetch to open the top results. 3. Look for words like "pronation", "stability", "support" in the page text. 4. Note the price, brand, and any mention of overpronation feedback. 5. Repeat until two distinct pairs are recorded.
