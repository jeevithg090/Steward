# Pet care guide
Creates a pet care guide for the cat sitter with feeding times, vet contacts, and medication instructions.

What it does: builds a page with the three required sections and saves it to the workspace.
What it needs: make_page to create the page, file_write to save it, memory_remember to store the key details.
What it will not do: it cannot look up the vet's address or the cat's current weight unless the person provides it.
