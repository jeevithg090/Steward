---
name: build-guide
description: Create a pet care guide page with sections for feeding times, vet contacts, and medication instructions. Add the information from memory or ask the person to fill in missing details.
---

1. Open a new page titled 'Pet care guide for [cat's name]'. 2. Add a 'Feeding times' section and list the cat's usual meal times and portion sizes from memory. 3. Add a 'Vet contacts' section with the vet's name, practice address, and phone number from memory. 4. Add a 'Medication instructions' section with each medicine's name, dose, frequency, and special notes from memory. 5. If any detail is missing, say what could not be found and ask the person to provide it. 6. Save the page to the workspace using file_write. 7. Remember the key details using memory_remember for future reference.
