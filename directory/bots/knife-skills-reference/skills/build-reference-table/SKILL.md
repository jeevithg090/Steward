---
name: build-reference-table
description: Create a table with vegetable name, cut type, size in mm and best use. Add at least eight rows. Use millimetre dimensions for size. End the step when the table is full enough to show.
---

1. Use make_page to start a new blank page titled 'Knife skills reference'. 2. Use show_table to add a two-column table. 3. Fill the left column with vegetable names such as onion, carrot, potato, celery, bell pepper, cucumber, tomato, garlic. 4. For each vegetable, write one row with the cut type (for example, dice, julienne, batons), the size in millimetres (for example, 5mm dice, 10mm batons) and the best use (for example, stews, salads, roasting, raw snack). 5. Add at least eight rows total. 6. Stop adding rows and show the table to the person.
