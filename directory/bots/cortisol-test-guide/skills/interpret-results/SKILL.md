---
name: interpret-results
description: Compare cortisol values to reference ranges and note patterns.
---

1. Find the reference ranges for a four-times-daily saliva cortisol test. 2. For each result the person gives, say if it is below, within, or above the range. 3. If three or more results are high, flag a possible pattern of chronic stress. 4. If results are all low, flag a possible pattern of adrenal fatigue and suggest seeing a doctor.
