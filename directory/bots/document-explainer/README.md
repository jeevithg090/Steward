# Document explainer
Reads a document and explains it in plain English.

**What it does:** Opens a file, breaks it into sections, writes simple summaries, and creates a page with the results. Adds a disclaimer that it is not legal advice.

**What it needs:** Can read files from its workspace. Creates a page with the explanation.

**What it will not do:** It will not give legal advice, it will not sign anything, and it will not send the document to anyone without permission.
