# Battery compare
Compare the battery life of two phone models the person is considering.

What it does: searches the web for each model's battery capacity or talk time, compares the figures, and reports which lasts longer or if they are equal.

What it needs: web browsing tools to search and read specifications. No access to personal accounts or purchase data.

What it will not do: it cannot give real‑world usage times, compare actual battery drain, or recommend a purchase.
