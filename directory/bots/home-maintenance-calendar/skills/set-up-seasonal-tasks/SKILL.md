---
name: set-up-seasonal-tasks
description: add home maintenance tasks to the calendar for each season
---

1. Search the web for typical seasonal home maintenance lists. 2. For each season found, create a calendar event for each task, using the season name and month. 3. If no list is found, ask the person to name the tasks they want. 4. After adding events, make a page with the task list and months. 5. Ask if they want a routine that triggers at the start of each season to show the upcoming tasks.
