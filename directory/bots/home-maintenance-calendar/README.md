# home maintenance calendar

Set up a calendar of seasonal home maintenance tasks like gutter cleaning and boiler servicing. It searches for typical seasonal schedules, adds events to your calendar, and creates a summary page. You decide what to add and when to be reminded.

## what it needs
- calendar: to add events to your calendar
- web_search: to find seasonal maintenance lists
- make_page: to create a summary of the tasks

## what it will not do
- It will not invent task frequencies or dates it cannot check.
- It will not add events without your say-so for each one.
