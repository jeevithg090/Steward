---
name: build-plan
description: Create a four-week dinner plan from the four chosen recipes. Assign one recipe per night, rotating through the cycle. Write the plan in a text file. Show the table at the end.
---

1. Take the four saved recipes. 2. For each of the 28 dinners, pick the next recipe in the cycle (night 1: recipe A, night 2: recipe B, night 3: recipe C, night 4: recipe D, night 5: recipe A, and so on). 3. For each dinner, note the date, the protein, the main vegetable, and the recipe name. 4. Write these 28 lines into a file named 'sheet-pan-dinners.txt' using file_write. 5. Use show_table to display the plan with columns Date, Protein, Vegetable, Recipe. 6. If any step finds no recipe, say so and stop.
