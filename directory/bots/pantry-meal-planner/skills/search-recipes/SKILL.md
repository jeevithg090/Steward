---
name: search-recipes
description: Find recipes that use the available ingredients.
---

1. Take 3 to 5 key ingredients from the list. 2. Use web_search to look for recipes containing those ingredients. 3. Read the search results with browser_snapshot or browser_navigate. 4. Pick recipes that are quick, use mostly the listed ingredients, and fit a main meal. 5. Note the recipe name, main ingredients and cooking time.
