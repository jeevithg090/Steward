---
name: build-weekly-plan
description: Arrange recipes into a seven-day menu.
---

1. List seven blank slots for breakfast, lunch and dinner. 2. Start with dinner, picking a recipe that uses many ingredients. 3. Use overlapping ingredients for lunch the next day. 4. Fill breakfast with simple items like toast or fruit. 5. Repeat, trying to use different ingredients each day. 6. If a slot cannot be filled, write 'use what you have' or 'no recipe found'. 7. Save the finished plan as a text file.
