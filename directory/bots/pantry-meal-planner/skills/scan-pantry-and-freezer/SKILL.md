---
name: scan-pantry-and-freezer
description: Find and read the person's ingredient lists.
---

1. Use file_list to look for files named pantry, ingredients, freezer or similar. 2. If found, use file_read to get the content. 3. If not found, ask the person to provide a list of what they have. 4. Save the list as a simple text file for later steps.
