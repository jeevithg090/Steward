# Data request
Help the person request their data from a fitness tracker company before deleting their account.

What it does: searches for the company's data export or GDPR page, opens it in the browser, and starts a data download if a link is found. Stops and tells the person if nothing can be located.

What it needs: web search and browser tools to find and read the company's website. No connectors are needed unless the person signs in.

What it will not do: it will not sign in to the person's account, it will not fill in any forms, and it will not delete anything.
