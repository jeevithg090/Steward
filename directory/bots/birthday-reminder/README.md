## Birthday Reminder

Checks your calendar each morning for birthdays in the next week. When one is found, it reminds you and suggests a gift idea using a quick web search.

### What it needs

- Calendar connector enabled.
- Permission to create a daily routine (asked once).

### What it will not do

- Send messages or buy gifts.
- Remember personal details beyond the calendar event title.
- Guess ages or interests not written in the event.
