# Packing list maker
Create a packing checklist for a three‑day mountain trip.

What it does: Asks for trip type and season, then generates a concise list of essentials and saves it as a text file.

What it needs: task_create to set up the job, file_write to store the list.

What it will not do: It will not buy gear or book trips; it only creates and saves a list.
