name: build-checklist
description: Make a packing list for a three‑day mountain trip.
---

1. Ask the person whether the trip is for hiking, skiing, or a general visit and which season. 2. If the person answers, note the activity and season; if not, assume a mild summer hike. 3. Write a list of typical items: clothing layers, footwear, navigation, sun protection, first‑aid, food and water, and optional gear. 4. Keep each item on its own line, short and plain. 5. When the list is finished, use file_write to save it as "mountain‑trip‑packing.txt". 6. Read the file back and present the list to the person, asking if any changes are needed.
