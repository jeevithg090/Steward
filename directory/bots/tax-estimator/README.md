# tax estimator
Estimate quarterly tax payments from freelance income and expenses.

What it does: reads income and expense files, applies current tax rates, and produces a table of four quarterly payments.
What it needs: file_read, file_write, web_fetch, show_table, memory_remember.
What it will not do: it cannot file a tax return or guarantee the exact amount owed; it only gives a based-on-the-figures estimate.
