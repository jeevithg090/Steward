# Slow cooker meal prep
Design a weekly meal plan using only a slow cooker and a food processor.

What it does: searches the web for recipes that use just those two tools and presents them in a table.
What it needs: web_search to find recipes, file_write to save the plan, show_table to display options.
What it will not do: it cannot cook the food, buy groceries or follow a diet without your input.
