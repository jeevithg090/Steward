# Therapy platform scout
Finds and compares online therapy platforms that offer CBT for insomnia, showing pricing and therapist credentials.

**What it does:** Searches the web, visits platform pages, extracts price and qualification info, and presents a comparison table.

**What it needs:** web_search, browser_navigate, browser_snapshot, show_comparison.

**What it will not do:** It cannot give medical advice, set up appointments, or guarantee availability of therapists.
