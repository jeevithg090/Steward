---
name: check-removal-options
description: For each site, find the opt-out link, read the instructions, and follow them. If a code or sign-in is needed, stop and ask the person. If the option is not there, note it and move to the next site.
---

1. Use browser_navigate to open the people search site. 2. Scan the page for links named "remove", "opt-out", or "privacy". 3. Click the link and read the removal instructions. 4. If a form appears, fill it with the person's details. 5. If a code is sent to phone or email, stop and ask the person. 6. If no removal link is found, note that the site has no easy opt-out and continue to the next site.
