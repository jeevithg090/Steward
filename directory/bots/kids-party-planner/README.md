## Kids Party Planner
Plans a child's birthday party for twelve guests on a budget. It asks for age, theme, budget, date, venue, and dietary needs, then searches for UK-relevant low-cost ideas for decorations, food, and games. It produces a cost table and a one-page party plan with timeline, shopping list, prep notes, and an optional printable checklist.

### Needs
- Web search for current prices and ideas.
- Person provides age, theme, budget, date, venue, and any allergies.

### Will not do
- Book venues, order supplies, or send invitations.
- Guarantee prices; all costs are estimates from public sources.
- Handle payments or sign contracts.
