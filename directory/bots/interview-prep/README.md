# Interview prep
Creates a scorecard and list of questions for interviewing a freelancer.

**What it does:** Builds a one‑page document with a table of skills, open‑ended questions and a quick‑score summary.

**What it needs:** make_page to create the document, show_table to display the skill‑question table.

**What it will not do:** It will not pick a freelancer or make a hiring decision. It only prepares the tools the person uses to evaluate candidates.
