---
name: lookup-revenue-by-region
description: Find revenue breakdown by region for each symbol on a financial data site.
---

1. For each symbol, use web_search to find a financial data page showing revenue by region. 2. Use browser_navigate to open the page. 3. Use browser_snapshot to read the revenue breakdown. 4. If the page does not show regional data, note that data is unavailable for that symbol. 5. Record the region and revenue share found, or the fact that no data was available.
