---

name: learn-voice
description: Read writing samples and store voice traits for later caption writing.
---

1. Ask the person for files or folders containing their past writing (notes, journals, old captions, messages).
2. Use file_read to open each file.
3. Extract patterns: average sentence length, common contractions, favourite adjectives, typical opening words, humour style, topics they return to.
4. Use memory_remember to save these traits under keys like 'voice.sentence_length', 'voice.contractions', 'voice.topics', 'voice.avoid'.
5. Confirm with the person: 'I've noted your voice tends to be [summary]. Shall I use this for captions?'
