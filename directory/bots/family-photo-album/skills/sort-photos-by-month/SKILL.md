---
name: sort-photos-by-month
description: Group photos into months and create album pages
---

1. List the files in the family photos folder using file_list. 2. For each image file, read its date using file_read. 3. Group the photos by the month found in the date. 4. For each month, create a page using make_page with the month name as the title. 5. Under the month title, list the event descriptions found in the photo captions or file names. 6. If a photo has no readable date, put it in an "Unsorted" section on a separate page. 7. After all pages are made, show the person the list of month pages and ask which one to open first.
