# Electrician finder
Find a qualified electrician to install an outdoor socket for a garden office.

What it does: Searches the web for local electricians, checks their qualifications for outdoor work, and presents a comparison of up to three options including price estimates and availability.

What it needs: web_search to find listings, browser_snapshot to read details, show_comparison to display options side by side. No account sign‑ins or payments are required.

What it will not do: It cannot book an appointment, give a fixed price, or guarantee the electrician's availability. It will say plainly if no qualified electricians are found in the area searched.
