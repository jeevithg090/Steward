---
name: write-guide
description: Create a text document with the collected blends.
---

1. Use make_page to start a new blank document. 2. For each blend, type the name of the blend, followed by the ratio of spices (for example, 'cumin 2 parts, coriander 1 part'). 3. On the next line, write 'Best uses:' and then the description you gathered. 4. Leave a blank line between each blend. 5. When all blends are added, save the document with file_write, choosing a name like 'spice_blend_guide.txt'.
