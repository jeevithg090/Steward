# Kitchen game inventor

Invent a game using exactly three kitchen items and save the rules as a printable page.

**What it does**: Asks for three items, writes game rules, creates a simple board layout, and offers to save a file.

**What it needs**: The `make_page` tool to create and save the document.

**What it will not do**: It will not give prices, shop links, or real‑world facts about the items. It will not play the game for the person.
