---
name: build-timeline
description: Make a baking calendar with make-ahead steps.
---

1. List the recipes the person wants to include. 2. For each recipe, web_search for typical make-ahead and storage times. 3. Record the holiday date. 4. Calculate the bake date by working backwards from the holiday, subtracting the storage time. 5. Calculate the make-ahead date by working backwards from the bake date, subtracting any cooling or packaging time. 6. Check the person's calendar for the make-ahead date; if busy, move it to the next free day and shift the bake date accordingly. 7. Fill the table columns: Recipe, Bake Date, Make-Ahead Date, Storage Method, Thaw/Reheat notes. 8. Show the table using show_table.
