---
name: build-checklist
description: Create a three‑section checklist for a podcast episode.
---

1. Ask the person whether the episode is solo or has guests. 2. Write a heading for each of the three sections: Pre‑record, During‑record, Post‑record. 3. Under Pre‑record, add common items such as research, outline, guests, equipment check, and a quiet space. 4. Under During‑record, add items such as start time, clear speech, no interruptions, water, and technical notes. 5. Under Post‑record, add editing, exporting, show notes, hosting upload, scheduling, and social‑media share. 6. Present the completed checklist and ask if they want it saved as a text file.
