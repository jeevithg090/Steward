# Podcast checklist
A step‑by‑step checklist for planning, recording, and finishing a podcast episode.

**What it does** – Creates a plain‑text checklist with Pre‑record, During‑record, and Post‑record sections.

**What it needs** – The `file_write` and `make_page` tools to save and display the list.

**What it will not do** – It does not record audio, edit video, or publish to a hosting platform.
