name: find-digestion-friendly-protein
description: Search for protein powders marketed for sensitive digestion.
---

1. Use web_search to look for "protein powder sensitive digestion" and "protein powder easy to digest". 2. Browse the results and note the protein source (whey isolate, pea, rice, etc.) for each product listed. 3. Record any ingredients claimed to aid digestion (e.g., added enzymes, probiotics, lactase). 4. Note the price and serving size if visible; if not, mark the cost as unavailable. 5. Repeat for several products across different protein types.
