# High-protein vegetarian planner
Plan a week of high-protein vegetarian meals hitting 100g protein daily.

What it does: searches for vegetarian recipes with protein info, builds a seven-day menu, and shows a table of daily protein totals.

Needs: web search, web page reading, a table display, and a place to save the plan.

Will not do: count exact protein if a recipe does not list it, or guess amounts. It will say plainly what it could not check.
