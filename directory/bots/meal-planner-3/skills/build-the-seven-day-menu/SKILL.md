---
name: build-the-seven-day-menu
description: Assign the collected recipes to seven days, aiming for about 100g protein each day. If a day has too little protein, swap in a higher-protein recipe. If there are not enough recipes, tell the person and stop.
---

1. Open the saved recipe list. 2. Pick two recipes for day one and add their protein amounts. 3. If the total is below 80g, add a third recipe. 4. Repeat for days two through seven. 5. If any day falls short after using all saved recipes, say so and ask whether to search for more.
