# research ethics scanner
Find and compare ethics approval requirements for research across different jurisdictions.

What it does: searches the web for official guidance in each jurisdiction, reads the key requirements, and presents a comparison table of steps, documents, and processing times.
What it needs: web search and browser tools to find and read pages; file write to save notes; show comparison to display the table.
What it will not do: it cannot guarantee the information is up to date or provide legal advice. It will say clearly if a jurisdiction's requirements could not be found online.
