# Card game designer

Designs a two-player card game using a standard 52-card deck and a sand timer. Outputs the rules, setup, and a description of play.

## What it needs
- make_page tool to create the game rules page.

## What it will not do
- It will not play the game for the person or keep score. It only writes the rules.
- It will not invent card designs or artwork; only uses the standard deck.
