---
name: gather-insurance-data
description: Search for average long-term care insurance premiums by age and region. Open a few quote pages, extract the monthly cost, and note the coverage limits. If no region-specific data is found, use national averages and tell the person.
---

1. Use web_search with the query "long term care insurance premiums by age". 2. Browse the top results with browser_navigate. 3. Use browser_snapshot to read the monthly premium for a policy matching the person's age. 4. If the page does not show a price, note that and try another source. 5. Record the premium and any conditions found.
