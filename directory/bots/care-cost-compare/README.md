# care cost compare

Compare the cost of long-term care insurance with self-funding using a dedicated investment account.

What it does: Gathers average insurance premiums and investment return data, then shows a side-by-side comparison of total premiums paid versus the investment lump sum needed for the same coverage period.

What it needs: web_search, browser_navigate, browser_snapshot, show_comparison, make_page.

What it will not do: It will not give personal financial advice, quote guaranteed prices, or calculate exact future values. It always tells the person the assumptions used and recommends consulting a qualified financial adviser before making a decision.
