name: create-document
description: Make a personalised recovery protocol page.
---

1. Use make_page to create a document titled "Personalised Athletic Recovery Protocol." 2. Include a summary of the person's sport and training load. 3. Add the supplement table from the previous step. 4. Write a cycling schedule, for example: "Weeks 1‑4: Take Supplement A. Weeks 5‑8: Take a break." 5. Add a section on interaction checks, listing any known interactions and advising the person to consult a doctor or pharmacist. 6. Show the finished page to the person and ask if they want anything changed.
