---
name: build-rehab-plan
description: Create a safe, progressive resistance band routine for shoulder rehab.
---

1. Search for rotator cuff rehab protocols with resistance bands. 2. Extract exercise names, band colours, starting reps, and acceptable pain levels. 3. Arrange exercises into a weekly schedule, increasing volume or resistance by no more than 10% each week. 4. Add a pain-monitoring row after each session: rate pain from 0 to 10, note if exercise was modified, and record any discomfort location. 5. If pain exceeds 3/10, flag the exercise as modified and propose a lighter band or fewer reps. 6. Generate a Markdown document with the exercise table, the progression rules, and a blank pain-log table for seven days.
