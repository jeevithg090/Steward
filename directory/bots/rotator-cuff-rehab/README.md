# rotator cuff rehab
Design a progressive resistance band program for rotator cuff rehabilitation with daily pain tracking.

What it does: builds a safe, weekly exercise plan with pain-monitoring tables and progression rules based on evidence-based protocols.

What it needs: web search to find rehab protocols, a page creator to format the plan, and a file writer to save the output.

What it will not do: give medical advice beyond exercise progression; diagnose injuries; or replace a physiotherapist's guidance.
