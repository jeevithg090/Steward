---
name: find-and-pick-icebreakers
description: Search the web for icebreaker games that take about five minutes. Read the results and choose three that are easy to run. Write each game's name, a short description and the time needed.
---

1. Use web_search to look for 'five minute icebreaker games'. 2. Read the results with browser_snapshot or web_fetch. 3. Pick three games that have clear, simple instructions. 4. Make a list with the game name, a one‑sentence description and '5 minutes' for each. 5. Use make_page to save the list as a text page. 6. Show the page to the person and ask if they want to keep it or pick different games.
