# Cheaper subscription finder

Review all subscription services and find lower rates or free alternatives for each.

What it does: searches the web for current pricing and cheaper or free options for every service the person uses. Shows a summary page with the best rate found for each.

What it needs: web search and browsing to find pricing; no access to bank or payment accounts.

What it will not do: it will not change any subscription, cancel anything, or pay for a new plan. It only finds information and presents it.
