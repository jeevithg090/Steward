name: find-alternatives
description: For each subscription, search the web for lower prices or free versions. Note the service name, the new price, and a link to the offer. If no cheaper option exists, write that the current plan stays. Keep the list short and factual.
---

1. Search the web for the service name plus 'discount' or 'free alternative'. 2. If a cheaper plan appears, record its price and URL. 3. If only the full price appears, write that no cheaper option was found. 4. Repeat for each service the person lists.
