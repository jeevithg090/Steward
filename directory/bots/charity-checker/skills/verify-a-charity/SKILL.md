---

1. Search the web for the charity name and "scam" or "legitimate".
2. Read the search results for official registration numbers or news.
3. If a website appears, browse it and look for a physical address, registration number, and https.
4. Check for warnings on consumer-protection sites.
5. If nothing clear is found, tell the person what could not be verified and ask if they have a specific source.
