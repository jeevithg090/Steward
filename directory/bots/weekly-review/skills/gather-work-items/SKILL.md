---
name: gather-work-items
description: Find finished and slipped items from mail and calendar
---

1. Use mail_list to get all emails from the last 7 days. 2. Scan subject lines and body for words like "finished", "done", "completed", "shipped" or project names. 3. Add each item to the "Finished" list. 4. Use calendar_list to get all events from the last 7 days. 5. Look at event titles and descriptions for work done, meetings held or milestones reached. 6. Add each item to the "Finished" list. 7. For both mail and calendar, also note any tasks that have no update but were expected this week; add those to the "Slipped" list. 8. If a list is empty, write "Nothing found" under that heading.
