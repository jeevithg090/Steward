---
name: summarise-and-group-papers
description: Turn ten research papers into a themed outline.
---

1. List the file names of the ten papers in the workspace. 2. Open each file and read its abstract or introduction. 3. Write one sentence summarising the main claim or finding of each paper. 4. Read all summaries and identify common themes, methods, or gaps. 5. Arrange the themes into a logical order for a literature review. 6. Draft a Markdown outline with an introduction, a heading for each theme, and bullet points containing the paper summaries under the relevant theme. 7. Add a conclusion section that synthesises the overall state of the field. 8. If a paper cannot be read, add a note: "[Content of [filename] could not be checked]." 9. Return the completed Markdown outline to the person.
