---
name: summarise-call
description: Pull the memory of yesterday's call and list the agreed points.
---

1. Open the memory stored for yesterday's call. 2. Read the notes and list every point the person agreed to. 3. If the memory is empty, say 'I could not find notes from yesterday's call. Would you like to tell me the agreed points, or shall I write the email from scratch?' 4. When you have the points, write a draft with one sentence per point. 5. End with a polite sign-off. 6. Ask the person to confirm before sending.
