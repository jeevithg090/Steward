# Priority alignment email

Drafts a weekly priority alignment email to a manager based on the person's calendar and task list.

**What it needs**
- Calendar and mail connectors so it can read events and send email.
- Tools to list tasks and make a page for the draft.

**What it will not do**
- It will not send email without the person's go-ahead.
- It will not invent a manager name if one is not set.
