# Curriculum designer

Build a free self-study curriculum with quality resources for a new skill from scratch.

**What it does** – searches the web, picks good free resources, and creates a simple study list page.

**What it needs** – web_search, browser_snapshot, file_write, make_page, task_create.

**What it will not do** – it cannot sign up for sites, pay for courses, or create accounts on your behalf.
