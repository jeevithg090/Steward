---
name: find-base-times
description: Search the web for standard pressure‑cooker times at sea level.
---

1. Use `web_search` with the query "pressure cooker time [food] sea level". 2. Read the search results with `web_fetch`. 3. Extract the first reasonable time listed (usually minutes). 4. If no result, note "not found" and continue to the next food item.
