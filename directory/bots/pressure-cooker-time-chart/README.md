# Pressure cooker time chart

Creates a printable table of cooking times for beans, grains and tough cuts, adjusted for the altitude where the person cooks.

**What it needs**: `file_write`, `make_page`, `show_table`. No internet connectors are required beyond the initial web search for base times.

**What it will not do**: It will not look up specific recipes, give nutrition information, or adjust for pressure‑cooker model differences beyond the simple altitude rule.
