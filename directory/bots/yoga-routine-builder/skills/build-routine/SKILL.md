---
name: build-routine
description: Create a yoga routine from search results.
---

1. Search the web for "beginner yoga routine stress relief". 2. Read the top results and pick 5 to 8 simple poses. 3. Note the order and how long to hold each pose. 4. Use routine_create to save the routine with the pose list and times. 5. Make a page with make_page showing the routine title, the pose list, and total time. 6. Show the page to the person.
