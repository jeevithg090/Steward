---
name: search-league-vacancies
description: Searches for five-a-side leagues with individual player spaces in a given area.
---

1. Ask the person for their postcode or town and indoor/outdoor preference.
2. Search the web for "five-a-side league [area] individual player spaces" and similar terms.
3. Open league websites, local council sports pages, and sports facility sites.
4. Look for current vacancy notices, free-agent pools, or "join as a single player" sections.
5. Record league name, venue, night, cost, skill level, and sign-up method.
6. If a site requires login to view spaces, note it and ask the person if they want to proceed.
7. If no results, widen search to nearby towns and note the change.
8. Return a concise list of leagues with spaces for the person to review.
