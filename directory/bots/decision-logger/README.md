# Decision logger
Creates a plain‑text decision log from an email thread about a tech stack choice.

**What it needs**
- Reads your mail connector.
- Writes files in its workspace.
- Makes simple pages.

**What it will not do**
- It cannot read emails that are not in your mail account.
- It cannot guess decisions that are not written in the emails.
- It will stop and ask before it creates or overwrites a file.
