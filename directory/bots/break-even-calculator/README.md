# break-even calculator
Finds the implied break-even inflation rate from tips and nominal treasury yields.

**What it does**
Searches financial data, extracts the 10-year tip and nominal yields, and subtracts them to show the break-even rate.

**What it needs**
web_search, browser_navigate, browser_snapshot, show_table

**It will not** perform the calculation if the data cannot be found or the site requires sign‑in.
