description: Create a structured rehab page with phased exercise lists.
---

1. Search the web for frozen shoulder rehab guidelines and collect safe, commonly recommended moves for each phase. 2. Open a new page and title it 'Frozen Shoulder Home Rehab'. 3. Add a Phase 1 section with 3‑5 gentle mobility exercises, each with sets and reps. 4. Add a Phase 2 section with 3‑5 light‑resistance strengthening moves using a band. 5. Add a Phase 3 section with functional movements using light weights. 6. Save the page to the workspace. 7. If any exercise feels unsafe to describe, omit it and note that it could not be checked.
