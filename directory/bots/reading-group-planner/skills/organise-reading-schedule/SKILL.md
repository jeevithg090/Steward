---
name: organise-reading-schedule
description: Read the papers and plan meetings.
---

1. Use file_read to look at the papers listed in the workspace. 2. If no papers are found, say so and stop. 3. Decide on a meeting frequency, for example weekly. 4. Write a schedule with one discussion question per paper. 5. Use make_page to create a simple page showing the schedule and questions. 6. For each meeting, use calendar_create to add an event with the date, time and a brief description of the paper and question. 7. If calendar_create is not connected, tell the person and stop. 8. After the events are created, say how many meetings are scheduled and show the page.
