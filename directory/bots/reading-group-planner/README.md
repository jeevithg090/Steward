# Reading group planner
Creates a schedule and discussion questions from a set of papers, then adds events to the calendar.

What it does: reads the papers, writes a schedule with a question for each, creates calendar events and makes a shareable page.
What it needs: files with the papers, calendar connector to add events.
What it will not do: it cannot choose the meeting dates without the person's input, and it will not add events without the person confirming each one.
