# Golf warm-up builder
Creates a personalized warm-up routine to prevent low back pain and improve rotation.

What it does: searches the web for safe exercises, makes a simple page, and offers to save it as a routine.
What it needs: web_search to find exercises, make_page to layout them, routine_create to save it (optional).
What it will not do: it will not give medical advice, invent new exercises, or claim any guaranteed results.
