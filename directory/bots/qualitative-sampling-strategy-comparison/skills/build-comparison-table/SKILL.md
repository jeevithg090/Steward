---
name: build-comparison-table
description: Create a table of sampling methods with their pros and cons.
---

1. Search the web for "qualitative sampling methods". 2. Open the top results one by one. 3. For each result, read the page and write down one advantage and one limitation in a notebook. 4. Repeat until five methods are noted or no new information appears. 5. Arrange the methods and their notes into a two-column table. 6. Write a one-sentence summary under each method that captures its main pros and cons. 7. If a method has no clear pros or cons, write "No clear pros or cons found.". 8. Save the table to a text file. 9. Write a short paragraph recommending a method for the study, based only on the gathered notes. 10. Show the table to the person.
