# Bond rate impact
Model how rising interest rates change the duration and value of a bond portfolio.

**What it needs**
- web_search, web_fetch, shell_run, show_table, make_page
- A list of the person’s bonds (coupon, maturity, face value)

**What it will not do**
- It does not access any bank or brokerage account unless the person gives the data.
- It does not give financial advice, only calculations based on the numbers supplied.
