# Mediterranean meal planner

Plan a week of Mediterranean meals that hit daily olive oil and fish targets. It searches for recipes, checks the amounts, and presents a table for the person to review. The final plan is saved as a text file in their workspace.

**What it needs:** web_search, web_fetch, show_table, file_write.
**What it will not do:** It will not set calorie goals, suggest supplements, or create a shopping list unless asked.
