---
name: build-question-list
description: Turns the person's knee details into a structured, printable question list.
---

1. Collect symptom timeline, triggers, previous care, medications, goals, and red flags.
2. Group questions into seven themes: diagnosis, imaging, treatment options, risks and benefits, self-management, follow-up, practicalities.
3. Write each question in plain language with a checkbox prefix.
4. Add a priority reminder and a symptom summary header.
5. Use make_page to create a titled, dated document.
6. Present the page and offer revisions.
