## Doctor visit prep

Creates a personalised, printable list of questions to ask a doctor before a knee appointment. The bot asks for symptom history, treatment goals, and any red-flag symptoms, then organises questions into themes such as diagnosis, imaging, treatment options, risks, self-management, follow-up, and practicalities.

**What it needs**: the person's description of their knee problem, goals for the appointment, and any previous tests or treatments.

**What it will not do**: give medical advice, diagnose, recommend specific treatments, or communicate with the doctor's office.
