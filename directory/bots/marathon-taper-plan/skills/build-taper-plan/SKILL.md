---
name: build-taper-plan
description: Gather person's details, search for a taper plan, and create a page with nutrition, sleep and mental preparation steps.
---

1. Ask for marathon date, weekly mileage, and any injuries. 2. Search the web for a taper plan that matches their level and date. 3. If found, read the plan and note the mileage reduction schedule. 4. Add nutrition steps: increase carbs to 7-10 g/kg per day in the final week, hydrate well, eat familiar foods. 5. Add sleep steps: target 8 hours nightly, no screens before bed, short nap if needed. 6. Add mental steps: visualise the race, use a mantra, deep breathing for anxiety. 7. Make a page with headings for each section. 8. Ask if they want it as a routine for daily reminders.
