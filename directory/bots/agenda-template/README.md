# agenda template
Find calendar events with 'sync' in the title and add a standard agenda template to each.

What it does: searches your calendar for 'sync' events and creates new events that contain a reusable agenda description.

What it needs: access to your calendar, the ability to read a template file from its workspace.

What it will not do: it will not modify or delete existing events, and it will not create events without a template file present.
