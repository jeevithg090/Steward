# date-spreadsheet-to-calendar
Converts a spreadsheet of dates into a personal calendar feed.

What it does: reads a local spreadsheet file, finds dates in it, and creates calendar events for each one.

What it needs: access to read files in its workspace and add events to the person's calendar.

What it will not do: it will not guess dates, it will not create events without the person's say-so, and it will not touch any file that is not a spreadsheet in the workspace.
