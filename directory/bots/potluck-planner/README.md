# Potluck planner
Plan a menu where every dish serves 12 and travels well.

What it does: searches the web for recipes that feed 12 and have good travel feedback, then creates a simple table.

What it needs: web_search to find recipes, make_page to make a document, file_write to save it, show_table to display the results.

What it will not do: it will not cook the dishes, it will not check prices or availability, and it will not make any bookings.
