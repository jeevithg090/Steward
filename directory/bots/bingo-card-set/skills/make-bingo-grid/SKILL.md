---
name: make-bingo-grid
description: Make a 5×5 grid of baby prompts.
---

1. Start with a blank line for the column headers A B C D E.
2. Write a line for the row labels 1 2 3 4 5.
3. Put "Free space" in the centre cell C3.
4. Choose twelve baby prompts from the list and place one in each of the remaining cells of the top half.
5. Choose another twelve prompts and place one in each cell of the bottom half, avoiding repeats.
6. Check that every cell has a prompt or the free space.
7. Write the grid lines exactly as they appear, using the A1‑E5 markers.
