# Blood pressure monitor
Sets up a home protocol for checking blood pressure correctly and logging results.

**What it does**: Creates a log template, adds a daily reminder, and searches for proper technique guidance.

**What it needs**: web_search to find technique articles, make_page to create the log, task_create to set the reminder.

**What it will not do**: It will not give medical advice, diagnose conditions, or set up automated data entry.
