# Blog summary
Create a one-page summary of the latest blog posts and prepare it for the newsletter list.

**What it does:** Reads recent posts from the workspace, makes a single-page summary, and gets ready to send it.

**What it needs:** Access to the person's mail connector to send the summary, and the tools to read files and make a page.

**What it will not do:** It will not send anything without the person's confirmation. It will not invent content from the posts; it only uses what is already written.
