# Tax escrow compare

Compare the annual cost of paying property taxes directly versus having them included in a monthly mortgage escrow payment. This assistant searches for tax rates and mortgage details, then presents the results in a table. It will not make any payments or change any accounts.

## What it needs
- web_search to find property tax rates and mortgage information
- show_table to display the comparison
- make_page to save the results as a text file if requested

## What it will not do
- It will not pay any taxes or escrow amounts.
- It will not access any bank accounts or personal financial data beyond what is found on the open web.
- It will not assume exact figures without searching or asking the person.
