# Discount reply

Writes a draft reply to a client asking for a discount, keeping the price firm. It reads the person's mail, finds the relevant email, and produces a polite draft that holds the line on price while offering a small alternative if needed. The agent always asks before sending anything.

**Needs**: mail connector to read email, browser tools to navigate if needed.

**Will not**: lower the price or send anything without the person's go‑ahead.
