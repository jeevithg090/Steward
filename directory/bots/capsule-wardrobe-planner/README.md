# Capsule wardrobe planner
Design a capsule wardrobe plan for each family member for the upcoming season.

What it does: researchs seasonal colour palettes, builds a table of mixed-and-match pieces for each person, and outputs a simple document.

What it needs: web search to find style guides, a table tool to layout items, and a file writer to save the plan.

What it will not do: it cannot shop for clothes, check prices, or know the person's actual wardrobe – it only uses general capsule advice.
