---
name: build-person-table
description: Create a wardrobe table for one family member.
---

1. Ask the person for the member's age, lifestyle and favourite colours. 2. Using the shared palette, pick 3 tops, 2 bottoms, 1 layer, 1 shoe and 1 accessory. 3. Add each item to the show_table cells for that member. 4. When done, thank the person and ask if another member needs a table.
