# Swipe file designer

Create a template to save and organise winning competitor posts by format.

**What it does**: builds a markdown template or a set of templates for saving social media posts, with sections for URL, platform, date, engagement, and format-specific prompts.

**What it needs**: file_write and make_page tools.

**It will not**: create templates for formats the person does not specify; it cannot write files if the file_write tool is not connected.
