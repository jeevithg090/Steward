# Food diary analyzer

Analyzes a week of food entries to spot missing nutrients like fiber, iron, and omega-3s.

- Needs a food diary text file for the past 7 days.
- Searches the web for typical nutrient values of the foods listed.
- Shows a table of amounts found versus average daily targets.
- Will not invent nutrient values; it will say when a food could not be found.
- Cannot sign up for nutrition services or create accounts on external sites.
