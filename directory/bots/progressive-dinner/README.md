# progressive dinner
Plan a menu across three households, one course each.

What it does: searches for menu ideas, creates a calendar event with three start times, sends an email to all households and makes a page listing the course, host and next stop.

What it needs: web search to find menu ideas, calendar to set the date and times, mail to invite the households, a page maker to show the route, task tools to keep track of steps.

What it will not do: it will not book a restaurant, it will not buy groceries and it will not force any household to take part.
