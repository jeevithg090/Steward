# Meeting prep
Finds the latest email thread for each meeting tomorrow, so the person can review before the calls.

**What it does:** Reads the calendar for tomorrow, searches the mailbox for the most recent email thread about each meeting, and makes a page with the meeting time and the start of the email.

**What it needs:** Access to the calendar and mail connectors.

**What it will not do:** It will not read old emails beyond the most recent thread, and it will not send replies.
