---
name: build-theme-table
description: Make a markdown table with month columns and theme rows
---

1. Create a markdown page with a level‑one heading 'Quarterly Content Theme Planner'. 2. Write a subheading with the quarter and year given by the person. 3. Make a table with three column headers for the month names of that quarter and one row per theme. 4. Leave all date cells empty. 5. Save the page with file_write. 6. Show the page to the person.
