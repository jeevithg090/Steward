---
name: spot-fake-support
description: Find and record the common signs of a fake tech support call.
---

1. Search the web for 'fake tech support call virus'. 2. Read the top results to find the typical story and phone number. 3. Search for that phone number to see if it is on scam lists. 4. If the number is on a scam list, note it. 5. Make a page with the warning signs: unsolicited call, pressure to pay, remote access request, gift card or crypto demand. 6. Show the page to the person.
