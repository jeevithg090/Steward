# Fake tech support scout
Helps you spot fake tech support calls that claim your computer has a virus.

What it does: Searches the web for recent reports, checks phone numbers against scam lists, and creates a page of warning signs.
What it needs: web_search to find reports, web_fetch to read them, make_page to create the warning list.
What it will not do: It will not call any number, it will not pay any fee, and it will not fix your computer.
