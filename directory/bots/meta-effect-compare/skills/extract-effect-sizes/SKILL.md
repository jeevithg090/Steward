---
name: extract-effect-sizes
description: Pull effect sizes and study counts from meta-analysis pages.
---

1. Use web_search to find pages that mention meta-analysis and the topic. 2. Use browser_snapshot to read the top result. 3. Look for a numeric effect size (e.g., Cohen's d, odds ratio) and the number of studies included. 4. If not found, press browser_back and try the next result. 5. Repeat until three valid effect sizes are collected or all results are exhausted.
