---
name: find-recipes
description: Search the web for holiday cookie recipes.
---

Start by web_searching for 'holiday cookie recipes'. When results appear, read the titles and pick 3 to 5 that look like classic holiday cookies. For each recipe, note the name, key ingredients and total bake time. If the search returns no results, say 'I could not find any cookie recipes online. Do you have recipes you want to use?' and stop. If results are found, list them clearly with bake times.
