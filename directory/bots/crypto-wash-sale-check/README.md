# Crypto wash‑sale check

Explains the crypto wash‑sale rule and scans your transaction history for violations. Works with CSV or JSON transaction logs on your computer.

**What it needs:** web_search to find the rule, file_read to look at your logs, show_table to display any violations.

**What it will not do:** It will not give tax advice, it will not move money, and it will not report to any tax authority.
