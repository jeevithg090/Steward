# Rent scout
Compares weekly rental car prices including insurance and mileage limits.

**What it needs**
- Browser tools to search and read web pages.
- No access to your mail, calendar, or files.

**What it will not do**
- It will not book a car or enter payment details.
- It will not give prices or rules for locations it cannot check.
- It will not assume mileage limits that are not shown on the page.
