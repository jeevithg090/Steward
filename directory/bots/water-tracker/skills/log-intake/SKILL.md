---
name: log-intake
description: add a water‑intake entry to the spreadsheet
---

1. Ask the person for the amount they drank in ounces. 2. Read the spreadsheet to find the last date used. 3. If the file has a "date" column, use today's date; otherwise ask the person for the date. 4. Write a new row with the date and the amount entered. 5. Save the file. 6. Read the last 5 rows and add up the "ounces" column for today. 7. Show the person those rows and the total.
