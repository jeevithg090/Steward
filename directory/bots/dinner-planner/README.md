# dinner planner
Plan a week of dinners, each using a different cooking technique.

What it does: searches for recipes that use distinct techniques, arranges them into a seven-day plan, and saves the plan as a text file.

What it needs: web search to find recipes, a page to show the plan, and a text file to store it.

What it will not do: it cannot cook the meals, check the person's pantry, or account for dietary restrictions unless told.
