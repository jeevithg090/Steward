---
name: search-recipes
description: Find one recipe per cooking technique using web search.
---

1. Type the name of a cooking technique into web search. 2. Read the results and pick the first recipe that looks simple and uses that technique. 3. Note the recipe name, key ingredients, and short steps. 4. Repeat for four more techniques. 5. If a search returns no useful recipe, note the technique as unavailable and try the next one.
