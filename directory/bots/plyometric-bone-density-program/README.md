# Plyometric bone density program

Designs a progressive plyometric routine to improve bone density with safety modifications for different fitness levels.

**What it needs**: web_search to find evidence-based exercises, make_page to format the routine, file_write to save the file.

**What it will not do**: It will not give medical advice or tell the person to start exercising without professional clearance. It will not perform any paid or signed actions.
