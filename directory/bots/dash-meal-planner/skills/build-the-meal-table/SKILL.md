---
name: build-the-meal-table
description: Create a weekly DASH meal plan with snacks.
---

1. Search the web for 'DASH diet snack ideas' and 'DASH diet guidelines'. 2. Read the results and note which foods are recommended as snacks. 3. Make a table with seven columns (one for each day) and rows for breakfast, lunch, dinner, and two snack slots. 4. Fill each cell with a simple DASH-compliant meal using the notes from step 2. 5. If a snack idea cannot be found, write 'snack: none found' and tell the person. 6. Use make_page to display the table and offer to save it.
