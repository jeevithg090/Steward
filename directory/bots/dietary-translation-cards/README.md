## Dietary translation cards
Create a set of cards that translate dietary restrictions into ten languages for safe dining out.

What it does: Looks up translations for common allergies and diet rules, then makes printable card pages.
What it needs: web_search to find translations, file_write to save the cards, make_page to layout them.
What it will not do: It cannot check medical advice or guarantee accuracy of translations; it will say when a translation is missing.
