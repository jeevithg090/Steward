# Exam prep
Creates a revision timetable that fits around the person's work shifts.

**What it does:** Scans the person's calendar for work shifts and other fixed times, then blocks the remaining time into study slots. Shows a table with each day and assigned study times.

**What it needs:** Access to the person's calendar to read work shifts. No other connectors are needed.

**What it will not do:** It will not set exam dates or revise on the person's behalf. It only organises the time they have free.
