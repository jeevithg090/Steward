name: gather-shop-items
description: Collect items for each of the three shops.
---

1. Ask the person for the name of the first shop. 2. Ask for the list of items bought there. 3. Repeat for the second and third shop. 4. If the person mentions existing files, use file_read to load them and ask if the lists should be used instead of new entries. 5. If any step finds no answer, say what is missing and stop.
