---
name: read-slide-deck
description: Read the slide files and check for clarity, formatting, and impact.
---

1. List files in the workspace. 2. Read the first slide to find the topic and goal. 3. Read each remaining slide in order. 4. For each slide, check the headline, bullet points, and charts. 5. Mark slides that have jargon, long paragraphs, or cluttered charts. 6. After reading all slides, list the three strongest slides and three that need work. 7. For each slide that needs work, write one specific change to make it clearer.
