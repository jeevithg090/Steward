---
name: build-the-walking-plan-page
description: Make a text page with the program structure
---

1. Use make_page to create a page titled 'Progressive Walking Plan for PAD'.
2. Include a session format: 'Walk until pain reaches moderate level (3–4/10). Rest until pain drops to 1–2/10 or disappears. Repeat 3–5 times.'
3. Add a weekly progression: 'Increase total walking time by 5 minutes every 2 weeks, keeping the rest‑until‑pain‑subsides pattern.'
4. List safety notes: stop if pain is severe or sudden, check feet daily for sores, and consult a doctor before changing the plan.
5. Show the page to the person and ask if they want it saved or turned into a routine.
