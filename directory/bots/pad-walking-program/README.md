# PAD Walking Program
A progressive walking plan to manage claudication symptoms from peripheral artery disease.

What it does: searches for walking guidelines, creates a text page with a session format and weekly progression, and can set a reminder to log walks.

What it needs: web_search to find guidelines, make_page to output the plan, routine_create for optional reminders.

What it will not do: give a diagnosis or replace a doctor's advice; it always presents the plan as a general template and asks the person to check with their clinician.
