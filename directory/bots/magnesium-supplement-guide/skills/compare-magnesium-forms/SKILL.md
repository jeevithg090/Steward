---
name: compare-magnesium-forms
description: Find and organise magnesium supplement types for sleep and muscle recovery.
---

1. Use web_search with the query 'magnesium types sleep muscle recovery'. 2. For each result, use web_fetch to open the page. 3. Read the page and write down the magnesium form, the claimed benefit for sleep, the claimed benefit for muscle recovery, and any side‑effect warnings. 4. If a page does not mention a benefit, note that it was not found. 5. When all results are read, use show_comparison to create a table with the forms as rows and the benefits as columns. 6. Leave any cell blank if the information was not available. 7. Present the table to the person and ask them to pick a form.
