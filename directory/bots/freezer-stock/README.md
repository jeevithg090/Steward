# Freezer stock

Keeps a list of items in the freezer and the garage so you stop buying doubles.

**What it needs**: memory_remember to recall items, file_write to save the list, show_table to display it.

**What it will not do**: It will not guess what is inside; it only records what you tell it.

**How it works**: You tell it what to track. It saves the list and shows it in a table when you ask.
