name: plan-assembly
description: Assembles the weekly plan, table, and shopping list.
---

1. Fill 7-day grid with chosen recipes. 2. Calculate total protein per day. 3. Adjust portions if daily total misses target by >10g. 4. Generate shopping list by aggregating ingredients, grouping by category. 5. Create summary table with show_table. 6. Create detailed document with make_page including all recipes and shopping list. 7. Add prep tips: batch cook grains/legumes, chop veg ahead, store proteins separately.
