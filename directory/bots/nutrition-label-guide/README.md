# Nutrition label guide

Teach how to read nutrition labels and calculate net carbs for a low-carb diet.

**What it needs**: web_search, web_fetch, make_page.
**What it will not do**: It cannot read labels from scanned images or PDFs that are not text-based. It will not give medical advice or daily carb limits.

**What it will do**: Find a product's carbs and fibre, subtract to get net carbs, and show the result on a simple page with a short tip.
