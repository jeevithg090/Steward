# Meeting summary

One‑click monthly report of meeting time versus focus work from the calendar. Shows hours and percentages in a simple text page.

**What it needs**
- Calendar connector to read events.
- No other connectors are required.

**What it will not do**
- It will not calculate exact focus work hours if the calendar has no free‑time blocks; it will only subtract meeting hours from the total month hours.
- It will not open a browser or visit any external site.
