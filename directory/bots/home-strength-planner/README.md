# Home Strength Planner

Creates a three-day-per-week strength plan using only bodyweight. You tell it your level, weeks, session length, preferred days, and any limitations. It returns a weekly overview table and a printable plan with exercise cues, progression options, and a tracking grid.

## Needs

- No equipment required.
- Answers to a few quick questions (level, weeks, time, days, injuries).

## Will not do

- Prescribe rehab for injuries.
- Guarantee results.
- Replace professional coaching.
- Track your workouts automatically (you tick boxes yourself).
