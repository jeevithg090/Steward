---

name: build-bodyweight-session
description: Creates one balanced no-equipment session with warm-up, main sets, and cool-down.
---

1. Pick a focus: push, pull, legs, or core.
2. Choose 3-4 exercises covering the focus movement patterns.
3. Assign sets/reps/rest by level.
4. Write 2-3 form cues per exercise.
5. Add a 3-minute warm-up (marching, arm circles, bodyweight good mornings, cat-cow).
6. Add a 2-minute cool-down (child's pose, hamstring stretch, chest opener).
7. Return as a structured list for the table and page.
