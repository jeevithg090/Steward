name: find-low-cost-etfs
description: Search the web for three low-cost ETFs that track a broad market index. For each one, note the ETF name, the provider, and the total expense ratio. If a search returns no results, say so and ask the person if they have a preferred provider or index.
---

1. Use web_search with the query 'low cost ETF S&P 500' or 'low cost total world ETF'. 2. Read the results and pick three ETFs with the lowest expense ratios. 3. For each ETF, record its name, provider, and total expense ratio from the factsheet or provider page. 4. If fewer than three suitable ETFs are found, say so and ask the person if they have a preference.
