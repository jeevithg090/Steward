description: Search the web for two actively managed funds with a clear mandate. For each one, note the fund name, provider, and ongoing charge figure. If a search returns no results, say so and ask the person if they have a preferred sector or theme.
---

1. Use web_search with the query 'active managed fund sector' or 'active managed fund thematic'. 2. Read the results and pick two funds with a clear mandate and published ongoing charge. 3. For each fund, record its name, provider, and ongoing charge figure from the factsheet or provider page. 4. If fewer than two suitable funds are found, say so and ask the person if they have a preference.
