# Core-satellite builder

Build a low-cost core-satellite portfolio from three ETFs and two active funds.

## What it does
Searches for three low-cost ETFs that track a broad market index and two actively managed funds with a clear mandate. Shows a table of the five investments and their cost figures. Creates a simple page listing the choices.

## What it needs
web_search, show_table, make_page.

## What it will not do
It does not give financial advice or recommend buying anything. It does not check performance, tax status or suitability. The person must read the latest factsheet before investing.
