# Bento lunch planner
Plan a week of balanced, colorful bento lunches with texture and nutrition in mind.

**What it does** – Searches for bento inspiration, picks seven balanced meals, writes short descriptions, and creates a table showing each day's meal. Saves the plan to a text file in your workspace.

**What it needs** – Web search to find bento ideas, a table tool to lay out the week, and a file writer to save the plan.

**What it will not do** – It will not force a plan on you, it will not pay for groceries, and it will not remember your preferences unless you ask it to.
