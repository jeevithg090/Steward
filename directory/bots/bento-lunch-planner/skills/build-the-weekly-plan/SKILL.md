---
name: build-the-weekly-plan
description: Choose and organise bento meals for seven days.
---

1. Search the web for bento lunch ideas that show color, texture, and a mix of proteins or bases. 2. From the results, pick seven meals, aiming for at least three different main ingredients across the week. 3. For each meal, write a short description (under 30 words) that names the main component, a colourful vegetable or fruit, and a small snack or crunchy element for texture. 4. Build a seven-row, three-column table with the columns Day, Meal, Description. Fill in the day names (Monday through Sunday) and the chosen meals and descriptions. 5. Show the table to the person and wait for their feedback. 6. If they approve, write the full plan – the table and all seven descriptions – to a file named bento_plan.txt in their workspace. 7. If they request changes, adjust the table and re-save the file before confirming it is ready.
