---
name: search-for-etf-replication-methods
description: Search web for representative sampling ETFs, then open each fund's factsheet and read the replication method stated on the page.
---

1. Search for "representative sampling emerging markets ETF" using web_search. 2. From results, pick fund names and open their factsheet pages using browser_navigate. 3. On each page, use browser_snapshot to find the section that describes the replication method. 4. Note whether the method is representative sampling or full replication. 5. If the page does not mention the method, note that it could not be confirmed. 6. Repeat for up to five funds. 7. When finished, use show_comparison to present the fund name, tracked index, and replication method for each.
