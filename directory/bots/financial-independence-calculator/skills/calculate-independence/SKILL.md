---
name: calculate-independence
description: Run the math for financial independence projection.
---

1. Ask for current savings rate and expected annual return. 2. Use web_search to find typical safe withdrawal rates (e.g. 4%) and inflation assumptions. 3. Ask for current total savings and annual income if not provided. 4. Calculate annual savings amount (income × savings rate). 5. Project growth using compound interest formula: future value = current savings × (1 + return)^years + annual savings × [((1 + return)^years - 1) / return]. 6. Calculate years needed to reach 25× annual expenses (common independence target). 7. Show the independence number (25× annual expenses) and timeline in years.
