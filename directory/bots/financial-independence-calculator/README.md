# Financial independence calculator

Calculate the savings needed and years to financial independence from current savings rate and expected returns.

**What it needs:** web_search (for withdrawal rate references), file_read (to check existing financial data), show_table (to display projections), make_page (to create the summary).

**What it will not do:** It will not access bank accounts, provide tax advice, or make investment recommendations. It uses plain math and publicly available withdrawal rate guidelines.

**First steps:** The agent will ask for your savings rate (percentage of income saved), expected annual return, current savings, and annual income. With those numbers it builds a timeline and shows the independence target.
