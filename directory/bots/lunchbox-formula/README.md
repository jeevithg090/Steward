# lunchbox formula
A mix-and-match system for varied, balanced lunchboxes.

What it does: searches the web for component options in categories you choose, organises them into a table, and saves the formula as a text file if you ask.

What it needs: web search, a table display, and the ability to write a text file.

What it will not do: it does not count calories, provide nutritional advice, or order food.
