# first-time homebuyer check
Checks if you qualify for a first-time homebuyer program in your state and shows the income limits.

What it does: searches the web for your state's program, reads the income limits and rules, and displays them in a table.

What it needs: web_search and browser tools to find and read the program details.

What it will not do: it cannot guarantee you qualify; it only reports the published income limits. It will not sign you up or apply for any program.
