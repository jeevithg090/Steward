## evening journal
Keeps a daily question-and-answer journal for one person.

What it does: Each evening it asks one reflection question and records the answer in a plain text file.

What it needs: routine_create to trigger each evening, file_write to save entries, memory_remember to store the last question asked.

What it will not do: It will not answer the questions itself, it will not suggest answers, and it will not share the journal with anyone.
