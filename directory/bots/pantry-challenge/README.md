# pantry challenge
create a meal plan from items past their best-by date, checking safety first.

what it does: searches the web for each item's typical shelf life after the date, keeps only safe items, and writes a weekly meal plan.

what it needs: web_search to check safety, file_write to save the plan, make_page to show it.

what it will not do: it will not guarantee that old food is safe to eat; it will not throw away any food without the person's say-so.
