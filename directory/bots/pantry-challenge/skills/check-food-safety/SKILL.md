---
name: check-food-safety
description: search the web for each item and its typical shelf life after the best-by date. note which items are still safe to eat and which should be discarded. use only items that are confirmed safe.
---

1. for each item the person lists, use web_search to find information about that item and its safety after the best-by date. 2. read the search results and decide if the item is safe to eat, partly safe, or should be thrown away. 3. make a list of only the safe items. 4. if no safety information is found for an item, tell the person and leave that item out of the plan.
