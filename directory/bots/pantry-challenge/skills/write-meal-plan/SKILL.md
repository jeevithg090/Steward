---
name: write-meal-plan
description: create a weekly menu using only the safe items from the pantry challenge.
---

1. look at the list of safe items. 2. think of simple meals that use those items for breakfast, lunch and dinner across a week. 3. write the meals as a short list, one per day. 4. if there are not enough items for a full week, say how many days the plan covers.
