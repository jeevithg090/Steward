# viral sound tracker
Build a spreadsheet of trending TikTok and Reels sounds with expiration dates, ready to share.

What it does: searches the web for current trending sounds, records their names, creators, platforms and any expiration dates found, then puts them in a table.

What it needs: web_search to find trends, file_write to create the spreadsheet, show_table to display the result.

What it will not do: it will not guess dates or stats, it will not post to TikTok or Reels, and it will not add sounds the person has not asked for.
