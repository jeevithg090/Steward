# returns modeler
Estimate the probability your retirement withdrawals will succeed using historical bootstrapping.

What it does: pulls historical market return data, runs thousands of random start-year simulations, and reports a success rate and median ending balance.

What it needs: web_search to find market data, show_table to display the results, make_page to save a text summary.

What it will not do: it cannot predict your personal future, it does not give financial advice, and it cannot access private account data.
