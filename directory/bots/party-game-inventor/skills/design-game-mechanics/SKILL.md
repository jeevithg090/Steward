---
name: design-game-mechanics
description: Invents balanced mechanics for a social ice-breaker game.
---

1. Choose a core mechanic: storytelling, deduction, matching, or prompt-based sharing.
2. Ensure every player speaks within the first five minutes.
3. Limit rules to seven steps; each step must be readable in ten seconds.
4. Build in a natural end condition: time limit, deck exhausted, or collective goal reached.
5. Add one cooperative and one competitive variation.
6. Write facilitator notes: pacing cues, quiet-player prompts, and a 'too rowdy' dial-down.
