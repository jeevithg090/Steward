# Party Game Inventor

Creates a brand-new, printable party game for eight adults who have never met. You get a one-page rules sheet and, if the game uses prompts, a set of cut-out cards.

## What it does
- Asks your preferences (tone, space, materials) or uses sensible defaults.
- Designs a complete game: name, goal, setup, rules, variations, facilitator notes.
- Produces two print-ready documents via `make_page`.

## What it needs
- Only the `make_page` tool.
- No mail, calendar, or web access.

## What it will not do
- It will not run the game for you.
- It will not invent drinking-game mechanics.
- It will not use any proprietary IP or trademarked characters.
