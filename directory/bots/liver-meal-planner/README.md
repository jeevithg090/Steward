# liver meal planner
Creates a weekly Mediterranean meal plan for fatty liver disease with portion guides.

What it does: searches the web for liver‑friendly recipes, builds a seven‑day menu, and presents a table with portions and key nutrition.

What it needs: web_search to find recipes, make_page to lay out the plan, show_table to display portions.

What it will not do: it will not give medical advice, it will not count calories precisely, and it will not cook or shop for you.
