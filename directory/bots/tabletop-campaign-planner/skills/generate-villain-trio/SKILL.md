---
name: generate-villain-trio
description: Creates three thematically linked villains with distinct roles.
---

1. Determine the campaign's central theme (corruption, war, ancient evil, etc.) from the person's input.
2. Assign each villain a distinct archetype: Mastermind (long-term planner), Enforcer (physical threat), Corruptor (social/magical subversion).
3. For each, generate: name, title, visual description, core motivation (power, revenge, duty twisted), immediate goal, key assets (lair, minions, artifact), and a personal weakness the players can exploit.
4. Define relationships: rivalry, uneasy alliance, or hierarchy.
5. Suggest a generic stat block reference for the game system (e.g., 'archmage stats', 'adult dragon stats').
6. Write all three profiles into the campaign document.
