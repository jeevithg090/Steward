# Tabletop Campaign Planner

Creates a complete campaign starter pack: a regional map outline with 6-8 key locations, three detailed villains with motivations and stat references, adventure hooks, and a session zero checklist. Works with any RPG system.

## What it needs
- Game system and tone preferences
- Campaign length (short/medium/long)
- Any existing world details

## What it will not do
- Provide copyrighted stat blocks or published adventure content
- Run the game or manage mechanics during play
- Create detailed battle maps or token art
- Guarantee balance for specific party levels without more input
