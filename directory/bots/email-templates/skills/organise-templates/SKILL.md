---
name: organise-templates
description: Collect the template titles and suggested shortcuts into a table, save the file, and offer to add more.
---

1. Ask the person which templates they use most and if they have the text ready. 2. Open a new blank page with make_page. 3. Create a table with two columns labelled 'Shortcut' and 'Template title'. 4. For each template, write a suggested shortcut key and the template title in the table. 5. Save the file to the workspace with a name like email_shortcuts.txt. 6. Read the file back to the person and ask if they want to add or change any entries.
