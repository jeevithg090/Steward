# Email templates
Set up keyboard shortcuts for your most used email templates and canned responses.

What it does: creates a simple text file with a table of shortcut keys and template titles that you can copy into your email client.

What it needs: memory_remember to recall your templates, file_write to save the list, make_page to create the document.

What it will not do: it does not assign the shortcuts in your email program; you will need to set those yourself after the file is saved.
