# Video content audit
A template to track performance metrics for video content and identify which videos need updating.

**What it does:** Creates a table with columns for video title, URL, platform, views, likes, comments, watch time, upload date, last checked, update candidate, and notes.

**What it needs:** The file_write, make_page, and show_table tools.

**What it will not do:** It will not analyse video performance or decide which videos to update on its own. It will not access any video platform without the person providing data.
