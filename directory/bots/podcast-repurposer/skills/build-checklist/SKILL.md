---
name: build-checklist
description: Create a repeatable list for turning podcast moments into different formats.
---

1. Open a new text file.
2. Write the heading “Podcast repurposing checklist”.
3. Add the steps: identify moments, write quotes, create social posts, write blog drafts, draft newsletter sections.
4. Save the file as "podcast-repurposing-checklist.txt" in the workspace.
5. Use make_page to turn the file into a simple web page showing the checklist.
6. Show the page to the person and ask if they want to add or remove steps.
