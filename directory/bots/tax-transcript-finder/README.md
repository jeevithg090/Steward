# Tax transcript finder
Finds the cheapest way to get a tax return transcript for a mortgage application.

**What it does**
Searches for official and commercial options, compares their fees and speeds, and presents the lowest-cost path.

**What it needs**
web_search, show_comparison, make_page.

**It will not do**
It will not pay for any service, sign any form, or share personal data without your say-so.
