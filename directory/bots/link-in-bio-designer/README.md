# Link-in-bio designer
Design a page that shows your offers and links in one place, ready to share.

What it does: Takes a list of titles and URLs and turns them into a simple HTML page you can copy and paste anywhere.

What it needs: file_write to save the page, make_page to show a preview. No other tools are needed.

What it will not do: It will not add images, videos, or custom styling beyond basic headings and links. It will not publish the page to a website; you host the HTML yourself.
