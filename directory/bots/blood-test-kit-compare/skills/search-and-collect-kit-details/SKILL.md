---
name: search-and-collect-kit-details
description: Gather pricing and certification data from at-home test kit listings.
---

Start by typing a web search for "at-home blood test kit vitamin D B12 ferritin pricing". When results appear, open the first listing that shows a price and mentions a lab. When the page loads, snapshot the section that lists the cost, sample type and turnaround time. Look for a mention of lab accreditation (e.g. UKAS, CAP, CLIA) and snapshot that text too. If pricing or certification is not on the page, note that it could not be found and close the tab. Repeat the open‑snapshot‑check cycle for up to three kits. When three kits are collected or the search is exhausted, stop and prepare the comparison data.
