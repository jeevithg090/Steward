name: find-statistical-test-guides
description: Search the web and read pages to learn test-selection criteria.
---

1. Use web_search with terms like "statistical test selection guide" or "choosing statistical test by data type".
2. Use browser_snapshot to read the top results and identify sections that list test types and their requirements.
3. Use browser_click and browser_type to follow links and search within pages for assumptions such as normality and sample size.
4. Summarise the key points: measurement scale, distribution, number of groups, paired or independent.
5. If the search results do not give a clear answer, stop and tell the person what was found and what is missing.
