---
name: assess-fbar-requirement
description: Determine if foreign accounts need FBAR filing
---

1. Search the web for current FBAR filing thresholds and requirements. 2. Read any files in the workspace that contain bank account details, names, or balances. 3. For each account, check if the peak balance in the relevant years exceeded the threshold. 4. Note the years each account was over the threshold. 5. If no account files are found, say so and ask the person to provide the information. 6. If the threshold or rules cannot be found online, say what could not be checked.
