# push-squat plan
Designs a 4-week progressive overload plan for push-ups and squats based on your current max reps.

What it needs: memory to store your max reps, a page to show the plan, a table to display the weeks, and a task to remind you to follow the plan.

What it will not do: it will not guess your max reps if you do not give them, and it will not run any workout for you.
