# collab scout
Find creators in your field and draft a first outreach message.

What it does: searches the web for people who make content in your topic, notes what they do, and writes a short friendly message you can send or edit.

What it needs: web search, page fetching, a table to show results, and a page to present the final message.

What it will not do: it will not sign you up for anything, it will not send a message without your go-ahead, and it will not invent facts about the creators it finds.
