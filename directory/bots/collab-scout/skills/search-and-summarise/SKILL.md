---
name: search-and-summarise
description: Find creators and note what they do.
---

1. Run web_search with the person's field and the word "creator". 2. For each top result, use web_fetch to read the page. 3. Note the platform, the type of work, and any contact link. 4. Stop after 5 results or when no more relevant pages appear. 5. Return a list of the findings.
