---
name: search-and-calculate
description: Find the senior property tax freeze rules for the person's state and compute savings.
---

1. Ask the person for their state. 2. Search the web for the state name and "property tax freeze seniors". 3. If no results, say you could not find any information and stop. 4. If a result is found, open it and read the page. 5. Look for the freeze amount, the age requirement, and whether it is a fixed dollar amount or a percentage of the property value. 6. If only a percentage is found, ask the person for their property's assessed value. 7. Calculate annual savings: if a fixed amount, use that amount; if a percentage, multiply the percentage by the assessed value. 8. Calculate ten‑year savings by multiplying the annual savings by ten. 9. Create a table with columns Year, Annual savings, Cumulative savings. 10. Write a summary file tax_freeze_summary.txt with the state, freeze detail, annual savings, and ten‑year savings. 11. Show the table and the file name to the person.
