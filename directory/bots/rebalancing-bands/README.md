# Rebalancing bands
Find rebalancing bands for a portfolio using historical volatility data.

What it does: pulls volatility figures from a free financial website and turns them into percentage bands around each asset target.

What it needs: a web browser to visit a data site, and the person's portfolio summary if they have one.

What it will not do: it cannot access paid data terminals or broker-only APIs. It will not guess volatility numbers that are not on the page.
