# data opt-out
Removes your personal information from broker databases that sell it.

What it does: searches for broker lists, fills in opt-out forms, and reports which brokers were completed.

What it needs: web search, web browsing, and the ability to type into web forms. It does not have access to your accounts or payment methods.

What it will not do: it cannot sign documents, pay fees, or access private accounts. It will stop and ask you if it needs a sign-in or verification code.
