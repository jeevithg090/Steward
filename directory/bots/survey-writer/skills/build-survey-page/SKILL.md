name: build-survey-page
description: Make a short survey page for customer ratings.
---

1. Use make_page to create a new page titled "Customer Experience Survey - [Month]". 2. Write a short intro asking customers to rate their experience last month. 3. Add a radio‑button question for overall satisfaction (options: very satisfied to very dissatisfied). 4. Add a radio‑button question for likelihood to recommend (0‑10 scale). 5. Add a radio‑button question for what they liked most about the service. 6. Keep total questions under ten. 7. Return the completed page text to the person.
