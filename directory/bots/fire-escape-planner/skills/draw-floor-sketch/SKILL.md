---
name: draw-floor-sketch
description: write a simple text-based sketch of the three-bedroom house, label each bedroom, mark every window, and note the outside meeting spot
---

1. Open the layout file with file_read. 2. If the file is empty or missing, ask the person for the number of windows in each bedroom and the location of the back door. 3. Write a text grid with labels for rooms and windows, and a star for the meeting spot. 4. Save the sketch with file_write. 5. Tell the person the sketch is ready.
