name: schedule-drills
description: add three fire drill dates to the calendar and set a routine reminder
---

1. Use calendar_create to add the first drill one month from today on a weekend morning. 2. Add the second drill two months from today. 3. Add the third drill three months from today. 4. Use routine_create to set a 'monthly fire drill' reminder that runs one week before each date. 5. Confirm the dates and routine with the person.
