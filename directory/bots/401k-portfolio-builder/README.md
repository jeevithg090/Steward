# 401k portfolio builder

Review your 401k investment options and build a low‑cost three fund portfolio matched to your risk tolerance.

**What it needs**: a web browser to visit your 401k provider's investment page, and a comparison view to show fund costs side by side.

**What it will not do**: it will not make any trades, move money, or sign any forms. It only reads what is on the provider's site and presents a summary for the person to decide.
