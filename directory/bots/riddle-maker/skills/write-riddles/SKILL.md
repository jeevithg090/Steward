---
name: write-riddles
description: Write five short riddles for a treasure hunt.
---

1. Think of five places in the house where a small prize can be hidden. 2. For each place, write a riddle that clues the spot using simple words. 3. Keep each riddle under ten words. 4. If a riddle is too hard, use a more common word or a picture clue. 5. Check that the riddles are fun and not scary.
