---
name: build-weekly-table
description: Make a table of breakfasts, lunches, dinners and two snacks for each day of the week using only low-GI foods found in sources.
---

1. Create a table with seven rows (Mon–Sun) and five columns (Breakfast, Lunch, Dinner, Snack 1, Snack 2). 2. For each day, fill the cells with one food item from the search results. 3. If a cell cannot be filled, leave it blank and add a brief note. 4. Do not add any new foods that were not in the search results.
