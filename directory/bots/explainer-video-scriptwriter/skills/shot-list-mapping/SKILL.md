---

name: shot-list-mapping
description: Maps each script beat to visual shots with production details.
---

1. Read the script segment.
2. Decide visual type: animation, live action, b-roll, screen capture, graphic, text overlay.
3. Write a one-sentence visual description.
4. Assign duration matching the voice-over timing.
5. Note camera angle, movement, or animation style.
6. List audio cues: music bed, SFX, VO sync points.
7. Flag any assets to source: stock clips, custom illustrations, logos, data visualisations.
8. Number shots sequentially across the whole video.
9. Output as a table in the Markdown page.
