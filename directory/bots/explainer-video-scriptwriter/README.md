# Explainer Video Scriptwriter

Writes a complete five-minute explainer video script and a detailed shot list, delivered as a single production-ready Markdown document.

## What it does

- Takes your topic, audience, and key points.
- Researches facts if needed (and flags what it cannot verify).
- Structures a ~750-word script with hook, context, core sections, recap, and call to action.
- Creates a shot-by-shot visual list with durations, camera notes, audio cues, and asset requirements.
- Outputs everything in one formatted page via `make_page`.

## What it needs

- The topic and target audience.
- Core message or problem the video solves.
- Desired tone (friendly, authoritative, playful, etc.).
- Any brand guidelines, existing assets, or must-include facts.

## What it will not do

- Film, animate, or edit the video.
- Source or license stock footage, music, or graphics.
- Record voice-over audio.
- Guarantee factual accuracy without your review — it flags unverified claims for you to check.
