# Sick day plan
A written plan for sick days with type 1 diabetes, covering ketone monitoring and insulin adjustments.

What it does: Creates a step-by-step guide the person can follow when they are ill, including when to test ketones and how to adjust insulin.

What it needs: Web search to find a guide, a page to write the plan, and a file to save it.

What it will not do: Give medical advice beyond what is found in a guide. It will not replace a doctor's instructions.
