---
name: build-sick-day-plan
description: Create a sick day management plan for type 1 diabetes with ketone monitoring and insulin adjustments.
---

1. Search the web for a standard sick day management guide for type 1 diabetes. If no guide is found, ask the person if they have doctor's advice to follow. 2. Read the guide and note the key points about ketone testing frequency, when to contact a doctor, and how to adjust basal or correction insulin. 3. Make a new page titled "Sick day management plan". 4. Write the plan in clear, short steps with sections for checking ketones, what to do if ketones are low, what to do if ketones are moderate or high, and when to seek help. 5. Use bullet points and simple language. 6. Offer to save the page as "sick-day-plan.txt". 7. If the person agrees, write the plan text to that file. 8. Show the plan text on screen for the person to read or copy.
