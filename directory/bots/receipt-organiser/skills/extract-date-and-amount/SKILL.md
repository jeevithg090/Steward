---
name: extract-date-and-amount
description: Read each file and pull out a date and a number that looks like a total amount.
---

1. Open the file. 2. Look for a line that contains a date in day-month-year format. 3. Find the first number that looks like a price (for example, £12.50 or 12.50). 4. Write the date and the number on a list. 5. If either is missing, close the file and move to the next one.
