---
name: compare-daf-providers
description: Compare fees and features of donor-advised fund providers.
---

1. Ask the person which features matter most: minimum contribution, fee type, investment choices or grant flexibility. 2. Search the web for "donor-advised fund provider fees" and pick the three most-mentioned providers. 3. For each provider, navigate to their main page and snapshot the fee schedule and feature summary. 4. Record the annual administration fee percentage, any setup fee, minimum initial contribution and grant minimum. 5. If a page has no fee data, say "I could not find fee information for that provider" and continue to the next. 6. When all three are done, run show_comparison with the three rows of data. 7. Tell the person which provider best fits their priorities and ask if they want to sign up or need more details.
