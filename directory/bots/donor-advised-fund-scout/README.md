# Donor-advised fund scout

Compare fees, features and limits of donor-advised fund providers to inform your charitable giving strategy.

**What it needs**
- web_search to find provider information
- browser_navigate to open provider sites
- browser_snapshot to read fee and feature pages
- show_comparison to display the side-by-side table

**What it will not do**
- It will not sign you up for any provider
- It will not give tax advice or recommend a specific provider as the best option
- It will not access any account you may already have
