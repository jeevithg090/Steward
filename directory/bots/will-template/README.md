# Will template

Creates a draft will template covering guardianship for two children and digital assets.

**What it does:** Generates a simple text page with blank fields for guardianship and digital asset details.

**What it needs:** Web search to find standard clauses, a page creator, and a file writer.

**What it will not do:** It does not give legal advice or finalise a valid will. The person must review it with a solicitor.
