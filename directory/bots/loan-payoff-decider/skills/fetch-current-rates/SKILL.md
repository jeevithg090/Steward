---
name: fetch-current-rates
description: Finds current UK easy access savings rate and a low-risk investment benchmark from reputable sources.
---

1. Search for "current UK easy access savings rate" and open two reputable consumer money or bank sites.
2. Read the headline AER for easy access accounts. Note the date and source.
3. Search for "current UK low risk investment return 5 year" and open a reputable investment platform or fund factsheet.
4. Read the annualised return for a low-risk multi-asset or bond fund. Note the date and source.
5. If no rates are found, return empty and tell the agent to ask the person for a rate to use.
