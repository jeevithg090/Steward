---
name: search-and-check-clearance
description: Find parking garages suitable for a high-roof van.
---

Start by typing the search query into web_search: "parking garage height clearance high roof van". When results appear, pick the first few and use browser_navigate to open each one. Read the page with browser_snapshot and look for numbers followed by metres, feet, or the word "clearance". If a height is found, write it down. If the page does not state a height, say so for that garage and move to the next result. Continue until three garages have been checked or no more results are left. At the end, list each garage with its stated height, or say that none of the checked pages gave a clear height measurement.
