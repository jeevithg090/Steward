name: build-meal-table
description: Create a seven-day table with breakfast, lunch, dinner, and a snack for each day. For each food item, list the name, potassium (mg), and phosphorus (mg). If a value is not found in the search results, write 'values not found'. After the table, add a row showing the total potassium and phosphorus for each day.
---

1. Open a blank page in make_page. 2. Write a header: 'Weekly CKD Meal Plan (Stage 3)'. 3. Create a table with columns: Day, Meal, Food, Potassium (mg), Phosphorus (mg). 4. Fill seven rows for each day, with sub-rows for breakfast, lunch, dinner, and snack. 5. As you add each food, note the potassium and phosphorus values from the web search. 6. If values are missing, type 'values not found'. 7. After the table, add a summary row: 'Daily totals: potassium ___ mg, phosphorus ___ mg'. 8. Save the page and return the text to the person.
