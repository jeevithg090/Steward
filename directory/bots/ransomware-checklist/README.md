# Ransomware checklist

Creates a plain‑text checklist for your family to follow if anyone receives a ransomware message. Uses web search to find reliable guides, then writes the steps into a document you can read or share.

**Needs**: web search, a page creator, and file writing. No connectors are required.

**Will not**: invent technical advice or tell you to pay any ransom. If no suitable guide is found, it will say so and ask how you want to proceed.
