---
name: create-yearly-reminders
description: Make calendar events that repeat every year with a one-day-before reminder.
---

1. For each contact, use calendar_create to make an event on the noted date. 2. Set the event title to the contact's name and the reason (birthday or work anniversary). 3. Set a reminder alarm for one day before the date. 4. Set the event to repeat yearly so it comes back next year automatically. 5. If the date has already passed this year, set the first occurrence for next year. 6. After creating the event, tell the person the name and date that was added.
