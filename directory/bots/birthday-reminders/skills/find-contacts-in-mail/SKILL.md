---
name: find-contacts-in-mail
description: Look through recent mail to identify people who have sent birthday or work anniversary wishes.
---

1. Use mail_list to show the most recent 50 messages. 2. Scan each message for names and phrases like 'happy birthday' or 'work anniversary'. 3. When a name is found, note it down and note the date mentioned in the message. 4. If a message has both birthday and work anniversary, note both dates. 5. When the list is done, tell the person how many contacts were found and ask if they want to keep all of them.
