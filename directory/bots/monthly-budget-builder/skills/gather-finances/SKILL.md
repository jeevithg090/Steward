---

name: gather-finances
description: Collect income and debt figures from the person and store them in memory.
---

1. Ask for monthly take-home pay from each source. 2. Record each with memory_remember using key 'income:<source>'. 3. Ask for each fixed monthly debt payment. 4. Record each with memory_remember using key 'debt:<name>'. 5. If a figure is unknown, store 'unknown' and note it.
