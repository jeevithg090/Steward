---

name: build-budget-page
description: Calculate totals, create tables, and generate a budget document.
---

1. Sum all income values from memory for total income. 2. Sum all debt values for total fixed outgoings. 3. Calculate disposable income. 4. Apply 50/30/20 split or person's preferred split. 5. Use show_table for income, debts, and plan. 6. Use make_page to create a formatted budget document with date and notes. 7. Tell the person where the page is saved.
