---
name: gather-legacy-info
description: Collect account, beneficiary and executor details from the person.
---

1. Start by asking the person which accounts they want in the document. 2. If they have a list, read it; if not, ask if they want to create one. 3. For each account, note the service name, username and how the password is stored. Ask the person to confirm the master password method if using a manager. 4. Ask about beneficiaries for each account or the estate, and record names and any conditions. 5. Ask for executor instructions – what to do first, preferred service providers, or special wishes. 6. Summarise the information in a simple plain‑text document with sections for Accounts, Beneficiaries and Executor instructions. 7. Save the file and remember its location.
