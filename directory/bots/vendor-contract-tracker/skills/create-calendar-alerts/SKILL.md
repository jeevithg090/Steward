---
name: create-calendar-alerts
description: "For each contract found, add a calendar event with three reminder alerts: 90 days, 60 days and 30 days before the renewal deadline."
---

1. Use calendar_create to add an event titled "Vendor contract renewal: [reference or description]". 2. Set the event date to the contract end date or renewal deadline. 3. Add three alerts: 90 days before, 60 days before and 30 days before. 4. If the calendar tool is not connected, say that calendar access is needed and stop.
