---
name: organise-by-child
description: Group files by the child they belong to.
---

1. Run file_list to see all files in the workspace. 2. Read each file name and guess the child it belongs to. 3. If the child is clear, note it. 4. If unsure, ask the person which child the file is for. 5. After all files are labelled, create a folder for each child name found.
