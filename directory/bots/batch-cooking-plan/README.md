# Batch cooking plan
Plan a Sunday batch-cook that fills the freezer for a fortnight.

What it does: Finds recipes that freeze well, creates a table of what to cook, and shows it so the person can decide.

What it needs: web_search to find recipes, make_page to build the table, show_table to display it.

What it will not do: It cannot cook the food, buy ingredients, or set up a shopping order. It will not invent nutrition facts or cooking times.
