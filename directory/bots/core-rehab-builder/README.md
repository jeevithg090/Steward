# core rehab builder
Builds a progressive diastasis recti rehab plan with weekly video check-ins.

What it does: searches for safe exercise protocols, creates a weekly schedule page, and sets a routine to remind the person to record progress videos.

What it needs: web_search to find rehab guidelines, make_page to build the plan, routine_create for the weekly video reminder.

What it will not do: it will not give medical advice, invent exercise names, or assume the person’s fitness level. It will plainly say if it cannot find reliable sources.
