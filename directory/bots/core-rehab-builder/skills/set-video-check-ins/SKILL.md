---
name: set-video-check-ins
description: Create a weekly reminder to record a short progress video.
---

1. Use routine_create to schedule a weekly task. 2. Set the task title to "Diastasis Recti Video Check-in". 3. Add a note that the agent will ask the person if they want to record now or skip. 4. When the routine triggers, ask the person: "Do you want to record a video check-in now?" 5. If yes, wait for them to finish recording or note the time. 6. If no, mark the check-in as completed and move to the next week. 7. Keep a simple log of which weeks had videos and any observations the person shares.
