name: build-rehab-plan
description: Create a weekly diastasis recti rehab schedule with safe exercises and progression notes.
---

1. Search the web for approved diastasis recti exercises and safe movement guidelines. 2. List exercises that support deep core healing, noting reps and sets for week 1. 3. Write a progression plan that adds difficulty each week, e.g., adding transverse abdominis engagement or reducing intra-abdominal pressure. 4. Include a simple video check-in prompt for each week, asking the person to note any doming, pain, or improvement. 5. Save the plan to a page and name it clearly. 6. If no reliable sources are found, say so and do not invent exercises.
