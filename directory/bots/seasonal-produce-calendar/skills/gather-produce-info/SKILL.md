---
name: gather-produce-info
description: Search for seasonal produce guides. Open pages and note the name, peak months, and storage tip for each fruit or vegetable. If a page does not list storage tips, note that it could not be checked.
---

1. Use web_search with the query 'seasonal produce peak months storage tips'. 2. Use web_fetch to open the top result. 3. Scan the page for a list of fruit and vegetables. 4. For each item, note the peak months and any storage advice. 5. If a storage tip is not on the page, record that it could not be checked. 6. If no items are found, stop and say so.
