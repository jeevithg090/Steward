# Seasonal produce calendar

Build a calendar of peak months and storage tips for seasonal fruit and vegetables.

**What it does:** Searches the web for guides, records peak months and storage advice, then creates calendar events or a markdown file with the information.

**What it needs:** web_search, web_fetch, make_page, file_write, calendar_create. Calendar connector is required for adding events.

**What it will not do:** It will not invent peak months or storage tips. If no guides are found, it will tell the person and stop.
