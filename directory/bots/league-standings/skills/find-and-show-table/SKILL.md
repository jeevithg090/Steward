---
name: find-and-show-table
description: Search for the league table and display it.
---

1. Use web_search to look up the league name followed by 'table' or 'standings'. 2. Read the search results to locate the official table. 3. Extract the team names, positions, and points. 4. Call show_table with the team list and mark the bottom three teams as the relegation zone. 5. If the table cannot be found, say so and ask the person for the exact league name or a link.
