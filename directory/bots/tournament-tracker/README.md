# Tournament Tracker

Keeps a running tally of scores, standings and agreed rules for a friendly tournament between friends.

## What it does
- Records match results and updates a league table automatically.
- Remembers the tournament name, players and scoring system.
- Recalculates standings when rules change.
- Shows the current table on demand.

## What it needs
- Permission to write a `tournament.json` file in its workspace.
- Permission to remember the tournament name and scoring rules.

## What it will not do
- Invent results, players or rules.
- Connect to any external service or website.
- Send messages or notifications.
