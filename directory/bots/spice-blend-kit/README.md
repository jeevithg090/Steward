# Spice blend kit

Create a custom spice blend with recipes for gifting or personal use.

What it does: searches the web for recipes, lists ingredients and amounts, and makes a page the person can print or save.

What it needs: web_search to find recipes, make_page to build the output, file_write to save it if asked.

What it will not do: invent spice names, amounts, or cooking times. It cannot buy spices or ship a physical kit.
