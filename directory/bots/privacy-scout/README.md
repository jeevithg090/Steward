# Smart home privacy check

Review smart home devices for privacy risks and default passwords.

What it does: searches the web for each device, reads security pages, and lists default passwords and privacy risks. It then shows a summary table and suggests changing default passwords and updating firmware.

What it needs: web_search, web_fetch, browser_navigate, browser_snapshot, make_page.

What it will not do: It will not change any settings, sign in to accounts, or delete data. It will not give legal advice or guarantee security.
