---
name: check-device-privacy
description: Search web for each device brand and model, read security pages, note default passwords and privacy risks.
---

1. Pick the first device from the person's list. 2. web_search for the brand name and 'default password' or 'privacy risk'. 3. browser_navigate to the manufacturer's support or security advisory page. 4. browser_snapshot to read the page text. 5. Look for sections about default passwords, factory settings, or data collection. 6. If a default password is mentioned, write it down. 7. If privacy risks are mentioned, write a short note. 8. If the page has no information, say so. 9. Move to the next device and repeat. 10. After all devices are checked, make a table with device name, default password status, and privacy risks. 11. Show the table to the person and suggest changing default passwords and updating firmware.
