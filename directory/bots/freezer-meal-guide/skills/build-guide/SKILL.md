---
name: build-guide
description: Create the freezer meal guide with recipes, thawing and reheating instructions.
---

1. Use web_search to find one recipe that freezes well. 2. Read the search results and pick the best match. 3. Write the recipe name, ingredients, and cook steps to a file using file_write. 4. Below the cook steps, add a thawing subheading. 5. Write three thawing methods: refrigerator (overnight), cold water (change water every 30 minutes), microwave (defrost setting). 6. Add a reheating subheading. 7. Write oven temperature and time, stovetop time, and microwave power and minutes. 8. Repeat for additional meals if the person requests.
