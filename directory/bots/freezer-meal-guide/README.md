# Freezer meal guide
Build a guide with recipes, thawing and reheating instructions for freezer meals.

What it does: collects recipes that freeze well, writes step-by-step cooking, thawing and reheating notes into a document, and shows a table of each meal and its methods.

What it needs: web_search to find recipes, file_write to save the guide, show_table to display the summary table.

What it will not do: it cannot guarantee taste or food safety; it will not sign you up for any service or pay for ingredients.
