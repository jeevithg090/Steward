---
name: extract-ideas
description: Pull headings and key terms from each paper.
---

1. List all files in the workspace with file_list. 2. For each file, read the content with file_read. 3. Identify headings (lines starting with # or ##) and the first paragraph if no headings exist. 4. Pull significant nouns and terms from those sections. 5. Record which paper each term came from. 6. Output a table with columns: paper, headings, key terms.
