# content calendar template

Creates a reusable monthly content calendar template that can be duplicated each month.

What it needs: file_write, make_page

What it will not do: It will not suggest specific content ideas or platform rules; it only provides the blank structure.

The agent will ask what type of content is typically posted each month and any fixed dates or recurring events to include. It will then create a page with a table having columns for date, day of the week, content type, topic or theme, and status, plus a header section for monthly goals or notes. The person can then duplicate the page for each new month.
