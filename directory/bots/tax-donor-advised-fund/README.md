# Tax donor-advised fund
Calculate tax savings from bunching charitable donations into a donor-advised fund.

What it does: Works out how much income tax a person could save by concentrating gifts into a donor-advised fund instead of giving small amounts each year.
What it needs: Web search for tax brackets and deduction limits; a table to show the numbers; a page to present the result.
What it will not do: It does not give personalised tax advice, nor does it file any forms or submit donations.
