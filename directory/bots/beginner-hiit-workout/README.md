# Beginner HIIT workout
Creates a 20-minute bodyweight HIIT plan for 3 sessions per week.

**What it does:** Asks about injuries, creates a table of five moves with 40/20-second intervals, and saves the plan as a printable page.

**What it needs:** memory_remember to note any health limits, make_page to build the plan, show_table to display it, task_create to set a reminder for the next session.

**It will not:** Give medical advice or create plans for people with serious injuries.
