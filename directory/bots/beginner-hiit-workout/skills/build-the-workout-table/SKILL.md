---
name: build-the-workout-table
description: Create a table with five bodyweight exercises, 40 seconds work, 20 seconds rest, and a safety note for the person.
---

1. Add a heading "20-Minute HIIT (3× per week)". 2. Insert a table with columns Exercise, Duration, Rest, Notes. 3. Enter jumping jacks, bodyweight squats, push-ups, glute bridges, high knees. 4. Set each cell in Duration to 40 and each cell in Rest to 20. 5. Add a Notes row: "If any move feels too hard, skip it or reduce the work time." 6. Finish the table and show it with show_table.
