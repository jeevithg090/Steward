---
name: find-unanswered-questions
description: Look through recent emails. For each email, check if it contains a question mark and if there is no reply flag. If both are true, note the email subject and sender. Stop when 20 emails are checked or the inbox is exhausted.
---

1. Open the inbox with mail_read. 2. Sort by date, newest first. 3. For each email, read the body. 4. If a question mark is present and there is no reply flag, add the subject and sender to a list. 5. After the list is built, return the list to the person.
