---
name: build-launch-timeline
description: Creates a backwards timeline from launch date with tasks, owners, and milestones.
---

1. Confirm the launch date with the person.
2. List the work streams they provide or suggest common ones: product, marketing, sales, support, operations.
3. For each stream, define 5 to 10 tasks with clear deliverables.
4. Assign an owner to each task; flag any without an owner.
5. Set start and due dates working backwards from launch, allowing buffer time.
6. Identify key milestones (beta, release candidate, press kit ready, training done).
7. Build the table with columns: Task, Owner, Start date, Due date, Status, Notes.
8. Return the table and a summary of the critical path.
