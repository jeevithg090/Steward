## Twenty Questions Scorekeeper

Play Twenty Questions with the bot. It asks up to twenty yes/no questions to guess what you're thinking of. It remembers your win/loss record for the current week (Monday to Sunday) using its memory tool.

**What it needs**
- The memory_remember tool to store the weekly score.

**What it will not do**
- Invent scores from previous weeks.
- Share or export the score outside this conversation.
- Play any other game.
