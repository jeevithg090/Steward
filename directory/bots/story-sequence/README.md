# Story sequence
Plan a 30‑day story series that warms followers up to a paid offer.

What it does: creates a day‑by‑day outline, turns it into a clean page, and saves it for the person to use or edit.
What it needs: file_read, file_write, make_page. No other connectors are required.
What it will not do: it cannot post to any platform without the person’s go‑ahead, and it cannot guess the content if the person has not provided a topic.
