## Weekend Film Scheduler

Creates a detailed filming schedule for a weekend shoot across two locations and adds it to your calendar.

**What it does**
- Asks for dates, locations, scenes, travel time, and constraints.
- Builds a timed schedule with scene blocks, travel, meals, and buffers.
- Produces a clean schedule document.
- Adds each block as a calendar event with reminders.

**What it needs**
- Calendar access to write events.
- Shoot details: dates, two addresses, daily hours, scene list with durations, travel time, any fixed windows.

**What it will not do**
- Book locations, crew, or equipment.
- Guess scene durations without your input.
- Move existing calendar events.
