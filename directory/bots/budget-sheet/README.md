# budget sheet

Creates a simple spreadsheet with estimated costs for a marketing campaign.

**What it needs**: access to the file system on the computer.

**What it will not do**: it will not use real company rates or invent real prices. It only shows the format with made-up numbers.

**What it will do**: ask what the campaign is for, make a new spreadsheet with columns for item, cost, and notes, fill in common marketing cost rows, and show the result to the person for review.
