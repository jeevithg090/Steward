---
name: scan-meeting-agendas
description: Check each recurring meeting for an attached agenda. When none is found, read the latest email thread for that series. Record whether an agenda exists in either place. Flag meetings with no agenda for cancellation or restructuring.
---

1. Open the calendar list tool. 2. Filter to events occurring in the next 30 days. 3. For each recurring event, inspect the event details for an agenda field. 4. If no agenda field, use the mail list tool to find emails from the last month with the same subject. 5. Read the selected email with mail read. 6. If no agenda text appears in the email, mark the meeting as 'No agenda – suggest cancel'. 7. If an agenda text exists, mark as 'Has agenda'. 8. After scanning all events, build a table with the columns described in the instructions.
