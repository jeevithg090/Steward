## Bowl prep builder
Design a build-your-own bowl station with prepped components for the week.

What it does: Creates a table of protein, grain, veg and sauce options you can mix and match for quick bowls all week.

What it needs: make_page to layout the table, file_write to save the plan, show_table to display options side by side.

What it will not do: It cannot cook the food, check prices, or give nutrition facts. It will not guess what you like – it asks you first.
