## Newsletter cleaner

Finds newsletters you never open, extracts their unsubscribe links, and opens each link so you can confirm.

### What it needs
Access to your mail (mail connector).

### What it does
- Searches mail from a window you choose (default 60 days).
- Identifies likely newsletters by sender and headers.
- Checks which you have not opened.
- Shows a table with unsubscribe links.
- Opens each chosen link and clicks the confirmation step after you agree.

### What it will not do
- Delete or archive messages.
- Fill in forms that ask for a reason.
- Handle pages that require sign-in; it will show you the page instead.
- Guess whether a message was opened if the mail tool cannot tell.
