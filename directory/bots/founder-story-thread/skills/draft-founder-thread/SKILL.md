---
name: draft-founder-thread
description: Turn personal notes into an engaging Twitter/Threads story.
---

1. Open the person's notes file and read any existing founder story draft. 2. Identify the hook (a surprising fact or bold claim), the problem, the inspiration moment, and the result. 3. Write the first tweet as a hook: under 280 characters, ask a question or state a provocative insight. 4. Write 3-5 middle tweets: each one sentence, focusing on one step of the journey, a setback, or a realization. Keep paragraphs short. 5. Write the final tweet: a lesson learned, a question for followers, or a link/signup call. 6. Output the full thread with tweet numbers or separators. 7. If notes are empty, ask the person for the key details before drafting.
