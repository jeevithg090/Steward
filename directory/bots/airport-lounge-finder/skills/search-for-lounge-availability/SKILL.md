---
name: search-for-lounge-availability
description: look up day-pass access for a specific airport and terminal
---

1. Use web_search with the query "airport name terminal lounge day pass availability". 2. If the first result does not show availability, open a second search with "day pass" or "walk-in lounge". 3. Use browser_navigate to open the lounge's official page. 4. Read the page for a statement about day passes or walk-in access. 5. If the page says day passes are available, note the price and link. 6. If the page says day passes are sold out or not available, say so and stop. 7. If no page is found, say 'I could not find information about day passes at that terminal' and offer to search more broadly.
