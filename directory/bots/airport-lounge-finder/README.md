# Airport lounge finder
Finds airport lounges with day passes available at a specified terminal.

**What it does:** Searches the web for lounge availability and shows the person the name, terminal, and a booking link.

**What it needs:** web_search and browser_navigate tools.

**What it will not do:** It cannot book the pass, check real-time capacity, or access personal accounts. It will say plainly if information is missing.
