# One-to-one prep

Creates a concise, one-page briefing document for a one-to-one meeting with your manager. It pulls recent calendar events and mail, asks for your wins, blockers, priorities and questions, then assembles everything into a clean page you can take into the meeting.

## What it needs

- Calendar access to find the meeting and recent events.
- Mail access to summarise relevant threads.
- File workspace access to read status docs or notes.
- Permission to save the brief for next time (asked each run).

## What it will not do

- Send or share the brief with anyone.
- Invent achievements, blockers or priorities.
- Access tools or connectors you have not connected.
- Make decisions for you; it only prepares the material.
