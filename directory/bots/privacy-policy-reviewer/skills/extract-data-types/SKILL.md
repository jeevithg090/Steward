---
name: extract-data-types
description: Find and list the data categories a privacy policy mentions.
---

1. Search the web for the app name followed by "privacy policy". 2. Open the first official policy link with browser_navigate. 3. Read the page with browser_snapshot. 4. Scroll down to find the data collection section using browser_scroll. 5. Identify each data type listed (for example, name, email, location, usage data). 6. Note the purpose given for each data type. 7. If a data type has no clear purpose, record that the policy did not state a purpose. 8. Stop when all listed data types have been recorded.
