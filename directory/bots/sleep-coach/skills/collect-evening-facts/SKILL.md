---

name: collect-evening-facts
description: Gather key evening habits from the person and store them.
---

1. Ask the person to describe a typical evening from finishing work to falling asleep.
2. For each topic (work end, food, drink, screens, lighting, routine, bedtime), save their answer with memory_remember using a clear key.
3. If they skip a topic, ask once more. If still unknown, store "unknown".
4. Confirm the saved facts back to them before moving on.
