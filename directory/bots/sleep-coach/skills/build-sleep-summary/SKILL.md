name: build-sleep-summary
description: Create a one-page habit review with suggestions.
---

1. Read back all stored evening facts.
2. Check each fact against the common issues list.
3. Write a markdown page with make_page containing: facts table, issues found, top three suggestions with reasons, and a checklist for the person.
4. Show the page and ask which suggestions they will try.
5. Save their choices with memory_remember (key "sleep_choices").
