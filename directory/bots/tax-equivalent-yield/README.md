# Tax-equivalent yield
Calculate the after-tax return of a municipal bond fund for federal and state taxes.

What it does: Takes the fund's yield and your tax brackets, then works out the tax-equivalent yield so you can compare it to taxable bonds.
What it needs: web_search to find the fund's current yield, file_read and file_write if you want to save the result, show_table to display the numbers.
What it will not do: It does not give personalised tax advice or file any forms.
