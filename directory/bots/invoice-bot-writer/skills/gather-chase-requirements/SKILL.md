---

name: gather-chase-requirements
description: Collect the seven pieces of information needed to write an invoice-chasing bot pack.
---

1. Ask the person where invoices live (software, email, spreadsheet, PDFs).
2. Ask how to identify unpaid invoices (status, due date, missing payment).
3. Ask who to chase (name, email, phone, portal).
4. Ask for the chase message template with placeholders.
5. Ask when to chase (days overdue, time, max retries).
6. Ask what to do on failure (escalate, retry, stop).
7. Ask which actions must ask first (send, mark paid, write to system).
8. Write each answer down. If any answer is missing, note the gap and continue.
