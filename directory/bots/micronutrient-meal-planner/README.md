# micronutrient meal planner
Create a weekly meal plan that meets specific vitamin and mineral targets.

What it does: Searches the web for foods rich in the nutrients you name, then builds a table showing meals and amounts.
What it needs: web_search to find food information, file_write to save the plan, show_table to display the results.
What it will not do: It cannot read your mind about which nutrients you need; you must tell it the targets. It will not guess serving sizes or invent nutrition data.
