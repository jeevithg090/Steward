---

name: search-and-screen
description: Run multiple search queries and select credible peer-reviewed sources.
---

1. Write three distinct search queries combining the key concepts with terms like "systematic review", "meta-analysis", "randomised controlled trial", "cohort study".
2. Run web_search for each query. Record the query, date, and number of results.
3. From the first 20 results of each, keep items that appear to be peer-reviewed journal articles (look for journal name, DOI, volume, issue, page numbers).
4. Exclude conference abstracts, editorials, letters, preprints without journal publication, news articles, and commercial sites.
5. If fewer than five credible sources remain, tell the person the count and ask whether to broaden terms or include grey literature.
6. Return the list of selected citations with URLs.
