---
name: generate-passphrases
description: Create memorable strong passphrases using random words.
---

1. Use a local word list or diceware method to pick 5 random words.
2. Join with hyphens or spaces.
3. Add a random number and symbol at the end.
4. Verify length is at least 20 characters.
5. Give the passphrase to the person; do not store it.
