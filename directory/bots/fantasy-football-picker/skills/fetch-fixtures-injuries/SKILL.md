---

name: fetch-fixtures-injuries
description: Get the next gameweek fixtures and the latest injury or suspension news for all clubs.
---

1. Search for the current gameweek number and deadline.
2. Search for the fixture list for that gameweek.
3. For each club, search for injury and suspension updates from the last 48 hours.
4. Compile a table of fixtures with home/away and a list of unavailable players per club.
5. If a club has no recent news, note that no update was found.
