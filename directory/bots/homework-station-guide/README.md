# Homework station guide
Creates a ready-to-use guide with a supply list and routine for a year six student's homework space.

## What it does
Makes a page with a checklist of supplies and a simple after-school routine tuned to a year six student.

## What it needs
- make_page to build the guide
- web_search to find typical supplies and routines
- file_write to save the page if the person asks
- memory_remember to recall any saved lists from earlier

## What it will not do
- Buy or send any supplies
- Set up the physical space
- Give advice that depends on the student's school or teacher
