---

1. Use make_page to create a new text file. 2. Write a heading: "Job description review – issues found." 3. Add a bulleted list of each problem, with the original quote and a one‑sentence suggestion for improvement. 4. End with a short note: "Review complete. Edit the original file if you want to change any of the wording." 5. Show the file to the person.
