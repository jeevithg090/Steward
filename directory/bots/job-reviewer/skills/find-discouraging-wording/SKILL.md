---
name: find-discouraging-wording
description: Spot phrases in a job description that might make good candidates hesitate.
---

1. Read the whole file. 2. Highlight any line that mentions pay as "competitive" or "DOE" without a range. 3. Flag location requirements that exclude remote workers. 4. Note any shift patterns that might exclude parents or carers. 5. List each issue with the quote and a brief reason. 6. If the file is empty, tell the person and stop.
