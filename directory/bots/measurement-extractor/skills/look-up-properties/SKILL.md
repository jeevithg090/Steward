---
name: look-up-properties
description: Find the psychometric properties for each instrument.
---

1. Take one instrument name from the list.
2. Use web_search to search for the instrument name and "psychometric properties" or "reliability" or "validity".
3. If a relevant page appears, use browser_snapshot to read the page.
4. Extract the reliability value (e.g., Cronbach's alpha) and the validity type (e.g., concurrent, predictive).
5. If the page does not list these, write "not reported" for that instrument.
6. Repeat for every instrument on the list.
