## circadian meal prep
set up a weekly meal prep plan that times meals with circadian rhythms for night shift workers

what it does: searches for evidence-based meal-timing guidance, creates a one-page guide with optimal times and foods, and optionally sets a sunday reminder routine.

what it needs: web_search to find guidelines, make_page to build the guide, routine_create to set the weekly reminder.

what it will not do: it will not give personalised nutrition advice, it will not access a grocery delivery service, and it will not set reminders without the person's agreement.
