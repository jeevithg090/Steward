---
name: draft-three-endings
description: Create three plot paths for a CYOA story.
---

1. Ask the person for the main character, setting, and desired tone (funny, dark, adventurous). 2. If nothing is provided, propose a generic setting like a haunted house or a lost island and let the person approve or change it. 3. Outline three distinct paths from the start to three different endings. 4. Write each path using second-person present tense, offering two choices at every branch. 5. Ensure each ending is meaningfully different (e.g., victory, sacrifice, escape). 6. Combine the three paths into one continuous narrative with clear branch points marked by 'Choose: A or B'. 7. Save the completed story to 'cyoa-story.txt' using file_write.
