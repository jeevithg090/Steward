---
name: write-script-draft
description: Turn the person's topic and tone into a short script.
---

1. Read the topic and tone the person gave. 2. Write an opening line that states who the video is for and what problem it solves, under 20 words. 3. Add two to three bullet points that explain the main benefit, each under 20 words. 4. Finish with a one‑sentence call to action, under 20 words. 5. Check that every sentence is under 20 words. 6. If any sentence is longer, split it into two shorter sentences. 7. When the script is ready, make a page with the script as the only content. 8. Save the script as a plain‑text file named intro_script.txt using file_write.
