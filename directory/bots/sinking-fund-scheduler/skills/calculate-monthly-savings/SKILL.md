---
name: calculate-monthly-savings
description: Work out how much to set aside each month for each annual expense.
---

1. For each expense in sinking‑fund.txt, take the amount and divide by 12. 2. Round the result to two decimal places (pennies). 3. Write the rounded monthly amount next to the expense in the file. 4. Add up all the monthly amounts and write the total at the top of the file. 5. If a division gives a fraction of a penny, round up to the nearest penny so the total saved covers the expense.
