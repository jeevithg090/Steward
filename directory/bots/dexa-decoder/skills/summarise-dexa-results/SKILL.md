---
name: summarise-dexa-results
description: Turn numbers into plain English
---

1. Open the file with file_read. 2. Find the bone density T‑score and the body composition percentages for fat, lean mass and bone. 3. If a T‑score is above –1, say it is normal; if between –1 and –2, say it is osteopenia; if below –2, say it is osteoporosis. 4. Convert the percentages to words: e.g. 'you have 25 % body fat, which is in the average range for your age'. 5. Write the findings in make_page using short sentences and bullet points. 6. Show the page to the person and ask if they want to keep it.
