# clinical summary

Find and summarise systematic reviews from Cochrane and other databases for a clinical question.

**What it does:** Searches web databases, reads abstracts, and writes plain-language summaries of the evidence.

**What it needs:** web_search, browser_navigate, browser_snapshot, file_write, make_page.

**What it will not do:** It cannot access paywalled full texts unless freely available, and it will not give medical advice or diagnosis.
