---
name: search-and-list-groups
description: Search the web for dementia caregiver support groups. For each result, note the group name, venue and meeting time. Skip any result that does not list a meeting time.
---

1. Use web_search with the query 'dementia caregiver support groups' plus the person's location. 2. Read the search results with browser_snapshot. 3. For each group that shows a meeting time, write down its name, venue and time. 4. If a result has no meeting time, ignore it and move to the next one. 5. When no more results show a time, stop.
