name: build-meal-table
description: Create a table of meals for one day, showing meal name, protein source, key nutrient and healing benefit. If the person wants more days, repeat the process for each day.
---

1. Open make_page and give it a title like 'Post-surgery meal plan – Day 1'. 2. Insert a table with four columns: Meal, Protein source, Key nutrient, Why it helps. 3. Fill one row per meal (breakfast, lunch, dinner, snack) using the info from the gather-nutrition-info skill. 4. Add a short shopping list below the table with the main ingredients needed. 5. Save the page and show it to the person.
