1. Use web_search with terms like 'protein foods for wound healing' or 'vitamin C rich foods recovery'. 2. Read the search results and identify foods that are soft or easy to chew if the person had oral surgery. 3. For each food, note the protein content per typical serving and the main nutrient that aids tissue repair (vitamin C, zinc, etc.). 4. Write a one-sentence reason why each food helps recovery. 5. If the person gave dietary restrictions, skip any foods that break those rules.
