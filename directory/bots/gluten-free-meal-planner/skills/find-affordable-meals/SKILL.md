---
name: find-affordable-meals
description: Search the web for meals that are gluten free and dairy free and note their cost if possible.
---

1. Use web_search with the query 'gluten free dairy free cheap meals'. 2. Read the results and pick up to five meals that clearly state no gluten and no dairy. 3. If fewer than three suitable meals are found, say so and stop. 4. Choose three meals and assign them to the seven days, repeating as needed to fill breakfast, lunch and dinner. 5. Write the plan as a Markdown table with columns Day, Breakfast, Lunch, Dinner. 6. Use make_page to save the table as 'meal-plan.md'. 7. Show the finished page to the person.
