---
name: build-spreadsheet
description: Write a CSV with the collected expenses, sorted by date.
---

1. Open a new file with file_write and give it a name like 'travel-expenses.csv'. 2. Write the header row: date, vendor, amount, notes. 3. Write one row per receipt with the data gathered. 4. Sort the rows by the date column, earliest first. 5. Close and save the file. 6. Tell the person the spreadsheet is ready and show the table with show_table.
