# ETF expense compare
Compare zero-commission ETFs' expense ratios and bid-ask spreads across three brokers.

What it does: searches the web for cost data from up to three brokers and presents it side by side.
What it needs: web search, a comparison table tool, and the ability to write a short text file.
What it will not do: it cannot give financial advice, it cannot check real-time prices after the search, and it cannot open accounts or make trades.
