---
name: gather-kit-details
description: For each kit found, open the product page, read the price and the hormones measured, and note any accuracy claims or certifications. If any of these are not stated, record what is missing. Stop after eight kits or when no more results appear.
---

1. Use web_search to look for "at-home hormone test perimenopause". 2. From the results, pick a kit and use browser_navigate to open its product page. 3. Use browser_snapshot to read the page and extract the price, the list of hormones measured, and any accuracy or certification claims. 4. If the price is not shown, write "price not stated". If no accuracy claim is shown, write "accuracy not stated". 5. Record the data. 6. Repeat for up to eight kits or until no more results are available.
