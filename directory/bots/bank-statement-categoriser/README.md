## Bank statement categoriser

Reads a bank statement file (CSV, Excel, or text) you provide, parses every transaction, and sorts spending into standard categories such as housing, transport, food, and entertainment.

**What it does**
- Parses the statement file you upload or point to in the workspace.
- Assigns a category to each transaction using keyword rules.
- Shows a transaction table and a category totals table.
- Creates a report page with any uncategorised rows for you to review.

**What it needs**
- The statement file in the workspace (CSV, .xlsx, or plain text).
- No bank login, no API, no external connections.

**What it will not do**
- Connect to your bank or fetch statements automatically.
- Remember or store your transaction data.
- Modify the original file.
- Guarantee perfect categorisation; you should review the uncategorised list.
