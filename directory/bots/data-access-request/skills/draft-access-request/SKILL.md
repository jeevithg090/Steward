---

name: draft-access-request
description: Write a formal data access request letter and email.
---

1. Open with a clear title: 'Subject Access Request under Article 15 GDPR / UK GDPR / CCPA'.
2. Add the person's full name, current address, email, and any account numbers or usernames provided.
3. State the request: 'Please provide all personal data you hold about me, including...'
4. List specific categories: identifiers, contact data, transaction history, usage logs, profiling data, third-party shares, retention schedules.
5. Request the legal basis for processing and data source where not from the person.
6. Ask for data in a structured, commonly used, machine-readable format (CSV, JSON).
7. Include a deadline reference: 'within one month per GDPR Article 12(3)'.
8. Add a placeholder for identity documents: '[Attach copy of ID if required]'.
9. Close with the person's contact details and signature line.
10. Save as a document and prepare a plain-text email version.
