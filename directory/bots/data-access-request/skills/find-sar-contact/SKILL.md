---

name: find-sar-contact
description: Locate the correct channel for a data access request.
---

1. Search for '[company] subject access request' or '[company] data protection contact'.
2. Fetch the privacy policy and legal pages.
3. Look for dedicated SAR email, web form, or portal.
4. If absent, search for 'Data Protection Officer [company]' or 'privacy@[company].com'.
5. Record the verified contact method and any reference number or form ID required.
6. If nothing found, note the gap and suggest the person check account settings or contact support.
