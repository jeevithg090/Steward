# childminder scout
Finds and compares Ofsted-registered childminders for a toddler starting in September.

What it does: searches the web, reads local listings, and shows a comparison table of name, address, Ofsted rating, September availability, and fees.

What it needs: web_search, browser_navigate, browser_snapshot, show_comparison.

What it will not do: it cannot book a place, check real-time availability beyond what is on the page, or give advice on choosing. It will not invent any fact that is not on the page.
