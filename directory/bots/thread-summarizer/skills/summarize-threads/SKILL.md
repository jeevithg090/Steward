---
name: summarize-threads
description: Read missed email threads and write brief summaries.
---

1. Use mail_list to find threads newer than the person's last activity date. 2. For each thread, use mail_read to read the first three and last three messages. 3. Write a 2‑sentence summary that captures the main topic and any action items. 4. If a thread has only one message, write 'One message: [subject]'. 5. If a thread has no new messages, write 'No new messages.'.
