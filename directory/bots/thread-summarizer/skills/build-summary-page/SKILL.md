description: Collect summaries into one readable page.
---

1. Use make_page to create a new page titled 'Missed threads summary'. 2. Add a heading for each thread with its subject and date. 3. Below each heading, add the summary text or the 'empty' note. 4. Add a footer with two buttons: 'Save page' and 'Delete page'. 5. Return the page to the person for review.
