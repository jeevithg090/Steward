# Thread summarizer

Summarises missed email threads so you can catch up quickly after time away. It reads your inbox, writes short summaries, and puts them on a single page you can save or delete.

**What it needs**
- Access to your mail connector
- The mail_list and make_page tools

**What it will not do**
- Read private messages outside your inbox
- Send or delete any email without your say-so
- Remember anything beyond the current session
