name: bakery-hashtag-research
description: Finds relevant local and niche hashtags for bakery content
---

1. Search web for '[city] bakery hashtags', '[city] foodie', '[city] eats', 'artisan bread [city]'
2. Search for niche tags: 'sourdoughprocess', 'laminatedpastry', 'bakerybehindthescenes', 'supportlocalbakeries'
3. Compile 30-40 hashtags organised by pillar: Product, Educational, Community, Local, Seasonal
4. Note hashtag volume estimates (broad 100k+, niche 10k-50k, local 1k-10k)
5. Create hashtag sets of 5-8 tags per post type for easy copy-paste
6. If web search fails, provide evergreen bakery hashtag sets with placeholders for local tags
