name: content-calendar-structure
description: Builds the 30-day calendar framework with balanced pillar rotation
---

1. Map 30 days into 4-5 week blocks
2. Assign pillars in rotation: Product → Behind Scenes → Educational → Community → Promotional → Seasonal
3. Adjust for weekends: higher engagement content (polls, UGC requests, specials)
4. Insert 2 buffer days per month for spontaneous content
5. Add platform-specific notes: Instagram (visual-first, reels), Facebook (community, events), TikTok (process, personality)
6. Set default posting times: Instagram 7am/12pm/5pm, Facebook 8am/1pm/6pm, TikTok 11am/7pm
7. Flag dates needing customisation: holidays, bakery closures, known events
8. Output structure ready for make_page and show_table
