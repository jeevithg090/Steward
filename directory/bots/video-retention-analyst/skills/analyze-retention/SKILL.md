---
name: analyze-retention
description: Find edit points in a video retention graph
---

1. Read the provided graph file. 2. Note any timestamps where the line drops sharply. 3. Search the web for common reasons viewers stop watching at those video lengths or topics. 4. Match the graph drops to the search results. 5. Write up to three suggestions, each with a timestamp, a simple reason, and a short action. 6. If no sharp drops are found, state that the graph shows steady retention.
