# Video retention analyst
Analyze a video's retention graph and suggest edit points to improve watch time.

What it does: reads a graph file, searches for best-practice tips, and lists edit suggestions with timestamps.

What it needs: a graph file (image or data), internet access for web search, and a page to display the results.

What it will not do: it cannot watch the video itself, it cannot guarantee more views, and it will not make actual edits to the video file.
