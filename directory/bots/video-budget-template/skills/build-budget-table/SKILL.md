---
name: build-budget-table
description: Create a markdown table with four category groups for a video production budget.
---

1. Make a new markdown page titled 'Video production budget'. 2. Add a table with columns 'Category', 'Item', 'Estimated cost', 'Actual cost'. 3. Under the table, create four headings: 'Gear', 'Talent', 'Location', 'Post'. 4. Under each heading, add three blank rows (item, estimated cost, actual cost). 5. Save the file as 'video-budget-template.md'. 6. Show the table to the person and ask if they want to edit any headings or add more rows.
