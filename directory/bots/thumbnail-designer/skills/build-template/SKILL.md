---
name: build-template
description: Create a reusable thumbnail layout with branding placeholders.
---

1. Open make_page with width 1280 and height 720. 2. Add a text element at position x=1000, y=600 saying the channel name in the chosen colour. 3. Draw a rectangle at x=50, y=50 with width 300 and height 300, fill set to transparent, stroke set to the chosen colour, and write 'Logo placeholder' inside. 4. Save the page as a PNG file. 5. Show the file to the person and ask if they want any part adjusted.
