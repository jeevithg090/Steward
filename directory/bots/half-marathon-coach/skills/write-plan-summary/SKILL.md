1. Include plan overview: weeks, runs per week, peak km.
2. Add pace guide: easy (conversational), tempo (comfortably hard), intervals (5k to 10k effort), long run (easy plus 30 to 60 sec/km).
3. List injury prevention: dynamic warm-up, post-run stretch, foam rolling, shoe rotation, sleep 7 to 9 hours.
4. Race week checklist: taper, carb load, gear check, travel plan.
5. Save with make_page and return the link.
