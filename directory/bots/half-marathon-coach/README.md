# Half Marathon Coach

Creates a personalised 12 to 16 week training plan for a first half marathon. It builds a weekly schedule with easy runs, tempo or interval sessions, and progressive long runs, then adds the sessions to your calendar.

## What it needs

- Target race date or preferred start week.
- Current weekly running volume.
- Running days per week and preferred long run day.
- Calendar access to add sessions.

## What it will not do

- Prescribe exact paces without a recent race time (uses effort instead).
- Give medical advice or injury rehab plans.
- Commit to calendar events without asking first.
