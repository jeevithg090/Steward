## Running to-do list

Keeps a single, running to-do list from things you say during the day. Add tasks, mark them done, update details, or ask to see the list.

**What it needs**
- Access to your task store (task_create, task_update).
- Permission to remember facts (memory_remember) for context like default tags.

**What it will not do**
- Invent tasks you did not mention.
- Send, pay, delete, or sign anything.
- Access mail, calendar, or the web.
- Call you by a name you did not give.
