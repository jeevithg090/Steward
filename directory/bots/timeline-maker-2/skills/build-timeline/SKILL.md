---
name: build-timeline
description: Turn the dates into a markdown timeline.
---

1. Sort all collected dates chronologically. 2. For each date, write a line starting with the date, a dash, and the label (event name or email subject). 3. Use make_page to write this markdown to a file called timeline.md in the workspace. 4. If a date could not be verified, add a line saying 'DATE (not verified) – LABEL'.
