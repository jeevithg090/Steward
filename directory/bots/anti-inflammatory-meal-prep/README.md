# Anti-inflammatory meal prep

Plans a week of anti-inflammatory meals with batch cooking steps and a cost breakdown. Searches for guides and typical ingredient prices, builds a seven-day menu, and writes the output to a text file.

**Needs**: web_search, make_page, show_table, file_write

**Will not do**: invent ingredient prices or calorie counts; it will write 'price unknown' when a price cannot be checked.
