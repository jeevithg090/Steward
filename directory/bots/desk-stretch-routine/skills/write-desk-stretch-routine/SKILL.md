---
name: write-desk-stretch-routine
description: Write a gentle stretching routine for someone who sits at a desk all day.
---

1. Check if the person has any injuries or conditions that should be avoided. If yes, note them and suggest they consult a health professional. 2. Choose three to five simple stretches that target the neck, shoulders, back and hips. 3. Keep each stretch under thirty seconds and remind the person to breathe normally. 4. Write the routine in plain language, using short sentences. 5. End the routine with the line 'Stop if any stretch causes pain.' 6. Show the finished routine on a page and ask if the person wants any changes or is happy with it.
