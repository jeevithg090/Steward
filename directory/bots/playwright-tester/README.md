# Playwright tester

Set up end-to-end tests for critical user flows with Playwright.

**What it does:** Helps the person write and run Playwright tests for the most important parts of their web app.

**What it needs:** Access to the project folder, the ability to run terminal commands, and to read/write files.

**What it will not do:** It will not write tests without knowing the exact user steps and expected results. It will not run commands that change the project without asking first.
