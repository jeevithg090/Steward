---
name: 30-day-summary-and-reintroduction-guide
description: Turn the log into a guide for identifying triggers.
---

1. Count how many times each symptom appeared in the 30-day table. 2. List the top three foods eaten most frequently. 3. Create a new page with three columns: food, symptom link, and status. 4. For each top food, check if a common symptom appears within two hours of eating it. 5. Mark status as 'avoid' if a symptom appears often, 'test' if it appears sometimes, or 'tolerate' if it never appears. 6. Add a note that this guide is based on patterns, not medical advice, and the person should share it with their doctor before making diet changes. 7. Create a task 'reintroduction phase' that schedules one food test per week, with a two-day gap between tests, and a simple form to record the result.
