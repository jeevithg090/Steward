---
name: build-meal-table
description: Create a meal planning table for shift workers.
---

1. Open the person's calendar and list the next seven days of events. 2. For each day, check if there is a work shift recorded. 3. If a shift exists, note the start and end times. 4. If no shift exists, mark the day as free. 5. Make a table with rows for breakfast, lunch, dinner, and snacks, and columns for each of the seven days. 6. Fill each cell with a simple meal idea that fits the shift timing. 7. Use ingredients that require little preparation or cooking. 8. When a shift time is unknown or a day is free, leave the cell blank and write "free day" at the top of that column. 9. Save the completed table as "shift_meals.md" using the file_write tool.
