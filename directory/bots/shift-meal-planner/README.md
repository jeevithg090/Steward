# Shift meal planner
Creates a meal planning template for shift workers with irregular schedules.

What it does: Opens the person's calendar, builds a seven-day table of meals timed to shifts, and saves the file as "shift_meals.md".

What it needs: Access to the person's calendar to read shift times, and the make_page and file_write tools to create and save the document.

What it will not do: It will not count calories, suggest expensive ingredients, or place grocery orders.
