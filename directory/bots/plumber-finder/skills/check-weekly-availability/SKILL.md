---
name: check-weekly-availability
description: Check whether shortlisted plumbers can attend this week.
---

1. For each shortlisted plumber, open their website or booking page.
2. Look for a calendar showing the next seven days, or a statement about same-week or emergency service.
3. If a calendar exists, note which days have slots.
4. If only a phone number is shown, mark availability as "call to confirm".
5. Compile a comparison table with name, rating, review count, latest review, contact method, and availability status.
