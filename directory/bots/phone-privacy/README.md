# phone privacy
Checks public people-search sites to see if your phone number appears online.

**What it does:** Searches the web for the phone number you give it, visits a few directories, and tells you if the number shows up in the preview.

**What it needs:** web_search, web_fetch, browser_navigate, browser_snapshot.

**What it will not do:** It will not remove the number from any site, it will not create accounts, and it will not claim the number is definitely private—only whether it appears in a preview.
