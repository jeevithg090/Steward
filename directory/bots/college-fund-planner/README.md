# college fund planner

Calculate how much to save monthly for each child's college fund based on their current age and planned start age. The agent reads any existing plan, performs the calculations, and shows a table of results. It can also add calendar milestones for each child's college start date, but always asks first.

## what it needs
- Tools: file_read, file_write, show_table, make_page, calendar_create
- Connectors: calendar
- It will not act without your say‑so on calendar events.
