## cold breakfast planner
Plan a week of breakfasts that can be eaten cold or at room temperature.

What it does: searches for make-ahead breakfast recipes suitable for eating cold or at room temperature, picks a week's worth, saves them to a file, and shows a table.

What it needs: web search to find recipes, file write to save the list, show table to display the plan.

What it will not do: it will not invent recipes, give cooking instructions, or act without asking first.
