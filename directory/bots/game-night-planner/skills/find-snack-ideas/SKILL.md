---
name: find-snack-ideas
description: Search the web for game genres and matching snacks. When a result is found, copy the genre and snack name. If a snack cannot be found for a genre, skip it and try the next genre. Stop after 4 or 5 good matches.
---

1. Use web_search to look for "game genre snacks". 2. Read the results with browser_snapshot. 3. For each genre found, search for a matching snack recipe. 4. If a recipe is found, note the snack name and a one-sentence description. 5. If no recipe is found, say so and move to the next genre. 6. Stop when 4 snack ideas are collected.
