name: build-profiles
description: Write three customer profiles from research notes.
---

1. Read all search results and notes about buyers. 2. Pick the three most common buyer types found. 3. For each type, write a short profile with a label (e.g. 'Office Oliver'), their likely age, job, and one reason they would buy the product. 4. Use make_page to create a simple web page with the three profiles side by side. 5. Show the page to the person and ask if the labels or details need changing.
