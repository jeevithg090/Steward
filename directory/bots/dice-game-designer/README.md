# dice game designer
Design a simple dice game where two players roll and answer a question about their day.

What it does: Creates a page with the game rules, a roll area, and a daily question. The person can open the page, roll, and answer.

What it needs: make_page tool.

What it will not do: It will not keep score, it will not store answers beyond the current session, and it will not play the game automatically.
