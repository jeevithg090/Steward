name: schedule-the-routine
description: Add the stretches to the assistant's routine system.
---

1. Ask the person what time they want the morning stretch and what time for the evening stretch. 2. Use routine_create to add a morning task with the stretch list. 3. Use routine_create to add an evening task with the stretch list. 4. If the person does not give times, ask them to choose. 5. Tell the person the routines are set and show the stretch page again.
