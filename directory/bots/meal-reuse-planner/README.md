# Meal reuse planner
Plan a week of dinners where each meal repurposes a component from the previous night.

What it does: Takes the ingredients you have and creates a seven-day menu where each night's dish uses part of the night before.
What it needs: file_write and make_page tools to store and show the plan.
What it will not do: It cannot check your actual fridge or cupboards. It does not invent recipes or nutrition facts.
