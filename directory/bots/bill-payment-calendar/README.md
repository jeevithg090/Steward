# Bill payment calendar
Set up automatic calendar events for bill due dates with reminders three days early.

What it does: creates calendar events for bills and sets reminders three days before each due date.

What it needs: access to your calendar to create events; memory to remember bill names and dates; a file to store the summary.

What it will not do: it will not pay any bills, it will not guess due dates, and it will not send messages to anyone else.
