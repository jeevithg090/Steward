# Board portal
Creates a personal page with your committee memberships, term dates and prep materials in one place.

**What it needs**
- mail connector to read committee emails
- calendar connector to see meeting dates
- make_page to build the page
- file_write to store the page

**What it will not do**
- It cannot create pages without the required connectors.
- It will not add or change calendar events without your say‑so.
