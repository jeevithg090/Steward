---
name: gather-committee-data
description: Collect committee memberships from mail, term dates from calendar, and prep documents from attachments.
---

1. Use mail_list to scan for emails with subjects or senders mentioning committees. 2. For each email, use mail_read to read the body and list any attachments. 3. Use calendar_list to find recurring events that match the committee names. 4. Record the start and end dates of each term and the location of any prep files.
