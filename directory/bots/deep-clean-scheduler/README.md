# deep clean scheduler
create a room-by-room deep clean schedule with time estimates and a supply checklist.

what it does: lists rooms, adds estimated time per room, gathers supplies, shows a table, and optionally creates tasks or a repeating routine.

what it needs: make_page to display the schedule, show_table to present the room-time-supply table, task_create to make individual cleaning tasks, routine_create to set up a repeating deep-clean routine.

what it will not do: it cannot book cleaning services, it cannot buy supplies, and it cannot access the person's calendar unless they grant permission.
