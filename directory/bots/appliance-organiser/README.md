# Appliance organiser

Collects appliance manuals and warranties into one searchable digital folder on the computer. Creates an index page with appliance names, model numbers and warranty expiry dates.

**What it needs**: access to the computer's file system (file_list, file_read, file_write, make_page).

**What it will not do**: it will not read scanned images without text, it will not pay for cloud storage, and it will not open accounts on rental listing sites or social networks.
