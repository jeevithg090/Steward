# data deletion

Request deletion of personal data from a company that no longer needs it.

What it does: searches for the company's privacy request page, drafts a deletion request and sends it by email after the person confirms.

What it needs: web search, web page reading, browser actions and mail send. It also needs access to the person's mail.

What it will not do: it will not send any email or file any form without the person's confirmation. It will not invent a company address or a phone number.
