## Pub Quiz Maker

Creates a ready-to-play pub quiz with six themed rounds (ten questions each) and a printable answer sheet. You choose the themes or accept suggested ones. The bot writes original questions, checks key facts with a web search, and delivers two documents: a quiz master sheet with answers and a clean answer sheet for players.

**What it needs**: no external accounts; only web search for fact-checking.

**What it will not do**: copy questions from existing quiz books or websites; guarantee every answer is undisputed (it flags uncertain ones); handle scoring or tie-breaks unless you ask.
