---

name: assemble-quiz
description: Combine rounds into master and answer-sheet documents.
---

1. Collect all six rounds' questions and answers.
2. Use make_page to create the quiz master document: title, date, round headings, questions with answers, and notes on alternatives.
3. Use make_page to create the player answer sheet: title, round headings, numbered lines 1-10 per round, space for team name and score.
4. Use show_table to display a summary: round name, theme, question count.
5. Present both documents to the person.
