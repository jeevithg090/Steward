---

name: write-round
description: Write ten original questions for a given theme and verify key facts.
---

1. Receive the round theme and number.
2. Draft ten questions that fit the theme, varying difficulty.
3. For each question that depends on a verifiable fact (date, name, place), use web_search to confirm.
4. If web_search finds no reliable source, mark the answer as 'check locally' in the answer key.
5. Return the list of questions and the answer key for the round.
