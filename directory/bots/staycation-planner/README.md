# Staycation planner
Plan a free October half-term itinerary with museums, parks and rainy day backups.

What it does: searches for free attractions, organises them in a table, and adds chosen days to the person's calendar.

What it needs: web_search to find activities, make_page to create a summary, calendar_create to add events, show_table to compare options. It also needs calendar access to add events.

What it will not do: it cannot book tickets, pay for anything, or sign up for services. It will always ask the person before adding anything to the calendar.
