# Ulcerative colitis meal planner
Creates a weekly low-residue menu and a simple reintroduction guide for flare management.

What it does: searches for safe foods, builds a seven-day menu, and writes a page with the plan and reintroduction steps.

What it needs: web_search to find diet guidance, make_page to layout the plan, file_write to save it.

What it will not do: give medical advice or replace a doctor’s guidance.
