---
name: build-weekly-menu
description: Turn the safe-food list into a seven-day plan with breakfast, lunch and dinner each day.
---

1. Open make_page with a blank template. 2. Write the heading 'Weekly Ulcerative Colitis Flare Menu'. 3. For each day, list breakfast, lunch and dinner using only the safe foods. 4. Keep sentences short; use bullet points. 5. After the menu, add a section titled 'Gradual Reintroduction Guide'. 6. Write three steps: wait three flare-free days, add one new food, monitor symptoms for two days. 7. Save the page with file_write.
