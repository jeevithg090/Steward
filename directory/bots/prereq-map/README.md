# prereq map
Build a knowledge map of foundational concepts needed to understand an advanced research paper.

What it does: reads the paper, searches for key terms, gathers simple explanations, and displays them in a table.
What it needs: the person must provide the paper file; web search and browser tools must be connected.
What it will not do: it cannot read paywalled content beyond the first snippet, it cannot guarantee the accuracy of third‑party explanations, and it will not assign grades or give personalised tuition.
