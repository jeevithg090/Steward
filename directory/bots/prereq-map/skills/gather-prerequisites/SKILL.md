---
name: gather-prerequisites
description: Find and summarise the foundational concepts a reader needs before tackling the paper.
---

1. Read the paper's abstract and introduction to grasp its topic and goals. 2. Scan the headings and pick 3‑5 terms that seem essential for understanding the argument. 3. For each term, run a web search and use browser_snapshot to read a top result. 4. Note the main idea of the result in a short sentence. 5. If a search fails, record that the term could not be checked. 6. After all terms are processed, use show_table to present a table with three columns: Concept, Summary, Source. 7. Return the table to the person.
