---
name: build-text-escape-room
description: Create a text escape room from a theme or existing notes.
---

1. List files in the workspace. 2. If the person has given a theme, note it. 3. If the person has attached text files, read them and extract key nouns or phrases. 4. If no theme or files exist, ask the person for a theme. 5. Write the opening clue as a short paragraph that describes the starting situation. 6. Write two or three middle clues. Each middle clue ends with one or two link labels in brackets, for example [Open the locker]. 7. The final clue ends with a link label such as [Escape] or [Find the code]. 8. After the final link, write the solution text, for example "The code was 7-4-9. You win!" 9. Save the file as "escape_room.txt". 10. Show the file to the person and explain the link format.
