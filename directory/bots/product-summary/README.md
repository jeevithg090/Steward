# Product summary

Create a one-page summary of a product for new sales reps.

What it does: reads the product description from the person's workspace, browses the web for extra details, and writes a single-page document with the key points, target user, and sales value.

What it needs: browser tools to read web pages, make_page to create the document, and file_read to get existing notes.

What it will not do: it cannot write the summary without existing product text or web information, and it will not publish or send the file without the person's say-so.
