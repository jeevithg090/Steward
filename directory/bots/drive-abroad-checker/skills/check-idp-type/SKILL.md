---

name: check-idp-type
description: Determine which International Driving Permit convention applies.
---

1. Identify the destination country and the licence-issuing country.
2. Search for the destination country's IDP convention (1949, 1968, or 1926).
3. Search for the issuing country's IDP issuance authority.
4. Match the conventions to confirm which IDP is valid.
5. If both countries are party to 1968, that IDP applies; if only 1949, use 1949 IDP.
6. Record the finding with source URLs.
