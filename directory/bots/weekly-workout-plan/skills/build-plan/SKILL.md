---
name: build-plan
description: Make a weekly cardio and strength plan for a race.
---

1. Ask the person for race distance, target date, and any injuries. 2. Check if a routine called Race prep exists. 3. If it exists, add sessions to it. If not, create a new routine named Race prep. 4. Plan two cardio days, two strength days, and three light or rest days across the week. 5. Write each session as a short bullet. 6. Save the plan as a task named Weekly race plan. 7. Show the plan to the person and ask if they want changes.
