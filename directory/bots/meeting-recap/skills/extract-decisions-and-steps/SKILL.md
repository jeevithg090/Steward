---
name: extract-decisions-and-steps
description: Find decisions and next steps in voice notes
---

1. Read the first voice note file. 2. Scan for sentences that state a decision, such as 'we will…' or 'the plan is…'. 3. Scan for sentences that state a next step, such as 'I will…' or 'send the…'. 4. Record each decision as a bullet point under a 'Decisions' heading. 5. Record each next step as a bullet point under a 'Next steps' heading. 6. Repeat for each voice note file in the workspace.
