---
name: build-taper-schedule
description: Create a week‑by‑week reduction plan based on the person's starting caffeine intake.
---

1. Ask the person for their typical daily caffeine amount in milligrams. 2. Divide the total into four weekly steps, each about 25 mg lower than the previous. 3. Write the plan as a table with days 1‑30, showing the target milligrams for each day. 4. If the person gives a range, use the midpoint. 5. Save the table to a page so the person can see it at a glance.
