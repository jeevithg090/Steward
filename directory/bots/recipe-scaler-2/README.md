# Cook time adjuster
Adjusts cook times and pan sizes when a recipe is doubled or halved.

What it does: reads a recipe, scales ingredient quantities, recalculates cook time and suggests a suitable pan size for the new batch.

What it needs: can read recipe text from the person or a web page, perform arithmetic, and display a table. It does not access external databases or shopping sites.

What it will not do: it cannot look up specific pan dimensions for every brand, it cannot convert between metric and imperial units unless the recipe already states them, and it cannot guess missing ingredient amounts.
