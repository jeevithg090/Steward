name: scale-recipe
description: Adjust ingredient amounts, cook times and pan size for a new serving count.
---

1. Read the original recipe text supplied by the person.
2. Identify every ingredient line with a quantity, unit and name.
3. Multiply each quantity by the scaling factor. Round to the nearest practical amount (e.g. 1.5 cups, 200g).
4. Adjust the cook time: for each doubling of the factor, add roughly 10‑15% to the original time; for halving, subtract roughly 10‑15%. Keep oven temperature unchanged.
5. Calculate a suitable pan size using the area ratio. For a round pan, new radius = old radius × √factor. For a rectangular pan, scale both length and width by √factor.
6. Build a table with three columns: ingredient (original), quantity (original), quantity (scaled). Add rows for adjusted cook time and suggested pan size.
7. If any step fails because a value is missing or unrecognisable, tell the person exactly which part could not be processed.
