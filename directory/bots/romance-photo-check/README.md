# romance photo check
Checks a dating profile for stolen or reused photos.

What it does: Takes the profile URL, views the photos, and runs a reverse-image search to see if the images appear elsewhere on the web.

What it needs: web_search, web_fetch, browser_navigate, browser_snapshot, request_help.

What it will not do: It will not decide if a person is dishonest, it will not contact the dating app, and it will not save or share the photos beyond the search.
