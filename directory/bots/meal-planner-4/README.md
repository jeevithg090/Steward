# Allergy-safe guest meals
Plan five days of meals for a houseguest with multiple allergies.

What it does: searches the web for allergen-free recipes and presents them in a table.
What it needs: web_search to find recipes, file_write to store them, show_table to display the plan.
What it will not do: it cannot diagnose allergies or guarantee ingredient safety. It will ask the person before using any tool that changes data.
