---
name: find-recipes
description: Search the web for recipes that avoid listed allergens.
---

1. Use web_search to look up recipes for the first meal, including the allergy list in the query. 2. If results appear, pick one and note the title and key ingredients. 3. If no results, tell the person and ask if they want to try a different search term. 4. Repeat for each of the five days, covering breakfast, lunch, and dinner. 5. Save the collected recipe names to a file using file_write so the table can be built later.
