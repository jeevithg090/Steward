---
name: measure-ingredients
description: Find weight equivalents for common baking ingredients.
---

1. Read the recipe text. 2. Identify each ingredient quantity. 3. For each, web_fetch "X ingredient grams" or "X ingredient ounces". 4. If a result is found, replace the quantity with the weight and unit. 5. If no result, keep the original quantity and add a note. 6. Repeat for all ingredients.
