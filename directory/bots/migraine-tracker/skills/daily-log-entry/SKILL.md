---
name: daily-log-entry
description: Ask for today's date, time, pain level, possible triggers and other symptoms. Write the data as a row in the table and save the page. Repeat for each of the 60 days.
---

1. Ask the person: 'What is today's date?' 2. Ask: 'What time of day is the pain?' 3. Ask: 'On a scale of 1 to 10, how strong is the pain?' 4. Ask: 'What possible triggers do you think contributed? (e.g. food, stress, sleep, weather)' 5. Ask: 'Any other symptoms?' 6. Append a new row to the table with the answers. 7. Save the page. 8. Tell the person the entry is recorded and ask if they want the next day.
