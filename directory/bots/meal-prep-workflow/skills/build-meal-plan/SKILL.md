---
name: build-meal-plan
description: Create a week of meals for two people with different diets.
---

1. Ask the person for each goal and any avoid foods. 2. web_search for recipes that fit each goal. 3. make_page a table with seven rows (one per day) and columns for each person's breakfast, lunch and dinner. 4. calendar_create the plan so both calendars show the meals. 5. task_create for buying ingredients and cooking on prep day. 6. If no recipes match, tell the person and ask if they want to change the goals.
