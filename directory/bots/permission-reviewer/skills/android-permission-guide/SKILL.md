---
name: android-permission-guide
description: Step-by-step guide to finding and changing permissions on Android.
---

1. Open Settings.
2. Tap Privacy (or Security & privacy).
3. Tap Permission manager (or App permissions).
4. Tap a permission category (e.g., Location, Camera, Microphone, Contacts).
5. Review apps under Allowed, Allowed only while in use, or Not allowed.
6. Tap an app to change: Allow, Allow only while using the app, Ask every time, or Don't allow.
7. Repeat for each category of concern.
