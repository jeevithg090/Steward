---
name: find-privacy-guides
description: Search the web for a privacy-focused browser setup guide.
---

1. Use web_search with the query "privacy-focused browser setup guide". 2. Review the results and open the most relevant pages with web_fetch. 3. Scan each page for lists of extensions and specific setting changes. 4. If a page does not contain useful information, close it and move to the next result. 5. If no results contain a helpful guide, stop and inform the person.
