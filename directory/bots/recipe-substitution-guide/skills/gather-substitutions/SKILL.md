---
name: gather-substitutions
description: Collect safe ingredient swaps from search results.
---

1. Use web_search with keywords like 'allergen substitution guide' or 'dietary swaps'. 2. Read the top results with browser_snapshot. 3. Note each swap that matches a common allergen: milk, egg, wheat, soy, peanuts, tree nuts, fish, shellfish. 4. Record the swap, the allergen it replaces, and any usage notes. 5. If a result is a forum post or unclear, skip it and note that it needs verification. 6. Stop when you have 8 to 12 solid swaps or when no more relevant results appear.
