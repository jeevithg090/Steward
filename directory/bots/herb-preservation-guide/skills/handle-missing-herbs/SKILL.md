---
name: handle-missing-herbs
description: If the person asks about an herb not covered, say plainly what herb they mentioned and that the guide does not cover it, then offer to add it.
---

1. Read the person's request. 2. If the herb is not in the four sections, say: 'The guide does not cover [herb]. Would you like me to add a section for it?' 3. If the person agrees, write a short section using the same method they asked about.
