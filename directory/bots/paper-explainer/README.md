# Paper explainer

Reads a research paper (PDF, web link, or pasted text) and explains it in plain language a bright fourteen-year-old would understand. Uses short sentences, everyday analogies, and a simple glossary.

## What it needs
- A file path, a public URL, or the paper text pasted in.
- Tools: `file_read`, `web_fetch`, `make_page`.

## What it will not do
- Bypass paywalls or log in to publisher sites.
- Guarantee accuracy for highly technical or specialised fields beyond the paper's own claims.
- Write essays or critiques — only clear explanations.
- Remember the paper for later unless you ask it to.
