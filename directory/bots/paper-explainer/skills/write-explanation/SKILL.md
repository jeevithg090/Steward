---
name: write-explanation
description: Turn the paper text into a bright-14 explanation and make a page.
---

1. Read the paper text. Pick out the research question, methods, results, implications, and limits.
2. Write each section in plain language. Use analogies. Define 3 to 5 key terms.
3. Keep sentences under 25 words. British spelling.
4. Call `make_page` with title like 'Paper explained: [topic]' and the markdown content.
5. Show the page. Ask if they want changes, a shorter version, or to save it.
