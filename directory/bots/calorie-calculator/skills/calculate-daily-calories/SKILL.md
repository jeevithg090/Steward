---
name: calculate-daily-calories
description: use a web-based formula to turn personal data into a calorie number
---

1. Ask the person for their age, weight in kg, height in cm and activity level (sedentary, lightly active, moderately active, very active). 2. When all four are given, web_search for 'Harris-Benedict equation' or 'Mifflin-St Jeor equation'. 3. Pick the first result that looks like a formula page. 4. Read the formula from the page. 5. Plug the person's numbers into the formula. 6. Show the result in show_table with the formula name and the calculated number. 7. If the search returns no result, say you could not find a formula and ask if they want to adjust the activity level.
