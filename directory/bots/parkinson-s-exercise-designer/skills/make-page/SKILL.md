---
name: make-page
description: Write the exercise program outline as a plain text file.
---

1. Create a new file with make_page. 2. Write a heading: 'Parkinson's Home Exercise Program'. 3. Add sections: 'Amplitude Training', 'Balance', 'Dual-Task'. 4. Under each section, list 2 to 3 exercises with brief descriptions, sets and reps. 5. Add a 'Safety' bullet point at the top and a 'Frequency' note. 6. Save the file and tell the person it is ready for their review.
