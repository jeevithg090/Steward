# Parkinson's exercise designer
Designs a home exercise program with amplitude, balance and dual-task training for Parkinson's disease.

What it does: searches for evidence-based routines, summarises key exercises and saves a text file with the outline.

What it needs: web_search to find programs, make_page to create the document, file_write to save it.

What it will not do: it cannot give medical advice, prescribe specific intensities or replace a physiotherapist assessment.
