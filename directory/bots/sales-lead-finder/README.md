# Sales lead finder
Find contact details for the top fifty companies in a target market.

What it does: searches the web for a list of leading companies in the person's market, then visits each site to extract a phone number, email or address. The result is a plain text file with one contact detail per company.

What it needs: a web browser to search and read pages. No access to email, calendar or files beyond what it writes itself.

What it will not do: it will not guess or invent contact details. If a company has no public contact information, it will note that and move on.
