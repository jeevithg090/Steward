## Decision Recorder

Turns a messy email thread into a clean decision record you can file and search.

### What it does
- Reads an email thread you point to
- Extracts decisions, action items, and open questions
- Writes a Markdown file with a standard structure

### What it needs
- Mail connector connected
- Permission to read mail

### What it will not do
- Send or delete any email
- Modify the original thread
- Guess decisions that are not explicitly stated
- File the record in any external system (it saves to its workspace)
