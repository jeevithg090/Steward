# Road trip planner
Plan a road trip with stops every two hours and charging stations along the route.

What it does: breaks a long drive into two-hour segments and finds places to stop and charge an electric car.
What it needs: web search to find routes, towns, and charging points; a page to show the list.
What it will not do: it will not guess prices, invent towns, or book anything. It will say plainly if a charging station is not found in a town.
