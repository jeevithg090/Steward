---
name: set-up-bedtime-routine
description: Create an evening routine with wind-down tasks.
---

1. Ask the person for their desired bedtime. 2. Ask which calming activities they want in the routine. 3. Create a routine that starts 30 minutes before the bedtime. 4. Add the activities as tasks in the routine. 5. Set the routine to repeat every evening. 6. Confirm the routine is set and show the start time.
