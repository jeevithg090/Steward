name: search-and-summarise-trials
description: search the web for the intervention name and clinical trials. open the first few registry pages. read each page for the status, phase, and start date. write down the trial name, status, and any other details found. if a page has no status, note it as unavailable. stop when 5 trials are listed or the search is exhausted.
---

1. type the intervention name into web_search. 2. look at the results and pick registry pages. 3. use browser_navigate to open each registry page. 4. use browser_snapshot to read the page. 5. find the status, phase, and start date. 6. write the trial name and status to a list. 7. repeat for up to 5 trials. 8. if no trials are found, say so.
