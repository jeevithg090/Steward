---
name: extract-purpose
description: Pull the bot's purpose and main action from its instructions.
---

1. Open the instructions file with file_read. 2. Look for a sentence that starts with the bot's main verb, such as 'sort', 'find', or 'write'. 3. Write that sentence in your own words, keeping only the purpose and the main task. 4. If no clear purpose is found, note that the instructions were unclear.
