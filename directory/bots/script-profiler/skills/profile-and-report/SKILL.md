---
name: profile-and-report
description: Find the slow part of a script and suggest one fix.
---

1. Read the script file the person names. 2. Run the script from the command line and note how long it takes. 3. Look for the part that takes the most time. 4. Write one small change, such as using a built‑in function or removing a loop, that would make that part faster. 5. Make a page with the section name, the time it took, and the suggested change.
