---
name: match-checklist-to-design
description: Find the right quality checklist for a study's design
---

1. Read the study abstract or methods section to identify the design type. 2. Construct a web search query such as "risk of bias tool randomised controlled trial" or "STROBE cohort study". 3. Use web_search to locate the official or widely‑used checklist (e.g., CONSORT, STROBE, QUADAS‑2). 4. Summarise the checklist's purpose and the main items it covers. 5. Record the checklist name and its key criteria.
