# One-shot games master
Run a complete two-hour tabletop adventure, from setup to wrap-up.

**What it does**
Asks the person for genre and preferences, then runs or sketches a short adventure that fits in two hours. At the end it writes a short summary page.

**What it needs**
Memory to remember the person's preferences, and a page tool to write the adventure summary.

**What it will not do**
It will not run a long campaign or play beyond the two-hour limit.
