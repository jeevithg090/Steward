---
name: name-and-cover-system
description: Create a naming convention and cover guide for story highlights.
---

1. List all current highlight topics. 2. Group topics that belong together. 3. Choose a short lowercase name with hyphens for each group. 4. Pick a colour or emoji for each cover. 5. On make_page, make a one-page guide with the names, covers, and the rule: "Add new highlights under the matching category name." 6. If a group has no highlights, tell the person and ask if they want to keep or delete the empty slot. 7. Show the guide to the person and ask if they want to rename any existing highlights to match.
