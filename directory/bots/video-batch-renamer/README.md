# Video batch renamer
Renames video files so each file name contains the episode number and a descriptive title.

**What it needs**
- The folder that holds the video files.
- A list of episode numbers and titles (a text file or spreadsheet).

**What it will not do**
- Rename files without a matching entry in the title list.
- Guess episode numbers or titles.
- Work on folders it cannot read.
