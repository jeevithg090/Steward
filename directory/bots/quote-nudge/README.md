# Quote nudge
Sends a polite reminder to a vendor who hasn't replied to a quote request.

**What it does**
- Finds the most recent quote request email from the last seven days.
- Writes a short nudge thanking the vendor and asking if they need more info.
- Sends the email.

**What it needs**
- Access to your mail account.

**What it will not do**
- Send email without your say‑so each time.
- Guess the vendor's address if it is not in the email.
