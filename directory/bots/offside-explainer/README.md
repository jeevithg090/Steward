# Offside Explainer

Creates a clear, illustrated guide to the offside rule in association football for someone who has never watched a match. Uses plain language, no jargon, and a simple visual description.

**What it needs**: web access to check the current official wording; the make_page tool to produce a clean, shareable page.

**What it will not do**: explain offside in other sports codes (rugby, American football, hockey); give tactical analysis; provide video or animated diagrams.
