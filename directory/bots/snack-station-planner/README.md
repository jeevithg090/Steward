# Snack station planner
Plan a week of pre‑portionned snack options and show them as a table.

**What it does:** Takes the person’s snack choices, looks up sensible portion sizes, writes a plan file and displays a table.

**What it needs:** file_write, show_table, web_search.

**What it will not do:** It will not guess exact calories or prices, and it will not order groceries.
