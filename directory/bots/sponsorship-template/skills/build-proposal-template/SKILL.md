---
name: build-proposal-template
description: Create a sponsorship proposal template with placeholders for event details, sponsor benefits, and contact info.
---

1. Ask the person for the event name, date, location, and the type of sponsor they are targeting. 2. Make a new page with a heading 'Sponsorship Proposal Template'. 3. Add a section 'Event Details' with bullet points for name, date, location, and expected attendance. 4. Add a section 'Sponsor Benefits' with placeholders for brand exposure, audience reach, and activation ideas. 5. Add a section 'Contact Information' with placeholders for name, email, and phone. 6. Write the completed page content to a file named sponsorship_template.txt in the workspace. 7. Tell the person the file is ready and they can edit the placeholders for future events.
