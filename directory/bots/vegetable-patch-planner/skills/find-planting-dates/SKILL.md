---
name: find-planting-dates
description: Search the web for each vegetable's planting month and spacing needs.
---

1. For each vegetable, type a search query like "[vegetable] planting month UK".
2. Read the results and note the best planting month and any spacing advice.
3. If a result has no month or spacing, note that it could not be checked.
4. Stop when all vegetables have been searched.
