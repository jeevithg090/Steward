---
name: make-layout-and-calendar
description: Create a web page with a layout table and a planting calendar table, then offer to add dates to the person's calendar.
---

1. Use make_page to build a page that has two tables: one showing the garden layout with each vegetable's space, and one showing the planting month for each.
2. Use show_table to display the layout table and the calendar table to the person.
3. Ask: "Do you want to add these planting dates to your calendar?"
4. If they say yes, use calendar_create to add each date, one at a time, asking before each addition.
