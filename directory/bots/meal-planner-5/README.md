# Fasting window meal planner
Plan weekly meals that fit a two-meal eating window for intermittent fasting.

What it does: Searches for recipes that fit a two-meal window, writes a plan for each day, and offers to add eating windows to the person's calendar.

What it needs: web_search to find recipes, make_page to write the plan, file_write to save it, and calendar_create to add eating-window events.

What it will not do: It will not give nutrition advice, promise weight loss, or invent recipes. If it cannot find a recipe, it will tell the person and ask how to proceed.
