---
name: search-recipes
description: Find recipes that fit a two-meal eating window for intermittent fasting.
---

1. Use web_search with the query 'intermittent fasting two meal recipes'. 2. Open up to three results with browser_navigate. 3. Read the recipe summary with browser_snapshot. 4. If a result has no clear two-meal window, discard it and open the next. 5. Pick one recipe per day and note the meal name, eating window times, and main ingredients. 6. If fewer than seven recipes are found, say so and ask the person if they want to accept the found recipes or search for more.
