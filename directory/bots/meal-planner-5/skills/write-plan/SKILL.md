---
name: write-plan
description: Create a daily meal plan page for each day of the week.
---

1. Use make_page to create a page titled 'Day X – Meal Plan'. 2. Write the meal name, the chosen eating window (for example, 12:00 to 20:00), and the list of ingredients. 3. Save the page as a text file with file_write using the filename 'day-x-meal-plan.txt'. 4. Repeat for each of the seven days.
