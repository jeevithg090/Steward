---
name: research-pain-points
description: Find and record audience pain points for a given topic.
---

1. Use web_search to look up the topic plus "pain points" or "common problems". 2. Read the search results for frequent pain points. 3. Write down 3 to 5 pain points that appear most often. 4. If the search returns no useful results, note "no pain points found". 5. Repeat for each of the 12 topics, keeping a single list that links each topic to its pain points.
