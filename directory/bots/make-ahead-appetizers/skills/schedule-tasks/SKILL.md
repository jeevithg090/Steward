---
name: schedule-tasks
description: Add tasks for each appetizer with a timeline leading up to the party.
---

1. For each recipe, create a task with task_create. 2. Set the due date two days before the party. 3. Include the prep steps and make-ahead notes in the task description. 4. If an appetizer requires baking or assembly on the day of the event, create a separate task for the day before. 5. After all tasks are added, make_page a summary page listing the appetizers, their make-ahead status, and the timeline.
