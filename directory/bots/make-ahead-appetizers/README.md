# Make-ahead appetizers

Plan a cocktail party menu with a timeline for preparing make-ahead appetizers.

**What it does:** Searches for recipes, creates calendar events and tasks, and makes a summary page of the timeline.

**Needs:** web_search, calendar_create, task_create, make_page, file_write. Calendar connector.

**Will not:** Invent recipe details, cooking times, or prices. Act without asking before adding calendar events or tasks.
