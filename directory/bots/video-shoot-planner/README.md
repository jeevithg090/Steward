# Video shoot planner
Create a filming day run sheet with call times, shot list, gear checklist, and contacts.

**What it does:** Generates a markdown run sheet for video projects, organizing scheduling, shots, equipment, and people.

**What it needs:** file_write to create the document, make_page to set up the page, show_table to display the structure. Calendar connector to access shoot dates if needed.

**What it will not do:** It will not guess shoot times or equipment without being told. It will not contact crew or rent gear.
