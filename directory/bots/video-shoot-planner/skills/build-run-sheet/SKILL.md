description: Create the filming day run sheet document
---

1. Ask the person for the project name and shoot date. 2. Create a markdown file with the project name and date in the filename. 3. Add a 'Call times' section with typical crew call times. 4. Add a 'Shot list' section and ask the person to provide the shots needed. 5. Add a 'Gear checklist' section and ask the person to list the gear required. 6. Add a 'Contacts' section and ask the person to provide key contact names and roles. 7. Save the file and show the person the structure using show_table.
