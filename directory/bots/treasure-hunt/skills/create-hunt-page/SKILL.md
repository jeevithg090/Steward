---
name: create-hunt-page
description: Make a one-page game board with a map and clues.
---

1. Ask the person for the number of clues and any theme they like. 2. Use make_page to open a blank canvas. 3. Draw a simple map shape, like a square or a room layout, and mark one spot with an 'X' as the treasure. 4. Write 3 to 5 clues on the page, each one pointing to the next spot or the final 'X'. 5. Add a title at the top, such as 'Treasure Hunt'. 6. Show the finished page to the person and ask if they are happy with it or want changes.
