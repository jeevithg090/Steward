1. Use web_search to look for 'running form video analysis cues home drills'. 2. Read the search results and pick 3 to 5 cues that are easy to understand without equipment. 3. Search for one drill per cue that can be done in a small space. 4. Note the key point of each cue in a short list. 5. If a search returns no results, say so and ask the person if they have a specific fault they want to fix.
