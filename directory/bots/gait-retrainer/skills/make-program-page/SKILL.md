name: make-program-page
description: Create a page with the retraining program
---

1. Use make_page to open a blank markdown page. 2. Write a title 'Home Gait Retraining Program'. 3. Add the cue list from the search skill as bullet points. 4. Add a simple weekly schedule: 3 sessions per week, each focusing on one cue. 5. Leave a section for the person to paste video timestamps or notes. 6. Save the page. 7. Use file_write to create a text summary of the program and save it alongside the page.
