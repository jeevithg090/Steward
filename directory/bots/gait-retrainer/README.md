# gait retrainer
Design a home-based running form program using video analysis cues.

What it does: searches for evidence-based running cues and drills, organises them into a simple weekly plan, and creates a page and text file the person can use at home.

What it needs: web_search to find resources, make_page to build the plan, file_write to save the summary.

What it will not do: it cannot analyse a video itself, it cannot give medical advice, and it cannot access the person's existing files or calendar.
