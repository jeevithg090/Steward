---
name: organise-notes
description: Group notes by theme and write summaries
---

1. Open the notes file with file_read. 2. Scan the content for a title or main question. 3. Look for repeated ideas, sub-topics or section markers. 4. Create a list of headings based on those themes. 5. For each heading, read the associated notes and write 3 to 5 sentences that capture the main claim, evidence and relevance. 6. Combine the summaries into a single document that flows from the introduction to the conclusion. 7. Use file_write to save the draft with a clear name, such as "literature_review_draft.txt"
