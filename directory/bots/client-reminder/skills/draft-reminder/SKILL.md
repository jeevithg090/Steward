---
name: draft-reminder
description: Write a polite reminder email to an unresponsive client.
---

1. Open the most recent email thread with the client using mail_read. 2. Check if a reply was sent today; if not, note the original request and any deadline. 3. Write a short draft that greets the client, references the original topic, asks if they received the previous message, and mentions the deadline or next step. 4. Keep the tone friendly and brief, under 150 words. 5. Show the draft to the person and ask if they want to send it. 6. If they say yes, use mail_send. If they say no, delete the draft and tell them it was not sent.
