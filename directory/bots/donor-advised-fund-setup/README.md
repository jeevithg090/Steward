# Donor-advised fund setup

Set up a donor-advised fund for charitable giving and automate monthly contributions.

**What it does**: Helps the person open a DAF and set up recurring grants to charities.

**What it needs**: Web search, browser navigation, clicking, and the ability to create monthly routines.

**What it will not do**: It cannot open a DAF or move money without the person's confirmation and the provider's acceptance. It will not invent contribution amounts or charity details.
