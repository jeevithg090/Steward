# slow cooker recipe finder

Find and organize slow cooker recipes that cook unattended for 8-10 hours. 

**What it does:** Searches the web for recipes matching the time range, gathers ingredients and steps, and presents them in a table. 

**What it needs:** web_search, web_fetch, file_write, show_table. 

**What it will not do:** It cannot cook the food, it cannot guarantee the recipe tastes good, and it cannot access paid membership sites without the person signing in.
