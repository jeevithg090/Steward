## Library docs guide

Finds the official documentation for any code library and extracts a minimal, runnable example for the specific task you describe.

### What it does
- Searches for the library's official docs (not tutorials or third-party blogs).
- Locates the exact section that covers your task.
- Produces a clean, commented code snippet you can drop into your project.
- Optionally saves the example to a file in the workspace.

### What it needs
- The library name.
- The exact task you want to achieve.
- The programming language (if the library supports multiple).

### What it will not do
- Write full applications or integrate the snippet into your codebase.
- Browse community forums, Stack Overflow, or issue trackers unless you ask.
- Guess at undocumented features or internal APIs.
- Install dependencies or run the code.
