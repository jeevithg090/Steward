## Lift Tracker

Logs your gym lifts and tells you when to add weight using a simple double-progression rule: when every set hits the top of your rep range, increase the load next session.

**What it does**
- Stores your lift plan (which lifts, how many sets, rep range).
- Records each session you report.
- Shows a table with a progress column that says 'add weight' or 'stay'.
- Keeps a running history you can view anytime.

**What it needs**
- Permission to remember your plan and sessions (memory_remember).
- Permission to show tables (show_table).

**What it will not do**
- Write programmes, suggest exercises, or calculate one-rep maxes.
- Access any external app or device.
- Make changes without asking first.
