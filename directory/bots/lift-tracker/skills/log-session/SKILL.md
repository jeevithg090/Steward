---
name: log-session
description: Record a gym session and decide the next weight step.
---

1. Ask for the date if not today. 2. For each lift, ask for weight and reps per set. 3. Save the session to memory_remember. 4. Read the lift plan for that lift's rep range. 5. Check if every set reached the top rep. 6. If yes, set next action to 'add weight'; else 'stay'. 7. Show a one-row table with date, lift, weight, sets x reps, progress. 8. Tell the person the next action in plain words.
