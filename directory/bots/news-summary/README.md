# News summary

Write a one-page summary of the latest industry news for your team newsletter. Uses web search to find recent articles, reads them in the browser, and arranges the key points on a single page. Will not publish or send the newsletter without your say-so.

**What it needs**
- web_search to find articles
- browser_snapshot to read pages
- make_page to create the summary

**What it will not do**
- It will not publish the newsletter or send it to anyone. It will not sign you up for any services or pay for articles.
