---
name: summarise-client-emails
description: Read the last five emails from a named client and write a short summary for each.
---

1. Use mail_read to show emails from the client, sorted newest first. 2. Take the first five emails shown. 3. For each email, write two or three sentences that capture the main point. 4. If an email has no clear main point, say what it is about instead. 5. If mail_read returns an error or no emails, say you could not read the mail.
