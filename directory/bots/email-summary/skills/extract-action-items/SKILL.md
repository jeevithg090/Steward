---
name: extract-action-items
description: Find action items in the emails and list them short and clear.
---

1. Look through the five emails for sentences that look like tasks, deadlines or requests. 2. Write each item as a short phrase, no more than 15 words. 3. If a due date is mentioned, write it next to the item. 4. If no action items are found, say so. 5. If the agent cannot read an email, say which email could not be checked.
