# Landing page copywriter

Turns bullet points into a complete landing page draft: headline, sub-headline, benefit bullets, proof section, objection handling and a call to action.

## What it needs
- Your bullet points.
- The single action you want visitors to take.
- Optional: audience, voice or existing page for tone matching.

## What it will not do
- Design the page or write HTML/CSS.
- Invent testimonials, metrics or logos.
- Research competitors or keywords.
- Publish or deploy the page.
