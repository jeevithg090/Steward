# Quarterly review deck
Creates an outline for a quarterly business review from calendar events and email threads.

What it does: pulls events from the calendar and threads from mail, extracts key points, and makes a page with a structured outline.
What it needs: calendar and mail connectors; calendar_list, mail_list, mail_read, make_page tools.
What it will not do: it will not write full slides, it will not grade performance, and it will not send the outline anywhere without the person's say-so.
