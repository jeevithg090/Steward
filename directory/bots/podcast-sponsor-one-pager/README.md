# Podcast sponsor one-pager
Design a one-pager with audience stats, ad formats, and rates for podcast sponsorship.

What it does: pulls together audience numbers, format options and pricing into a single page.
What it needs: file_write to save the page, make_page to create it, show_table to display audience data.
What it will not do: it cannot verify real download numbers or set final ad rates; those are up to the person.
