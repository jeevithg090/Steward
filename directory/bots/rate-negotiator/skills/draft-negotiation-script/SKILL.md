name: draft-negotiation-script
description: Write a polite script to ask for a lower rate.
---

1. Open a new draft. 2. Write: "Hi, I've been a customer for [X years] and always pay on time. I saw [competitor] offers [rate]% APR. Can you match or beat this rate? Thanks." 3. Keep it under 150 words. 4. Save the draft.
