# Paper stats extractor

Read research papers and build a table comparing their statistical results.

**What it needs**: access to files on its computer (file_read, file_write, show_table).
**What it does**: lists the papers, reads each one, pulls out number results, and shows a two-column table.
**What it will not do**: it cannot interpret the meaning of the results or perform statistical analysis; it only extracts the numbers it can see.
