# Rental scam check

Checks a rental listing for common scam signs before you pay a holding deposit. It compares the rent to local market rates, reverse-searches photos, verifies the agent or landlord, checks property ownership records, and searches for scam reports.

**What it needs**: The listing URL or the address, rent, landlord/agent name, and contact details.

**What it will not do**: Contact the agent, pay any money, sign anything, or guarantee the listing is safe. It only gathers evidence so you can decide.
