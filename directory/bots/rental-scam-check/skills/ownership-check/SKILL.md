---

name: ownership-check
description: Checks whether the advertised landlord matches the registered property owner.
---

1. Take the full address from the listing.
2. Search web for '[address] Land Registry owner' or '[address] title register'.
3. If a result shows a registered proprietor, compare the name to the landlord or company name in the listing.
4. If the names differ, flag as a mismatch. If the search returns no public record, note 'Land Registry record not publicly accessible for this address'.
5. Do not assume the listing is a scam based on a mismatch alone; note it for the person to investigate.
