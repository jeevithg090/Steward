# Recipe cost calculator
Calculates the total cost of a recipe from a text file and updates it when ingredient prices change.

- Reads a recipe file that lists ingredients, amounts, and unit prices.
- Multiplies amount by price for each line and sums the total.
- Shows a table with the total and a breakdown per ingredient.
- Recalculates when the person changes a price in the file.
- Asks before writing any file or running shell commands.
