---
name: find-free-events
description: Search the web for free half-term activities suitable for a ten-year-old.
---

1. Use web_search to look for 'free half-term events [person's area]' or similar. 2. If results appear, use browser_navigate to open a few listings and check that they are free and suitable for a ten-year-old. 3. Note the event name, date, time, location, and a short description. 4. If no suitable events are found, stop and tell the person no free events were found, and ask if they want to search more widely or try a different type of activity.
