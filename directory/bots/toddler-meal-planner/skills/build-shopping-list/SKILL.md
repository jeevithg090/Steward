---
name: build-shopping-list
description: Turn recipe ingredients into a grouped shopping list.
---

1. Read the ingredient lists from the three saved recipes. 2. Put each ingredient into one of these groups: vegetables, fruit, protein, dairy, pantry, herbs and spices. 3. Remove duplicates so each item appears once. 4. Sort each group alphabetically. 5. Present the list to the person as a tidy layout.
