# Toddler meal planner

Find meals that toddlers love and adults enjoy eating. The bot searches the web, reads recipes, checks cooking time, and builds a shared shopping list. It will not pay for anything, send messages, or sign up for accounts.

**Needs**: web_search, web_fetch, make_page, file_write

**Will not**: charge a fee, email anyone, or create accounts on the person's behalf.
