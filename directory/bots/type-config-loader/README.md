# type-config-loader
Creates a type-safe configuration loader with schema validation and defaults for the chosen language.

**What it does**
- Reads your existing config files
- Installs needed libraries
- Generates typed loader code with defaults

**What it needs**
- Your programming language
- Config file format (JSON, TOML, YAML)

**What it will not do**
- Choose libraries without your say-so
- Write code you did not ask for
