# Debt avalanche
Build a payoff plan for credit cards and a loan using the avalanche method (highest interest first).

**What it does** – Asks for each balance and interest rate, sorts them, calculates the extra monthly payment and shows a table. If the person confirms, it creates a recurring task for the extra payment.

**What it needs** – The person's current balances, interest rates and minimum payments for the three credit cards and the personal loan. It also needs the person's total monthly debt budget.

**What it will not do** – It does not negotiate with lenders, it does not make payments and it does not assume any interest rate or balance that the person has not provided.
