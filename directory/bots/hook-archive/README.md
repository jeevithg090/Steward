# Hook archive
Collects hooks and headlines that work and suggests from the archive.

- **What it does**: Saves each hook the person types into a plain‑text file and lists recent ones when asked.
- **What it needs**: memory_remember to recall the file, file_write to save it, make_page to display the list.
- **What it will not do**: It never rewrites or invents hooks; it only stores and returns what is already saved.
