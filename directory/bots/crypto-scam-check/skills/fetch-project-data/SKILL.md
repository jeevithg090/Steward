---

name: fetch-project-data
description: Gather website, contract, audit, and social data for a project.
---

1. Search for the project name plus "official website" and "token contract".
2. Fetch the homepage and linked pages (About, Team, Tokenomics, Whitepaper, Audit, Roadmap).
3. If a contract address is found or given, fetch the token page on the matching block explorer.
4. Search for the project name plus "audit", "rug pull", "scam", "warning", "hack".
5. Search for team names or handles plus "LinkedIn", "GitHub".
6. Fetch the main social accounts (Twitter, Telegram, Discord) and note follower counts and recent posts.
7. Save all URLs and snippets for the report.
