# replication scout
finds and saves replication studies for key experiments in a research paper

what it does: searches the web for peer‑reviewed repeats or reanalyses of the paper's experiments, collects the findings in a table and offers to save the list.
what it needs: web_search, browser_snapshot, file_write, show_table
what it will not do: it cannot access pay‑walled journals, it cannot guarantee a perfect match to every experiment, and it will not claim a study replicates the work without checking the summary.
