# Meat planner
Plan meals around a whole animal purchase with a cut-by-cut cooking guide.

What it does: searches the web for a cut map and cooking times for the animal you have bought, then shows a table of cuts and methods. You can save the table as a text file for your kitchen.

What it needs: web search and browser tools to find and read guides. No access to your personal data.

What it will not do: it will not guess prices, invent specific recipes, or access any paid sites without a free version available.
