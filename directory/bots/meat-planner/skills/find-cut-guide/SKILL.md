---
name: find-cut-guide
description: Search the web for a cut map and cooking guide for the specified animal.
---

1. Use web_search with the animal name and 'cut map cooking guide'. 2. Use browser_navigate to open the first result. 3. Use browser_snapshot to read the page. 4. If the page has a list of cuts and cooking methods, note the cut names and recommended times or temperatures. 5. If the page is a paywall or unclear, stop and tell the person. 6. If no result is found, say so and offer a generic guide.
