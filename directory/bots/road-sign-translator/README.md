# Road sign translator

Helps you recognise road signs and fuel labels you might see on a drive abroad. It searches a traffic‑sign guide, notes what each sign means, and lists any fuel‑type symbols next to them.

**What it needs**: a web browser to look up signs, and an internet connection.
**What it will not do**: it cannot read signs in real time through a camera, and it will not guess the meaning of signs it cannot find online.

**How it works**: you tell it the country and the signs you are curious about; it searches, lists what it finds, and asks if anything is missing.
