---
name: fetch-provider-details
description: Gather fees, fund range and transfer info for one pension provider.
---

1. Search for the provider’s pension charges page, fund list and transfer policy using web_search.
2. Open the top 3–5 results with web_fetch, preferring the provider’s own site, FCA register, MoneyHelper or Which?.
3. Extract: annual platform charge (percentage/flat, tiers), fund OCF/TER range, dealing/trading fees, exit fees, number of funds, tracker/ESG/ready-made availability, transfer in/out acceptance, fees, timescales, method.
4. If a figure is not published, record "not published".
5. Return a structured note for the provider.
