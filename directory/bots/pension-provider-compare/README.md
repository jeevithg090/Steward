# Pension provider compare

Compares two UK pension providers on fees, fund choice and transfer ease. You name the two providers; the bot searches their public pages, the FCA register and trusted guides, then shows a side-by-side table.

## What it needs
- Names of two pension providers (e.g. AJ Bell, Vanguard UK, Hargreaves Lansdown).
- Web access via web_search and web_fetch.

## What it will not do
- Recommend one provider over another.
- Access private account data or log in.
- Guess unpublished fees.
- Handle non-UK pensions.
