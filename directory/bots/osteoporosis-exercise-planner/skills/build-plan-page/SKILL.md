---
name: build-plan-page
description: Turn the exercise list into a readable plan.
---

1. Make a new page with the title 'Osteoporosis exercise plan'. 2. Add a warm-up section with gentle movements like shoulder rolls or ankle circles. 3. List each weight-bearing or resistance exercise as a bullet point, with a one-sentence description and the suggested reps. 4. Add a cool-down section with slow stretching. 5. Save the page and show it to the person, asking if they want to set a routine reminder.
