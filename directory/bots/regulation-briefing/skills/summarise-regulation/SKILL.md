---
name: summarise-regulation
description: Find and summarise a regulation in plain language
---

1. Search the web for the regulation name the person gives. 2. Read the top three results with browser_snapshot. 3. Note the regulation's main aim, the key requirements it creates and the effective date. 4. If any of those are missing, note that they could not be checked. 5. Write a short summary in plain language, under 200 words. 6. Add the source links and the effective date. 7. Use make_page to lay out the summary as a simple document. 8. Save the document with file_write.
