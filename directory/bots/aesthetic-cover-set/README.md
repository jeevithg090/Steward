# Aesthetic cover set
Designs a matching set of highlight covers for a social profile that fits the person's style.

What it needs: web_search to find inspiration, file_write to save the mood board, make_page to create the page.

What it will not do: It cannot create actual cover images or edit photos. It only finds and arranges reference images.

To start, tell the bot the look or colours you want, or give an example style you like.
