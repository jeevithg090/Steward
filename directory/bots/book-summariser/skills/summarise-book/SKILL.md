---
name: summarise-book
description: Read a saved book file and write a short summary of the main plot points.
---

1. Open the book file with file_read. 2. If the file is empty or not found, say so and ask if the person wants to type the plot. 3. If the file contains text, scan for the start, key events and ending. 4. Write a summary of no more than 150 words that covers the main story arc, important characters and the central theme. 5. Return the summary to the person.
