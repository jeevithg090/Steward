---

name: write-short-post
description: Turn one key idea into a punchy social post under 280 characters.
---

1. Take one key idea.
2. Write a hook: a question, bold statement, or vivid image.
3. Add the payoff in 1–2 short sentences.
4. Cut filler words. Count characters.
5. If over 280, trim the payoff, keep the hook.
6. Output plain text, no hashtags, no emojis unless requested.
