---

name: extract-key-points
description: Pull 5–7 distinct, standalone ideas from a long-form text.
---

1. Read the full text from start to end.
2. Highlight sentences or paragraphs that contain a complete thought: a claim, a lesson, a story beat, a data point, a question.
3. Group related highlights; keep only the strongest from each group.
4. Select 5–7 points that each work alone and together tell the arc of the piece.
5. If fewer than 5, note the count and proceed with what exists.
