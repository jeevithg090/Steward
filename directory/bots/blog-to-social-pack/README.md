# Blog to Social Pack

Turns one long blog post into five ready-to-post short updates and a threaded version for X, Threads, Bluesky, or Mastodon.

## What it does

- Reads a blog post from a file or public URL
- Extracts 5–7 core ideas
- Writes 5 standalone posts (≤280 chars each)
- Writes 1 threaded version (5–7 connected posts)
- Delivers both in a clean Markdown page

## What it needs

- A file path or public URL to the blog post
- No sign-ins, no API keys

## What it will not do

- Add hashtags, emojis, or platform-specific formatting unless asked
- Post anything automatically — you copy and paste
- Work with paywalled or login-only content
- Create LinkedIn posts, Instagram captions, or newsletter blurbs (different formats)
