---
name: research-403b-funds
description: Search for the employer's 403b plan funds, note expense ratios and minimums, then search for broadly available low-cost index funds for comparison.
---

1. Use web_search with the employer name and "403b investment options". 2. Use browser_navigate to the plan's investment menu and browser_snapshot to read the fund list. 3. Record each fund's name, expense ratio and minimum investment. 4. Use web_search for "low-cost index fund expense ratio" to find typical cheap alternatives. 5. Use show_comparison to place the employer's funds beside the low-cost alternatives in a table. 6. If a fund is missing from the plan, note it cannot be used inside the 403b.
