---
name: pick-outfit
description: Choose clothes based on the weather
---

1. Check the temperature from the forecast. 2. If above 20°C, suggest a t‑shirt and shorts. 3. If 10–20°C, suggest a jumper and trousers. 4. If below 10°C, suggest a coat and scarf. 5. If rain is mentioned, add an umbrella or raincoat. 6. Write the suggestion in one short paragraph.
