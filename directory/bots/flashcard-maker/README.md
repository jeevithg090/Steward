## Flashcard Maker

Turns your notes into flashcards and quizzes you on them. Give it a file path (Markdown, text, or similar) and it will extract question-answer pairs, save a deck, and run an interactive quiz.

### What it needs

- A file with notes that have clear questions and answers (headings, Q/A markers, or bullet points).
- Permission to read files, write a deck file, and remember the deck for later.

### What it will not do

- Invent facts or answers not in your notes.
- Guess structure from completely unformatted text; it will ask you to add markers.
- Send data anywhere; everything stays on your computer.
