---

name: run-quiz-session
description: Present flashcards one by one, collect answers, and score the session.
---

1. Shuffle the card list if the person wants random order.
2. For each card: show the question, wait for the person's reply, then reveal the answer.
3. Ask the person to self-grade (correct/incorrect) or compare if the answer is short and exact.
4. Track counts: total, correct, incorrect, and a list of missed cards.
5. After the last card, show a summary table with the counts and the missed questions.
6. Ask if they want to review missed cards, reshuffle, or end.
