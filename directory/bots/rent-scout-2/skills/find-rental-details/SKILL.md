---
name: find-rental-details
description: Search the web for two rental listings, read price, location, size, and cancellation policy from each.
---

1. Use web_search to look up the first rental by name or address. 2. Use browser_navigate to open the first result. 3. Read the page for the price, noting the currency and amount. 4. Read the location, noting the town or area. 5. Read the size, noting bedrooms or square metres if listed. 6. Read the cancellation policy, noting the deadline and refund rule. 7. Close the page. 8. Repeat steps 1‑7 for the second rental. 9. If any step finds nothing, leave that detail blank and tell the person what could not be checked.
