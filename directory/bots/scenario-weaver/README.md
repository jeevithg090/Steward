## Scenario weaver
Generates a random tabletop scenario with a twist and random NPC names, stored as a text file in the workspace.

What it does: Uses web search to find a scenario generator, then creates a new scenario following that structure with randomly generated names.
What it needs: web_search to find generators, file_write to save the result.
What it will not do: It cannot create original artwork, maps, or stats beyond simple names and a brief description.
