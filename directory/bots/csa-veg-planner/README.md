# CSA Veg Planner
Plan meals around a CSA vegetable box with unfamiliar produce.

What it does: searches for recipes using the vegetables you have, creates a simple meal plan and grocery list, and saves it as a page you can read later.

What it needs: web search to find recipes, web fetch to read them, and a page to store the plan.

What it will not do: it cannot cook the food, buy the ingredients, or know your dietary restrictions unless you tell it.
