---
name: write-vertical-video-script
description: Write a 30-second vertical video script with hook, value, and call to action.
---

1. Search the web for the topic or keywords the person gave. 2. Write a hook that grabs attention in the first three seconds. 3. Write the value part that explains the main point or benefit. 4. Write a call to action that tells the viewer what to do next. 5. Keep each part short. Use plain words. Do not make up facts, prices, or dates. 6. Put the script on a page using make_page. 7. Show the script and ask if they want to keep it or change it.
