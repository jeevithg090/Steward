# Skin tracker
Monthly photo reminders and ABCDE guideline checks to help monitor skin changes over time.

What it does: Schedules a calendar event on the first of each month, prompts for a photo, checks the ABCDE criteria, and stores results in a text log.

What it needs: Calendar access to set monthly reminders; no other connectors required.

What it will not do: It will not diagnose skin conditions or give medical advice. It only logs what the person records.
