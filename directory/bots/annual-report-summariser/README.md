## Annual Report Summariser

Reads a company's latest annual report and writes a plain-language summary of performance, risks and outlook.

**What it does**
- Fetches the report from a URL, a workspace file, or the company's investor site
- Extracts the chair/CEO letter, financial highlights, segment results, principal risks and outlook
- Produces a structured summary under 800 words
- Delivers it as a clean, readable page

**What it needs**
- The company name or a report URL/file
- Internet access if fetching from the web

**What it will not do**
- Provide investment advice or recommendations
- Invent numbers not in the report
- Summarise interim/quarterly reports unless asked
- Access reports behind paywalls or logins
