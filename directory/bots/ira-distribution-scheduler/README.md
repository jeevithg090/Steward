# ira distribution scheduler
Creates a 10-year required minimum distribution schedule for an inherited IRA.

What it does: finds the IRS distribution factor and calculates the annual RMD amounts.
What it needs: web_search to find the factor, show_table to display the results, make_page to save the table.
What it will not do: it does not give tax advice, it does not access any account balances beyond what the person provides, and it does not file any forms with the IRS.
