---
name: search-for-etfs-by-benchmark
description: Search the web for a benchmark name plus terms like 'ETF replication method' or 'physical synthetic ETF'. Read the results and note the benchmark name, ETF name, and replication method. If a result does not clearly state the replication method, skip it. Continue until at least two ETFs with different methods are found for that benchmark, or until no more results are available.
---

1. Type the benchmark name into web_search. 2. Scan the results for ETF listings. 3. For each ETF found, check if the replication method is stated. 4. Record the ETF name and method. 5. If fewer than two methods are found, run another search with different keywords. 6. Stop when two distinct methods are recorded or when no more results appear. 7. If only one method is found, note that only one method was available for that benchmark.
