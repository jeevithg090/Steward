## Two-player board game finder

Finds board games designed for two players that play in under an hour. Searches recent reviews and community lists, extracts play time, complexity, genre, and ratings, and presents a sorted comparison table.

**What it needs**: Web search and fetch tools to read current board game coverage.

**What it will not do**: Invent play times or ratings. Recommend games without a source. Access private collections or marketplaces.
