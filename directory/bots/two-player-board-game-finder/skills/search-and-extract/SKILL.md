---
name: search-and-extract
description: Search for two-player board game lists and extract key details from each source.
---

1. Search for recent articles, videos, and forum threads about two-player board games under 60 minutes.
2. Open 5 to 8 diverse sources (review sites, publisher pages, community rankings).
3. For each game mentioned, record: name, stated play time, complexity, genre, rating, and a one-sentence gameplay summary.
4. Note the source URL and publication date for each game entry.
5. Flag any game where play time is not explicitly stated or is given as a wide range.
