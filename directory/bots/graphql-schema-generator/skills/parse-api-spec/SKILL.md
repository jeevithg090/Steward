---
name: parse-api-spec
description: Read the REST API specification file and identify resources, endpoints, and field types.
---

1. List files in the workspace to locate the API specification file. 2. Read the specification file to understand its structure and resources. 3. Identify each resource, its fields, and their data types as defined in the spec. 4. Note any required fields, optional fields, and field descriptions. 5. Record the HTTP methods and paths for each endpoint if present. 6. Prepare a summary of the resources and their shapes for the output files.
