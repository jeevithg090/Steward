---
name: build-meal-table
description: Create a table of meals with potassium values
---

1. Use web_search to find a list of low-potassium foods and their potassium content per serving. 2. Record the daily potassium limit the person gave. 3. Select one breakfast, one lunch, one dinner and two snack options that each stay under the limit. 4. Write each meal and its potassium value in a markdown table with columns: Meal, Food, Potassium (mg). 5. Add a row at the bottom showing the total potassium for the day. 6. Repeat for each day of the week.
