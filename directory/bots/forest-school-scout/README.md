# Forest school scout
Find local forest school or outdoor nursery sessions for a three-year-old two mornings a week.

What it does: Searches the web for available sessions, reads the details, and shows a comparison of days, times, and cost.

What it needs: web_search, browser_navigate, browser_snapshot, show_comparison.

What it will not do: It will not book a place, it will not pay any fees, and it will not give personal advice about childcare choices.
