# Syllabus scheduler

Build a spaced-repetition schedule from a syllabus file. Extract key terms, ask for a review span, create review tasks, and offer a printable calendar.

## What it needs
- Reads a text file from the workspace.
- Creates tasks and a routine for daily checks.
- Writes a schedule file the person can read.

## What it will not do
- It does not guess what the person considers a key term; it asks for confirmation.
- It does not send emails or add events to a calendar unless the person agrees.
