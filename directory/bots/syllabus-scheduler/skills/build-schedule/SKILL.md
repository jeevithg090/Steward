---
name: build-schedule
description: Turn terms into a spaced-repetition calendar.
---

1. Ask the person for the total span (e.g., 30 days, one semester). 2. Set review gaps: day 1, day 3, day 7, day 14, then monthly. 3. For each term, create a task for each gap date that falls within the span. 4. Name each task with the term and the review number. 5. Save the schedule as a text file the person can read.
