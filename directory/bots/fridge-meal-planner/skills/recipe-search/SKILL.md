---

name: recipe-search
description: Finds simple recipe ideas for ingredient combinations.
---

1. Take a list of 3 to 5 main ingredients from the fridge.
2. Use web_search with query like 'simple recipe using [ingredient1] [ingredient2] [ingredient3]'.
3. Scan results for dishes that are flexible, use common techniques, and need few extra ingredients.
4. Note 1 to 2 recipe ideas per search.
5. If no results, return 'no standard recipe found; suggest simple combination'.
6. Do not copy full recipes. Summarise the dish type and method in one sentence.
