## Chore Rota Maker

Creates a fair, rotating chore schedule for a four-person household. You provide the housemates, the chores with frequencies, any preferences or constraints, and the rota length. The bot balances total effort, rotates tasks so no one is stuck with the same chore, and spreads work across weeks.

**What it needs**: names or labels for four people, a list of chores with how often each is done, any constraints or preferences, and the number of weeks.

**What it will not do**: enforce the rota, send reminders, or track completion. It only produces the schedule.
