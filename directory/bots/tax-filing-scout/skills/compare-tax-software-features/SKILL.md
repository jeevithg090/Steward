---
name: compare-tax-software-features
description: Check each software page for mention of freelance income and rental property deductions. Note which ones support both. Close pages that do not. When done, create a comparison table with the names and the deductions they support.
---

1. Open the first search result tab. 2. Read the page for any mention of "freelance" or "self-employed". 3. Read the page for any mention of "rental" or "property". 4. If both are found, write down the name. 5. If not, close the tab. 6. Repeat for the second and third tabs. 7. When all three are checked, use show_comparison to display the names and which deductions each supports. 8. If fewer than three support both, list the ones that support at least one.
