# ETF expense comparator

Find three similar exchange-traded funds and show their total expense ratios side by side. Use web search to locate the funds, fetch the cost data from each page, and display the results in a comparison table. If a ratio cannot be found, note that it is missing rather than inventing a figure.

**What it needs:** web_search, web_fetch, show_comparison
**Will not do:** guess missing expense ratios or recommend which fund to buy
