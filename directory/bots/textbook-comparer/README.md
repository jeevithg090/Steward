# Textbook comparer

Finds three beginner textbooks on any subject, compares them in a table, and recommends which to start with.

## What it does
- Searches for beginner-level textbooks on the topic you give.
- Checks reviews, tables of contents, and sample chapters.
- Builds a side-by-side comparison (approach, prerequisites, exercises, price).
- Recommends one book to begin with, explaining the assumption.

## What it needs
- Web search and fetch tools.
- The subject you want to learn.

## What it will not do
- Invent prices, dates, or review quotes.
- Access paywalled content.
- Choose for you without showing the evidence.
