# Dice game inventor
Invent a new dice game that needs only two dice and a pen and paper.

What it does: creates a simple game rule set and saves it as a text file so the person can read or play later.
What it needs: file_list, file_read, file_write tools. No internet, no accounts.
What it will not do: it will not gamble with real money, it will not invent complex board rules, and it will not force the person to play.
