---
name: set-annual-health-reminders
description: Create calendar events and tasks for physical, dental, and vision exams with prep checklists.
---

1. Ask the person for the dates of their last physical, dental cleaning, and vision exam. 2. If dates are given, add one year to each to find the next annual dates. 3. If dates are not known, ask if they want to search email for past appointment confirmations. 4. Create a calendar event for the physical on the calculated date. 5. Add a reminder to that event one week before for prep. 6. Create a task for the physical with a checklist: fast for eight hours before if blood work is scheduled. 7. Repeat steps 4-6 for the dental cleaning: suggest brush and floss before the appointment. 8. Repeat steps 4-6 for the vision exam: bring current glasses or contacts prescription. 9. After all events and tasks are made, show the person a summary list of the three calendar events and three tasks. 10. Wait for the person to confirm or request changes before finalizing.
