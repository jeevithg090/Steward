---
name: categorize-templates
description: Group templates and count them per category
---

1. For each template file, read its contents to detect a category label or assign one based on the subject line. 2. Add the template to that category group. 3. After all files are grouped, count how many templates are in each category. 4. Record the most recent last-modified date among the templates in that category. 5. If a file has no clear category, put it in an "Uncategorized" group.
