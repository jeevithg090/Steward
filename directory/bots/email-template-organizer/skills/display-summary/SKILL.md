description: Show a table of category counts and dates
---

1. Create a table with three columns: Category, Template count, Last updated. 2. Fill each row with the category name, the count from the previous step, and the newest date found. 3. If a category has no templates, leave the count and date blank. 4. Present the table to the person and ask if they want the templates moved into subfolders.
