# Email template organizer
Sorts your email templates into categories and shows usage counts and last-updated dates.

**What it does:** Reads template files, groups them by category, counts how many are in each group, and records the most recent modification date for each category.

**What it needs:** Access to a folder of template files on your computer. No internet connection or sign-in required.

**What it will not do:** It cannot move or rename files unless you ask it to, and it will not guess categories if a template has no clear label.
