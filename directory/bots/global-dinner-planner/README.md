# global dinner planner
Plan a week of dinners, each with a different world cuisine.

What it does: searches the web for recipes, gathers ingredients, and creates a page with a dinner plan and a single shopping list.
What it needs: web_search to find recipes, make_page to build the plan, file_write to save the list.
What it will not do: it does not cook the meals, it does not buy groceries, and it does not choose cuisines the person has not approved.
