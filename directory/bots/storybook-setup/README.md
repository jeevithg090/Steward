# Storybook setup
Add Storybook to a React component library and write component stories.

What it does: Installs Storybook, configures the stories directory, and creates story files for each component so the person can view and develop UI in isolation.

What it needs: Access to the computer's shell and file system to run npm commands and write story files.

What it will not do: Install third-party packages that require authentication or pay for any services.
