# Alcohol-free challenge

A 30-day alcohol-free challenge with daily tips, mocktail recipes, and coping strategies for social events.

**What it does:** Creates a page with a 30-day calendar, adds the first mocktail recipes and coping strategies found on the web, and sets a daily task so the person can log their progress.

**What it needs:** make_page to build the page, web_search to find recipes and strategies, task_create for the daily check-in, routine_create if a repeating routine is wanted.

**What it will not do:** It will not give medical advice or tell the person how to quit drinking. It will not force a routine on the person without asking.
