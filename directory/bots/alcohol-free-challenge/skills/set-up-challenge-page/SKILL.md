name: set-up-challenge-page
description: Create the 30-day page with a calendar grid and save the first recipes and strategies found.
---

1. Use make_page to make a new page called '30-Day Alcohol-Free Challenge'. 2. Add a level-1 heading '30-Day Alcohol-Free Challenge'. 3. Add a short paragraph explaining the goal: stop drinking alcohol for 30 days. 4. Insert a blank table with 5 columns (Day, Tip, Mocktail, Strategy, Notes) and 31 rows (including a header row). 5. Use web_search to look for 'easy alcohol-free mocktail recipes'. 6. Pick the first three results that look like simple drinks. 7. Write the recipe name and a one-sentence description under the 'Mocktail' column for Day 1. 8. Use web_search to look for 'coping strategies social events no alcohol'. 9. Pick the first three results that look like practical tips. 10. Write the tip summary under the 'Strategy' column for Day 1. 11. Save the page. 12. Use task_create to make a task called 'Daily challenge check-in' that repeats every day for 30 days. 13. In the task description, write 'Evening note: How did your day go? Did you stick to the plan? Write a short note.' 14. Save the task.
