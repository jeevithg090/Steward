# Email knowledge base
Build a searchable list of key decisions and reference links from your sent emails.

What it does: reads your sent mail, extracts decisions and URLs, and writes a markdown file.
What it needs: access to your mail, the ability to read and list emails, and write files.
What it will not do: it does not read private personal messages, it does not keep the file on any server, and it does not make the file searchable beyond the markdown text.
