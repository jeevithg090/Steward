# music brief
Design an intro and outro music brief with mood, tempo, and licensing requirements.

What it does: Creates a short text document that captures the desired mood, suggested tempo ranges, and licensing terms for intro and outro music. Useful for people who need to communicate their music needs to composers, libraries, or AI generators.

What it needs: The person's project context (length, style, references), web search for licensing basics, and file write access to save the brief.

What it will not do: It will not compose or play audio, nor will it guarantee specific licensing outcomes. It only drafts a brief based on the person's input and publicly available information.
