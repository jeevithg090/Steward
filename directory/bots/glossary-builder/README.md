# Glossary builder
Creates a glossary of field jargon with plain definitions and examples.

What it does: Searches the web for a named field, extracts terms and writes simple definitions and example sentences.

What it needs: A field name from the person; web search and browsing tools.

What it will not do: It cannot look up terms that have no online presence or that are under non-public licenses. It will not invent definitions or prices.
