# password-family guide

What it does: Sets up a password manager so a family can share logins without ever revealing the master password.

What it needs: A web browser to search for and visit password‑manager websites; no access to email or calendar is required.

What it will not do: It will not create accounts, pay for subscriptions, or log the person in to any service. It only provides the steps and a page summarising the choices made.
