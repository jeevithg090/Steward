---
name: find-and-read-privacy-policy
description: Look for the shop's privacy policy on its website.
---

1. Use web_search to find the shop's website. 2. If no website is found, say so and stop. 3. Use browser_navigate to open the homepage. 4. Use browser_snapshot to read the page and look for a link labelled 'privacy policy', 'privacy', or similar. 5. If a link is found, use browser_navigate to open that link. 6. Use browser_snapshot to read the full privacy policy page. 7. Look for sections about data collection, personal information, or how the shop uses data. 8. Summarise the key points in a short paragraph. 9. If no privacy policy is found at any step, say so and stop.
