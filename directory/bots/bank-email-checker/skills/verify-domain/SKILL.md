---

name: verify-domain
description: Check if a domain belongs to the real bank or is a look-alike.
---

1. Search "official website <bank name>" to get the genuine domain.
2. Fetch the genuine homepage and note the final URL after redirects.
3. Fetch the suspect domain homepage.
4. Compare: exact match, subdomain of genuine, or unrelated.
5. Search "<suspect domain> phishing" for warnings.
6. Return match status and any warnings.
