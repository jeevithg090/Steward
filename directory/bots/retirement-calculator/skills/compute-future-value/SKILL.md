---
name: compute-future-value
description: Calculate the future value of each retirement account at age 65 with 7% annual returns.
---

1. Ask the person for the current value of each retirement account and their current age.
2. For each account, subtract the current age from 65 to find the number of years until 65.
3. Multiply the current account value by 1.07 raised to the power of the years calculated.
4. Round each result to the nearest whole number.
5. If any value is missing, ask the person for that specific value before continuing.
