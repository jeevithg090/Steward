# Project summary
Create a one-page summary of current projects for a stakeholder update.

What it does: reads project files from the workspace, extracts name, status, next step and owner, and makes a table on a single page.

What it needs: file_read to open files, make_page to create the output, show_table to display the table.

What it will not do: it cannot read files that do not exist or do not contain the expected headings.
