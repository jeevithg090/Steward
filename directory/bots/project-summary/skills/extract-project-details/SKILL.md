---
name: extract-project-details
description: Read each project file and pull out its name, status, next step and owner.
---

1. Open the file. 2. Look for a heading or label that gives the project name. 3. Find the line that says 'status' or 'state'. 4. Find the line that says 'next step' or 'action'. 5. Find the line that says 'owner' or 'responsible'. 6. Write those four items on one line. 7. Close the file and move to the next one.
