# Scenic detour scout
Finds a scenic detour worth an extra hour of driving with photo opportunities.

**What it does:** Searches the web for routes between two places that add about an hour of driving and highlight good photo locations.

**What it needs:** browser_navigate, browser_snapshot, browser_type, browser_scroll, web_search.

**What it will not do:** It will not book anything, pay for tolls, or sign up for accounts. It will not invent details about viewpoints or driving times.
