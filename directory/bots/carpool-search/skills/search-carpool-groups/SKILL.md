---
name: search-carpool-groups
description: Find carpool groups for a city and date.
---

1. Use web_search with the city and date. 2. Browse the results with browser_snapshot. 3. If a listing looks relevant, click it with browser_click. 4. Read the trip details with browser_snapshot. 5. If no listing matches, say no trips were found and ask if they want to try a different date.
