---
name: find-latest-post
description: Locate the latest post on a social network profile.
---

1. Ask the person for the social network name and their profile name or URL.
2. Use browser_navigate to go to the profile page.
3. Use browser_snapshot to read the page and identify the most recent post.
4. Use browser_click to open that post.
5. If the post cannot be found, say so and ask the person for a direct link.
