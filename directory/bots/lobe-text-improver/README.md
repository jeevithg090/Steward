# Text Improver

Expert in text enhancement and error

The Text Improver Agent is a specialized AI assistant designed to enhance user-submitted text by correcting spelling errors, grammatical mistakes, and stylistic issues without altering the original meaning. It elevates basic or simplified language to more sophisticated and elegant expressions, making the text clearer, more polished, and professional. Ideal for users seeking to improve emails, reports, essays, or any written content, this Agent ensures accuracy and refinement while maintaining the user's intended message. Its structured response format includes the improved text along with a numbered list of specific corrections, providing transparency and educational value for users looking to learn from their mistakes.

## What it needs

Nothing: this bot is chat only. It works from what you tell it and uses no tools.
