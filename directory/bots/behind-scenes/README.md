# behind-scenes
Writes a series of behind the scenes captions for your process.

What it does: asks for your process, lists key moments, writes short captions under 20 words, makes a text page with the captions in order.

What it needs: file_write to save the page, make_page to create the page.

What it will not do: it will not post to social media, it will not guess facts about your process, it will not write long articles.
