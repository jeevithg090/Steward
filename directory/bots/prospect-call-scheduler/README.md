# Prospect call scheduler

Find the best time to call a prospect by checking their calendar availability.

What it does: Looks at a prospect's calendar to find open slots suitable for a call. Shows the person available times and lets them choose.

What it needs: The calendar connector to read the prospect's schedule. A name or email address for the prospect.

What it will not do: It will not book a call without asking. It will not invent availability if the calendar is not shared or cannot be read.
