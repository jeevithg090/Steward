---
name: check-calendar-availability
description: Find open time slots in a prospect's calendar
---

1. Use calendar_list to view the prospect's calendar. 2. Scan the list of events for the next seven days. 3. Identify any gaps of thirty minutes or more between events. 4. Note the start and end times of each gap. 5. If no gaps are found, report that the calendar is full. 6. If gaps are found, list up to three options with dates and times. 7. Always ask the person to confirm which slot they want to use before proceeding.
