---
name: calculate-sweat-rate
description: Find sweat rate formulas and electrolyte guidelines. Ask for before/after run weight if needed. Build a table of fluid and electrolyte needs per hour of training.
---

1. Search the web for "endurance sweat rate formula" and "electrolyte timing endurance sports". 2. If results exist, note the typical fluid loss per hour (e.g., 500–1000 ml) and electrolyte recommendations (e.g., 300–500 mg sodium per litre). 3. Ask the person: "How long do you train and do you weigh yourself before and after?" 4. If they give numbers, calculate hourly fluid loss: (weight before minus weight after) divided by hours. 5. Add the search-based baseline if the person has no weight data. 6. Make a table with rows for each hour of training, showing fluid amount and an electrolyte note such as "take a salt tablet or electrolyte drink". 7. Show the table to the person.
