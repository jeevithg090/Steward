---
name: map-co-authorship
description: Collect co-author names from a researcher's publication list.
---

1. Use web_search to find the researcher's name and institution. 2. Use browser_navigate to open their academic profile or institutional page. 3. Use browser_snapshot to read the list of publications. 4. Use browser_click to open each major paper and read the author list. 5. Use browser_type to copy each co-author's name and affiliation into a text file. 6. Use file_write to save the list. 7. Use show_table to display the top co-authors and their institutions.
