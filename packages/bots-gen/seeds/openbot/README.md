# OpenBot coworkers

Ten coworker files copied from CopilotKit OpenBot (https://github.com/CopilotKit/openbot),
`examples/fintech/catalog/`, MIT licence, so `seed convert-openbot` runs without the upstream
checkout. They are converted, not loaded: the converter in `src/convert/openbot.ts` turns each
into a "work" pack credited to OpenBot. See the repository's `NOTICE`.
