# Images

Screenshots used by the README and the docs. Take them from a fresh run with the scripted model and
the demo inbox (`STEWARD_MODEL_PROVIDER=scripted pnpm dev`), so they show nothing private, at a
window 1440 pixels wide, in the light theme.

| File                | Shows                                                                                                                                    |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `steward-today.png` | Today, after **Make my brief**: the brief with Needs you, Can wait and Today.                                                            |
| `steward-chat.png`  | Chat, with an email waiting for an answer: the approval card with Refuse, Allow once and Always allow, and the computer panel beside it. |

Every image in the docs needs alt text that says what it shows, not what it is.
