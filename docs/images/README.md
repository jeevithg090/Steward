# Images

Screenshots used by the README. They show nothing private: the mail and calendar are the made-up
demo inbox, and the web pages are real. The first five come from a live run (window 1440 pixels
wide, scaled to 1600). The last four come from a fresh data folder with the scripted model, on the
default ports, in a 1280 by 800 window at 1.25x.
